## 一、大致工作流程

1. 按需求撰写 .md 规划文件（Obsidian 样式），规划习题，配图，详细的解答。每题、每个分题及每个小分题（如有）各附四维难度标记与逐维判定理由——小分题独立打标、父分题不单设标记（直接参考原始规划文件 `C:\Users\xuless\OneDrive\Xuless Obsidian Note\HKDSE course\习题难度标记\习题难度标记方案-规划.md` 打标，不再调用 `hkdse-math-difficulty` skill）；

2. 执行自检，以对应章节的课题讲义为准，检查是否有超纲的技巧与问题；
3. 执行第七章 7.6 难度与框色统计、7.7 讲义节难度上限对照检查（规划初稿完成时、任何难度调整后必做）；
4. 提交给用户审批；
5. 按注释规划修改方案（如有）；
6. 按规划方案撰写 .tex 习题册与答案文件，落实**三处同步**——规划 .md／正文 .tex／答案 .tex 三份文件信息一致（.tex 内部的中文题面／英文题面／答案三处对应随三处同步一并保证）；
7. 后续细节处理与修改。

### 3.3 写作与符号规范

- **恒等号（≡/=）区分在 .md 规划阶段即须遵守，且仅自第四章（Ch04）起生效**：三恒等式（平方和、商数、互余）及其恒等变形（通分/约分/完全平方展开/合并同类项/同乘除非零量）用 `≡`；代入数值/特殊角求值、解方程、具体三角形定义代入用 `=`（互余关系亦作恒等式用 `≡`；**移项属解方程语境，用 `=`**，不列入恒等变形清单）。**Ch00–Ch03 统一用 `=`**（恒等号符号于讲义 Ch04 才引入，此前章节不出现 `≡`）。

> 下列示例中的恒等号写法仅适用于 **Ch04 及之后的章节**；Ch00–Ch03 一律用 `=`，不出现 `≡`。

```
# 三恒等式及一般恒等变形（恒等成立，恒用 ≡）
$\sin^2 x + \cos^2 x \equiv 1$（平方和恒等式）
$\tan x \equiv \dfrac{\sin x}{\cos x}$（商数恒等式）

# 恒等变形过程：通分 / 约分 / 完全平方展开 / 合并同类项 / 同乘除非零量（移项属解方程语境用 =，不列入）
$(a+b)^2 \equiv a^2 + 2ab + b^2$（完全平方展开）
$\dfrac{1}{a} + \dfrac{1}{b} \equiv \dfrac{a+b}{ab}$（通分）
$\dfrac{ab}{ac} \equiv \dfrac{b}{c}$（约分，$a \neq 0$）
$2x + 3x \equiv 5x$（合并同类项）

# 代入数值 / 解方程 / 具体数值 = 用 =
当 $x = 30^\circ$ 时，$\sin x = \dfrac{1}{2}$
解 $x^2 = 4$ 得 $x = 2$ 或 $x = -2$
```

## 四、命题规范与出题原则（强制）
### 4.1 题目结构

> **「结构化分题（结构化问题）」**：包含分题的题目，其中前面的分题具有前后联动——后面分题需要综合前面分题的信息与结论才能解题。下文的「分题结构」即指对结构化问题的分类（无结构 / task 类 / 简单结构 / 复杂结构）。

- **分题结构四分类**（只看大分题个数；i,ii 小分题不计）：
  - (1) 无结构（单一题）
  - (2) task 类（`\task` 多栏批量）
  - (3) 简单结构（恰 a、b 两大分题）
  - (4) 复杂结构（a-b-c 及以上）
- **结构比例**：(1):(3):(4) ≈ **2:7:1**（task 另计）；简单结构内部「有小分题:无小分题」≈ 1:2；
- **DSE 卷一长题 ≠ 复杂结构**：多按 (a)(b) 简单结构，分量在分题内多步骤操作；综合/长题不得默认堆 a-b-c 长度；
- task 类主要用来出批量的、重复的、机械性的小题。其余题目都要避免使用。

**`\task` 与一般题目的区分示例：**

```
# ✅ task 類（一句話指令 + 並列獨立項、各自套同一規則、項間無聯動；真實題：Ch27 題 1）
解下列各方程。
\begin{onecolunm}
    \item $5^{x}=5^{2(x-2)}$
    \item $3^{2x}=3^{x+6}$
    \item $2^{3x}=2^{2(x+1)}$
\end{onecolunm}
（各項均獨立以同底法求解，互不依歸 → task；正文用 `onecolunm`／`twocolunm`／`fourcolunm`）

# ✅ 一般題目（簡單結構：主題干只陳述信息，(b) 必須綜合 (a)；真實題：Ch27 題 26）
設 $a$ 為常數。考慮方程 $\log_{3}(x^{2}-2x+3)=a$。
(a) 當 $a=1$ 時，解方程。
(b) 求使方程有實數解的 $a$ 之取值範圍。

# ❌ 反例：把有聯動的問題硬寫成 task（(b) 需 (a) 的定義法與值域做台階，不得並列）
\task 當 $a=1$ 時解 $\log_{3}(x^{2}-2x+3)=1$。  \task 求使 $\log_{3}(x^{2}-2x+3)=a$ 有實數解的 $a$ 範圍。   % ← 錯
```

### 4.2 命题规范

- **命题范围只取自讲义**：范围只能取自 `DSE 课题讲义/`；官方考纲仅用于题目标记框判定（蓝框/红框，见 5.1），不决定内容范围、不增删内容。讲义未讲概念一律不考（如 Ch19 阶段：满射、读图解方程「交点=解」、二次不等式、零点/顶点/对称轴、最大最小值、斜率与 y 截距严格定义、圆方程、指数函数、连续性等；「顶点」虽在讲义 19.2.4 出现，属 Ch21 内容，习题避免）；
- **命题不得超出当前章节及前置章节范围**；对用户修改建议须核对是否超范围，不盲从；
- 参考 `hkdse-math-question-bank` 提供的 DSE 习题库，结合讲义混合命题；
- **必须联网搜索收集命题资料**；鼓励以有趣数学结论为基础拆分结构化为新题；不限于理論習題部分；
- **难度线性递增**（最高国内高考/竞赛级，仍须结构化分题）——按「难度评分体系」四维字典序 T→C→Q→E 排序落实；
- **命题难度须参考讲义节难度上限**：「各章小節」部分的題目難度以講義對應 `##` 節（XX.X 級）標注的「本節難度上限」為**上確界**——最高難度不突破該檔，且至少一題達到該檔；**綜合練習與理論習題部分不適用**（見第七章 7.7）；
- **「理論習題」板块必含**：证明为主之数学问题及理论探索；证明题严禁重复讲义证明——证明内容严禁与讲义一致，须用已建定理推新结论；
- **跨章联动题标准**：联动题＝題級總難度的 Q 維（跨課題）達到 C 檔或以上（按題計，分題不單獨計）；不再作全章聯動佔比與每節聯動題數之限制。
- **命题方法须通用、显然**：解答选用通用、显然的方法，
	- 避免解答过程出现对于当前阶段的学生无法掌握或没有掌握的技巧与思想。
	- 如果解答过程不可避免地出现上述内容，需要考虑在该题目内加入更多的引导技巧。详见第七章「超綱思想方法紅線」約束：分析式手法可在**給足引導**（分題台階或题干括號提示）下使用，未給引導即判錯題；詳見 7.2.1 紅線條。

```
✅ 正例：设 $P(x)=(x-1)(x-2)(x-3)$，求 $P(4)$——直接代入 $x=4$ 得 $P(4)=6$（通用直接法）
❌ 反例：设 $P(x)=(x-1)(x-2)(x-3)$，求 $P(4)$——先观察「$4-1,4-2,4-3$ 对称于 $1,2,3$」再构造对称式求值（依赖特殊结构观察，非通用法）
```

- **负数偶次根式的表述**：涉及负数的偶次方根，不得断言「无意义／无定义」——学生已学复数（Ch17），反驳类解答须在复数域实际计算结果对比（如 $\sqrt{-1}\cdot\sqrt{-1}=\mathrm{i}^{2}=-1\ne1=\sqrt{(-1)(-1)}$），或题干明确限定实数域；此类题目按关联分析 Ch17 复数条目（负实平方根未列学习重点、讲义覆盖）作考纲外表述处理（红框候选）

```
✅ 正例：$Q(x)$ 为首一二次多项式，且 $Q(1)=Q(2)=0$，求 $Q(x)$（首一限制使唯一确定）
❌ 反例：$Q(x)$ 为二次多项式，且 $Q(1)=Q(2)=0$，求 $Q(x)$（$Q=k(x-1)(x-2)$，$k$ 任意，不唯一）
```

- **task 之外的题目避免纯机械操作题，题目需要有匹配考核章节的深度。**

```
✅ 正例：求 $2x^2-3x+1$ 除以 $x-1$ 的余式（考核余式定理的理解与运用）
❌ 反例：逐项抄写多项式再合并同类项（纯机械操作，无教学价值）
```

- **基础操作的机械化操练须由 `task` 承载**（2026-09-29 新增，用户指认 Ch20「缺少直线的一般式、斜截式、截距式三者之间的互相转换，以及从这三种形式之间读取斜率，x y 轴截距的机械化操练类题目」）：本章核心的基本操作须以 `task` 类题目成批操练；**凡讲义为同一对象建立多种等价表达形式的章节，须覆盖「形式间互相转换」与「从各形式读取基本量」两类操练**（讲义明文不作要求的形式可除外）；转换与读取操练本身即以形式为考核对象，属 4.5.2「不要求表达方式」条的**刻意考核例外**，但操练项数据仍受下条「不得与讲义示例逐字相同」约束。此类题目属基础操练，按 5.1①「太基础批量操练」标无框（或按内容归框）；与上条「task 之外避免纯机械操作题」不冲突——task 正是机械操练的载体。

```
✅ 正例（设计示意：Ch20 §20.3 待依本条新增 task 题承载）
把下列直线方程化为指定的形式；若某一形式写不成，说明原因。
\begin{onecolunm}
    \item $3x-4y+12=0$ 化为斜截式
    \item $y=-\frac{2}{3}x+4$ 化为一般式
    \item $\frac{x}{5}+\frac{y}{-3}=1$ 化为一般式
    \item $2x+3y-6=0$ 化为截距式
    \item $3x-2y=0$ 化为截距式（写不成：过原点）
\end{onecolunm}
读取类同法成批：写出下列各直线的斜率、$x$ 截距与 $y$ 截距（不存在者说明原因）——项目分取一般式、斜截式、截距式三类。
❌ 反例（真实缺陷：Ch20 2026-09-28 重规版）：全章 5 道 task（描述法从属、斜率直算、共线判据、联立解况、点线距离）无一题操练三形式互化与斜率、截距读取，被用户指认缺少该类机械化操练题。
```

- **习题数据不得与讲义示例逐字相同**（2026-09-29 新增）：题目数据（坐标、系数）与讲义示例相同乃至答案一致者，学生照抄讲义即完成，考核失效；命题时逐题比对本章讲义示例数据，撞车即换。

```
❌ 反例（真实例：Ch20 题 6(a)(b) 旧数据）：task「求斜率」两项 $A(1,2)$ 与 $B(4,8)$、$C(-2,5)$ 与 $D(3,-1)$ 与讲义 §20.2.1 示例（求斜率）逐字相同，答案亦同（$2$、$-\frac{6}{5}$）
✅ 更正（真实例：Ch20 题 6 2026-09-29 换数据）：$A(-2,4)$ 与 $B(3,-6)$（$m=-2$）、$C(4,-3)$ 与 $D(-1,5)$（$m=-\frac{8}{5}$）
```

### 4.3 引导与提示方法

对题目添加引导与提示的处理方法：

- **引导**：使用分题、小分题，或在题干中插入提示语，引导学生思考特定的代数结构、公式、结论、定理等。
- **提示**：在题干后使用括号 `（提示：……）` 为考生提供方法。

**添加引导的行文风格**：必须保持**极简、克制、点到为止**；严禁「给完一个引导点后继续书写推导过程」。

```引导的示例与反例
例1（在题干前直接让学生利用前面分题 (a)，引导学生思考前面的分题与当前分题的关系）：利用 (a)，或其他方法，求 $x$。
（注意不要写任何其他细节，例如「利用 (a) 所得的…」，否则就是过度引导。）

例2（在题干中引入公式的一些性质，引导学生思考）：考虑 $(x-y)^2$ 的正负，证明 $x^2+y^2>2xy$。
（注意不要进一步继续说诸如「接着展开 $(x-y)^2$」之类，否则就是过度引导。）

例3（在题干中引入公式）：利用恒等式 $a^3+b^3 \equiv (a+b)(a^2-ab+b^2)$，求两根的立方和。

例4（类似于例1，但给出多个不同的引导）：利用 (a) 与三次恒等式，或其他方法，求 $x$；利用 (a) 与 (b)，或其他方法，求 $x$。

反例1：考慮關於 $t$ 的式子 $\left(a_1t+b_1\right)^{2}+\left(a_2t+b_2\right)^{2}$，**試說明它對每個實數 $t$ 的值均不小於零，並把它展開為 $At^{2}+Bt+C$ 的形式**，以 $a_1$、$a_2$、$b_1$、$b_2$ 表示 $A$、$B$、$C$。

（`**` 所标注的部分属过度引导——在给完一个提示点后又进一步对该提示点进行方法上的指导；此内容原本是留给学生完成的，要么删掉，要么出成独立的分题。）
```

- **提示**：用于给学生提供解题方法与思路，行文风格同样保持克制、极简、点到为止。

```提示的示例与反例
例1 证明质数有无穷多个。（提示：利用反证法以及考虑 $p_1 p_2 \cdots p_n +1$，其中 $p_i$ 均为质数。）
```

**何时可以给引导与提示**：

- **引导**：
  - 需要引用前文、前分题的结论。
  - 该题的解法需要引用一些定理、公式或性质；在不提示这些定理、公式或性质的情况下，题目会产生较大的思维壁垒，导致考生面临超纲的、没有学习过的技巧或红线技巧。
  - **考核点落在讲义冷门引理／注记细节时**（2026-09-29 新增）：题面应点名所用引理；凡指代引理中「某一式」者，须以引理名明确指代或写出该式，不得悬空（真实例：Ch20 题 13(a) 改后文「並就引理（三點共線的距離刻畫）的三式指出哪一式取等號」）。
- **提示**：
  - 题目的标准解答中出现相对困难的步骤，该步骤思维壁垒大、对该阶段的学生而言超纲，此时需要给提示降低思维壁垒。
  - 题目的标准解答中使用了红线技巧，已超过现阶段学生所掌握的方法与技巧范畴，需要给提示指导学生。

### 4.4 分题与题干规范

> 下列每条规范均附 **✅ 正例** 与 **❌ 反例**（以代码块给出），正例为正确写法、反例为应避免的错误写法。

- **结构化分题的考核目标**：复杂问题通过结构化分题分解——前分题为后分题铺设台阶（前分结论是后分题的工具），引导学生逐步深入；前面的分题可直接套用基本概念，后续分题在其基础上综合运用。

```
✅ 正例（真實題：Ch27 題 26）
（主題干）設 $a$ 為常數。考慮方程 $\log_{3}(x^{2}-2x+3)=a$。
(a) 當 $a=1$ 時，解方程。（直套定義法，屬基本概念）
(b) 求使方程有實數解的 $a$ 之取值範圍。（須把 (a) 的「定義法 ↔ 指數式」推廣到任意 $a$，再疊加值域條件）

❌ 反例：整題只問「求使 $\log_{3}(x^{2}-2x+3)=a$ 有實數解的 $a$ 之取值範圍」——不給任何台階（学生須自發想到定義法＋配方定值域兩層）
```

- **分题间需具有联动性、引导性或目的性，不可无故分题**：每个分题之间应设计成一般难做、唯有借助前几个分题的结论才易解的形式；跨题引用须显式标注（见下「跨题引用」条）

```
✅ 正例（真實題：Ch27 題 45）
(a) 解方程 $\tan^{2}\theta-4\tan\theta+3=0$，其中 $0^{\circ}\le\theta<360^{\circ}$，答案須準確至小數後一位。
(b) 就同一方程：(ii) 由此求方程在 $0^{\circ}\le\theta<720^{\circ}$ 內解的個數。（必須綜合 (a) 的四支解與 (b)(i) 的平移結論才數得對）

❌ 反例（真實題 Ch26 題 29 (a) 的形態硬拆為兩問）
(a)(i) 寫出 $f(\theta)=3\sin(2\theta+60^{\circ})-1$ 的振幅；(a)(ii) 寫出其最小正週期。
（兩問均對照參數直讀、互不依存，應合併為一問（「寫出振幅、最小正週期、相位平移與垂直平移」）或改作 task 項）
```

- **i,ii 小分题的使用建议**：通常情况下，由分题引入小分题时，需满足下列任意一个条件：
	- 在该层引入题干未给的新条件。
	- 该分题的提问点有多个，此时将其每个提问点分别拆成小分题。

```
✅ 正例（條件①：該層引入題干未給的新對象；真實題：Ch27 題 26）
（題干）設 $a$ 為常數。考慮方程 $\log_{3}(x^{2}-2x+3)=a$。
(b) 求使方程有實數解的 $a$ 之取值範圍。
    (i) 利用配方法，求 $x^{2}-2x+3$ 的最小值。
    (ii) 由此求 $a$ 的取值範圍。
（(b)(i) 處理干未提的新對象「二次式最小值」；(b)(ii) 綜合其值域 $[2,+\infty)$ 與 $3^{a}\ge2$ 才得結論。末級四維：(b)(i) T C+｜C C｜E C｜Q C；(b)(ii) T B-｜C C+｜E C+｜Q C+——思維量跨一檔半，非同質重複）

❌ 反例：(b)(i) 求 $x^{2}-2x+3$ 的最小值；(b)(ii) 求 $x=1$ 時 $x^{2}-2x+3$ 的值
（(ii) 只把已配方結果代一次，T D／C D——觸本節「過細」量化標準，且與 (i) 無思維量跨度，應合併為一問）
```

**條件②：該分題提問點有多個：**

```
✅ 正例（真實題：Ch27 題 45）
（題干）考慮方程 $\tan^{2}\theta-4\tan\theta+3=0$，其中 $0^{\circ}\le\theta<360^{\circ}$。
(b) 就同一方程：
    (i) 解釋何以若 $\theta_{0}$ 是解，則 $\theta_{0}+180^{\circ}$ 必也是解。
    (ii) 由此求方程在 $0^{\circ}\le\theta<720^{\circ}$ 內解的個數。
（兩個提問點——週期性論證 與 去重計數——各自成套、答案互不覆蓋，故拆；末級四維 (b)(i) T C+｜C C-｜E C｜Q C+、(b)(ii) T B-｜C C｜E C｜Q C+，無末級落 T／C 的 D 檔）

❌ 反例：(b)(i) 求 $\tan\theta=1$ 在範圍內的解；(b)(ii) 求 $\tan\theta=3$ 在範圍內的解
（兩支均為「查一個角＋對稱寫兩值」的單步操作，T D／C D，提問點同質無跨度——同一指令下的並列項應改作 task 項或合併為一問）
```

- **小分题打标联动**：无论基于何种理由拆分，每个小分题 (b)(i)(ii) 均须独立标注四维难度与逐维判定理由，父分题层不单设标记（详见 7.3、7.4、附录 A.4）。

- **题干与答案必须自洽**：发现矛盾须同步改题面与答案，不得只改其一；出题后逐题验算数据（如 HCF 须整除两者、余式条件须满足所有代入值）。
	- **错误分层：
		- 数据/数值类错误（验算不符、数值矛盾）可自行修正并记入修订记录；
		- 题目的逻辑错误（概念/条件/结构/命题逻辑类问题）不得擅改，须报告用户并提供修改方案，经审批后执行**

```
✅ 正例（數據互相咬合；真實題：Ch16 題 19）
（題干）設 $U=\{1,2,3,4,5,6,7\}$，$A=\{2,3,5,7\}$（即 $U$ 中的質數）。
(a) 求 $A^{c}$。（$\{1,4,6\}$）
(b) 驗證 $A\cup A^{c}=U$ 與 $A\cap A^{c}=\varnothing$。
（三處數據互相制約：$A\subseteq U$、$A^{c}$ 由 $U\setminus A$ 唯一定出、並集回填必須等於 $U$——改 $U$ 或改 $A$ 任一數字，(b) 即失效）

❌ 反例（同型缺陷的實際形態）：把題干的 $U$ 改為 $\{1,2,\dots,6\}$ 而解答仍寫 $A=\{2,3,5,7\}$、$A\cup A^{c}=U$——$7\notin U$，並集不等於全集，題面與答案矛盾。
（「題干寫 $a=3$、答案寫 $a=4$」式的單點筆誤由逐題驗算（解答代回題干核對）拦截，不具示範價值）

錯誤分層在此例的落點：$7\notin U$ 屬**數據類**（改 $U$ 或自 $A$ 刪 $7$ 即可，可自行修正並記修訂記錄）；若把 $A^{c}$ 的定義本身寫成「$U$ 中非質數的偶數」則屬**邏輯類**，須報用戶並附修改方案後才改。
```

- **数值答案必须简洁**：所有数值答案必须保证尽可能为整数或者简洁的分数，以下情况可豁免该原则：
	- 涉及无理数或循环小数的数值表达；
	- 概率或统计问题（按该领域表达习惯，百分数/小数/分数均可）。
	
	**凡涉及四舍五入的答案，题干统一注明「答案須取三位有效數字」**

```
✅ 正例（精確符號入題，真實寫法：Ch26 題 2／題 3）
$\dfrac{540^{\circ}}{\pi}$（精确值保留 $\pi$）；如需小数則题干已注明「答案須取三位有效數字」→ $172^{\circ}$。
$1^{\circ}=\dfrac{\pi}{180}\text{ rad}$（不寫小數展開）。

❌ 反例：答案寫 $0.0174532925\ldots$ 或 $171.8873385^{\circ}$
（無意義長小數：應以 $\dfrac{\pi}{180}$ 等精確符號入解答，或按题干注明取三位有效數字）
```


- **题干不提示解题方法**（不写「利用…」「以…方法」「同乘LCM」等），配方法除外（见 4.5 备注）；**允许给提示的两种情况**：① 起步过程很难——学生难以自行想到从何下手；② 讲义中未明讲、但以当前技巧完全可以直接学会的新技巧（如换元法解分式方程组，题干可给「設 $u=\dfrac{1}{x}$，$v=\dfrac{1}{y}$」提示）；**元程序要求与分类算法同属方法提示**（2026-09-29 新增）——「先写出…再选出一种…并说明其余为何不便」式的操作编排、「解方程组并就解的个数说明」式的算法交出均违规，题面只问数学任务本身

```
✅ 正例（真實題：Ch27 題 1 (g)）解方程 $2^{3x+1}=2^{2(x+3)}$。（不提示方法——同底法由講義 27.1.1 建立，題面不写「化成同底」）

✅ 正例（允許提示）：解方程組 $\begin{cases} \dfrac{1}{x}+\dfrac{1}{y}=5 \\ \dfrac{2}{x}-\dfrac{1}{y}=1 \end{cases}$（提示：設 $u=\dfrac{1}{x}$，$v=\dfrac{1}{y}$）——換元起步難、講義未明講，屬允許提示的②類

❌ 反例：解方程 $2^{3x+1}=2^{2(x+3)}$（提示：兩邊同除以 $2^{2x}$ 後比較指數）（直接暴露變形路徑）；又如「同乘最小公倍數後化簡……」
❌ 反例（真实例：Ch20 题 26 旧文）：解下列各聯立方程組，並就解的個數說明兩直線的位置關係（把「解聯立→數解→翻譯」的算法整个交出）；改为「判斷下列每對直線的位置關係。」
❌ 反例（真实例：Ch20 题 14 旧文）：先寫出四種說法各自的數學表達，再選出一種計算量最少且能覆蓋鉛垂線情形者完成判斷，並說明其餘三種為何不便（元程序堆叠）；改为「判斷 $P$ 是否在 $A$、$B$ 所確定的直線上，並解釋你的答案。」
```

- **跨题引用（不同题号）须题干显式标注「利用第 X 题的结果」**；同题内用「由此」/「利用 (a)」

```
✅ 正例（真實題：Ch08 正文「理論習題」節，L3209 題 95 (a)）
在直角 $\triangle ABC$ 中，$\angle ACB = 90\degree$，$\angle BAC = 30\degree$。延長 $BC$ 至 $D$，使 $CD=CB$，連接 $AD$。已知 $AB=8\text{ cm}$。
    (a) 利用第 93 題的結果求 $BC$。    % ← 跨題引用寫明顯式题號，可回溯

❌ 反例：同上題面寫成「(a) 求 $BC$。」却实际依赖第 93 題結論（读者与阅卷者无法追溯依据；若第 93 題未做则整题连撞）
```

#### 4.5.2 文字表达规范

- 定理标题不加「证明」「推导」；
- 对于**明确要求以配方法完成**的题目，题干**必须**使用「利用配方法，…」句式
- **题面任务用语一律「因式分解」**：不用「完全分解」「分解」等表述

```

❌ 反例：完全分解 $x^4-5x^2+4$；分解 $x^4-5x^2+4$（「完全分解」「分解」用词不合规范）
```

- **證明類題的起始句式一律寫「證明…」**（2026-09-24 新增）：不得寫「求證…」「求證：…」「證明：…」——既不另用「求證」一詞，也不在「證明」後加冒號；同一題各分題（含小分題）句式一律統一。

```
✅ 正例（Ch29 題 2(a)）：(a) 證明 $AB=CD$。
✅ 正例（Ch29 題 55(b)）：(b) 就 (a) 證明圓 $C(O,r)$ 的兩條弦等長 $\iff$ 兩弦的弦心距相等。
❌ 反例（Ch29 題 2(a)）：(a) 求證 $AB=CD$。（另用「求證」一詞）
❌ 反例（Ch29 題 55(b)）：(b) 就 (a) 證明：圓 $C(O,r)$ 的兩條弦等長 $\iff$ 兩弦的弦心距相等。（「證明」後加冒號）
```

- **宣稱判斷題的宣稱內容必須是陳述句**（2026-09-24 新增；同日經用戶補正「多個獨立陳述句可行」）：宣稱只直陳事實——可含「若…則…」「…時」等條件成分，**亦可由多個互相獨立的陳述句並列**（各句各自成一個可判斷真假的斷言，不含彼此推導關係）；不得寫成推理鏈（「由…可得…，故…」）、疑問句、祈使句或夾帶解題指引的複句——推理與辨析一律留給學生。

```
✅ 正例（Ch29 題 11(b)，改後）：(b) 某人宣稱「$CA$ 也平分 $\angle BCD$。」你是否同意？試解釋你的答案。
✅ 正例（Ch29 題 43）：某人宣稱「三角形的外心到三邊的距離相等，內心到三個頂點的距離相等。」該宣稱是否正確？（**兩個互相獨立的陳述句並列**，屬可行範圍——用戶 2026-09-24 裁定「这类不算，这种算多个独立的陈述句。仍然属可行范围。」）
✅ 正例（Ch29 題 3）：某人宣稱「圓心角增大為原來的 $2$ 倍時，它所對的弦也增大為原來的 $2$ 倍。」試求圓心角 $90^\circ$ 與 $180^\circ$ 所對的弦長，並判斷該宣稱是否正確，解釋你的答案。（條件成分屬陳述內容）
❌ 反例（Ch29 題 11(b)，改前）：(b) 某人宣稱「由 $\angle BAC=\angle DAC$ 可得 $\angle ACB=\angle ACD$，故 $CA$ 也平分 $\angle BCD$。」你是否同意？試解釋你的答案。（宣稱為「由…可得…，故…」的推理複句，把待辨析的推理步驟直接寫進宣稱）
```

- **不使用「由此說明…」的問法**（2026-09-24 新增）：凡要求學生就前述結果作論證者，一律改用「證明…」「由此證明…」等以證明為起始的句式；「說明」只保留於真正的解釋性要求（如「試解釋你的答案」「並說明理由」中的理由說明）。

```
✅ 正例（Ch29 題 52(b)，改後）：(b) 證明 $PT=2PQ$，並由此證明 $\Gamma_{1}$ 中與 $\Gamma_{2}$ 相切的弦長恆為 $2\sqrt{R^{2}-r^{2}}$。
❌ 反例（Ch29 題 52(b)，改前）：(b) 求證 $PT=2PQ$，並由此說明 $\Gamma_{1}$ 中與 $\Gamma_{2}$ 相切的弦長恆為 $2\sqrt{R^{2}-r^{2}}$。（同一分題「求證」與「由此說明」混用，且第二問實為證明）
```

- **分题不以「問」字起头**（2026-09-29 新增）：疑问一律写成疑问句并以问号结尾，不以「問」「又問」「另問」引出发问；「判断是否…」式陈述句亦可。

```

```

```
❌ 反例（真实例：Ch20 题 29(a) 旧文）：求使 $L_1$ 與 $L_2$ 的斜率相等的 $a$ 的全部值，並就每個值判斷兩直線的位置關係。
✅ 更正（真实例：Ch20 题 29(a) 改后文）：求 $a$ 使 $L_1$ 與 $L_2$ 的斜率相等，並判斷兩直線的位置關係。
```

- **宣称判断题尾句统一与验证提醒之禁**（2026-09-29 新增）：尾句一律「該宣稱是否正確？試解釋你的答案。」（判断＋证明型「判斷…並證明你的答案」不在此限）；不得指定验证对象或验证方法（「試就…判斷」「試以…檢驗」「試計算兩者」「試逐段計算」均删），如何验证由学生自行决定。

```
❌ 反例（真实例：Ch20 题 17 旧文）：該宣稱是否正確？試就 $L:2x-3y-12=0$ 的兩個截距判斷，並解釋你的答案。
✅ 更正（真实例：Ch20 题 17 改后文）：該宣稱是否正確？試解釋你的答案。（反例直线由解答自行构造）
```

- **除非刻意考核形式，不要求答案的表达方式**（2026-09-29 新增）：「並化為一般式」「把答案寫成 $x$ 的係數取正、三個係數無公因數的一般式」类指令一律删——默认化为最简，数学等价的形式皆可接受；**中间形式只作解题方法、不作交付物**（如 Ch20 点斜式／两点式只作立式方法，最终表示只接受一般式与斜截式）；刻意考核形式转换与系数特征者除外（真实例外：Ch20 题 18 惯用一般式、题 24(a) 退化系数特征、题 25／46 截距式）。

```
❌ 反例（真实例：Ch20 题 20(a) 旧文）：以點斜式寫出 $L$ 的方程，並化為一般式。
✅ 更正（真实例：Ch20 题 20(a) 改后文）：求 $L$ 的方程。（解答仍可以点斜式立式——方法不限，交付不锁形式）
```

- **「位置關係」「形狀」等开放式名词提问的限定**（2026-09-29 新增，承 Ch29「切线辨析一律问『是否为切线』」裁定）：仅作讲义已建立分类集的分类任务使用（两线位置关系＝相交／平行／重合等）；**关系已由题面前提显明者不得问**（空转），改问可计算的量或具体关系。

```
❌ 反例（真实例：Ch20 题 27(b) 旧文）：三線共點前提下「指出 $L_3$ 與 $L_2$ 的位置關係及它們的公共點」——共点已使「相交于该点」显明；整段删，只留「求 $k$」

## 五、.tex 文件题号与排版

### 5.1 题目标记框
为方便快速定位某些具有特殊性质的题目，在 LaTeX 正文文件中提供标记框环境。每道题必居且仅居以下四种状态之一：

| 框色 | 环境 | 判据（一句话） |
|------|------|---------------|
| **蓝框** | `recquestion` | 考纲内 ＋ 至少一维 C+~B+ ＋ 无 A-/A/A+ 维 |
| **红框** | `ofsquestion` | 考纲外 ＋ 讲义覆盖 ＋ 关联分析文件检索确认 |
| **黑框** | `exquestion` | 讲义为基础 ＋ 题面给出新概念/新名词 ＋ 在其下探索性解释/证明（纯证明公式不算） |
| **无框** | 裸 `\item` | 太基础（无维达 C+）或 高难度有 A-/A/A+ 维但不超纲无探索 |

**规划文件中每题在「標記框」checkbox 勾選歸屬（恰勾一項，見 3.2 模板）——標記框不寫在題目標題上，直接勾選，方便隨時更改；正文 .tex 落框以此勾選為準**；规划文件头部「框色边界」一节保留为逐类汇总声明（含无框类），须与各题勾选一致。

**判定总则（三步，动态判定，不可机械套用）：**

① **内容范围**：查课题是否在 DSE 官方考纲中（见〇章考纲目录）。考纲内 → 蓝框或无框候选；考纲外 → 红框候选（须讲义覆盖，否则不得出题）。**蓝框的标准完全基于 DSE 官方考纲，与课题讲义无关**。**表述方式亦属内容范围**：题面以考纲未采用的视角/语言出题，即使数学本质对应考纲内课题，仍按考纲外处理（如集合论表述的直线方程题 → 红框；若属太基础批量操练 → 可标无框）。

② **红框检索（仅红框候选执行）**：检索《官方考纲与课题讲义关联分析.md》对应课题章节的「2. 超纲知识点分析」，确认题目所涉知识点有超纲条目标签（六类：【完全超纲】/【增润课题】/【延伸部分】/【非基础课题】/【提前教授】/【深度超出】）支持，并在规划文件「框色边界」声明中逐题引用条目。检索不到支持条目 → 不得标红框，回到①按考纲内重新判定。

③ **难度档次**：按四维难度标记判断——「与真题相近（适宜操练）」＝题级总难度至少一维 C+~B+（含）、无 A-/A/A+ 维；低于此（无任何维达 C+）→ 无框第一类（太基础）；出现 A-/A/A+ 维 → 无框第二类（高难度，非探索时）；探索型（题面给出新概念/新名词并须在其下作探索性解释或证明；单纯用讲义既有工具证明公式、推导恒等式不算黑框）→ 黑框。真题库 `Combined_P1.tex`（见〇章）用于横向对比：真考查过的同型题是「考纲内、难度可对标」的直接佐证。

**下文示例仅示范判定过程，不可机械套用**——示例中的框色结论只对该示例所在课题成立；判定的唯一依据是：官方考纲 ＋ 蓝框量化难度判据 ＋ 课题讲义（红/黑框的内容来源）＋ 四维难度标记。

#### 5.1.1 蓝框 `recquestion` —— 常规 DSE（适宜日常操练）

- **性质**：课题出现在 **DSE 官方考纲**内（**与课题讲义无关**）；难度符合**蓝框量化难度判据**：题级总难度**至少一个维度位于 C+ 至 B+（含）区间**、且**无任何维度达到 A-/A/A+**——既不属显著低于真题的过基础题（无任何维度达到 C+），也不属显著高于真题的高难度题（出现 A-/A 档维）；适合大多数 DSE 考生作为平日功课与练习。
- **使用场景**：考纲内课题的常规操练、标准题型计算与证明（如 Ch19 §6 函数变换全部——课题在考纲内且难度与真题相近；Ch18 因式分解法解方程、Ch07 百分法常规应用题）。

### 6.4 难度标记环境 `difficulty`（.tex 答案文件）

- **難度標記環境 `difficulty`（強制，每個分題、每個小分題與整題都須標，且各維附詳細理由）**：
  - **例外**：task 类题目只标整题一个总体 `difficulty` 标记，不标每个分题**（批量、机械化，各项共用同一判准）；判定理由亦统一概括整体（引用「各项共用同一规则、同类计算重复 N 项、重复不抬档」等整体依据），不逐项给理由；
  - **每個分題的答案結束後**，立即以 `\begin{difficulty}...\end{difficulty}` 居中顯示該分題的四維難度標記（灰色小字），寫全中文名，格式 `思維量（T）B+ ｜ 計算量（C）B ｜ 探索性（E）C ｜ 跨課題（Q）B`；
  - **小分題同樣獨立打标**：分題再拆 (b)(i)(ii) 小分題時，**每個小分題的答案結束後**各標一個 `difficulty` 環境（四維檔位＋逐維判定理由，格式同上），父分題 (b) 層不設單獨 `difficulty`——難度標記只出現在末級；
  - **整題所有分題的答案都結束後**，最後再以一個 `difficulty` 環境標記**整題總難度**（取各分題、小分題各維最大值）；
  - **每個 `difficulty` 環境內，除四維檔位外，每一維都必須附一條詳細的判定理由**：引用該分題／小分題／整題解答的具體環節——推理鏈步數與各步內容、運算類型與步數、構造反例／矛盾源的步驟、動用的跨課題工具；不得只寫檔位、不得把各維合為一條籠統理由。

```
\begin{difficulty}
    \textbf{難度}：思維量（T）B+ ｜ 計算量（C）B ｜ 探索性（E）C ｜ 跨課題（Q）B

    判定理由（T）：解答需「定刻度→套範圍公式→驗證端點開閉」三步，鏈長 2–3 步。
    判定理由（C）：小數加減。
    判定理由（E）：須自行建立範圍模型並驗證端點，方法選擇層。
    判定理由（Q）：估算單課題。
\end{difficulty}
```

### 7.2 四维评分体系

- **四维独立评分，不合成总分**：T 思维量（推理负担）｜C 计算量（代数复杂度）｜E 探索性（自主探究深度）｜Q 跨课题（跨板块/课题广度）；每维 D/C/B/A 带 ±，共 12 档。
- **T 维计步公约**：链长之「步」只计**异质概念环节**（建模翻译、取交集判空、含参端点反推、整数筛选、构造反例、分类讨论、反证、量词否定、等价性论证）；同一概念之连续执行（逐项解同型不等式、逐点代入检验、逐顶点算目标值）依 C 维「数量叠加仅加半级」判据**不计入链长**。速查表「四步且步步顺承→B- 为下限」仅在四步皆属异质环节时适用；`task` 批量、逐句文字翻译建模、纯代值比较类分题 T 以 C／D+ 为上限，项数不得抬档。
- **Q 维实际调用口径**：仅当解答确实调用其他课题的独立操作才计数；「承接前一问结论」与「本章已建立之语言与算法」（不等式变形、区间与解集记号、本章定义）不另计课题；跨板块 B- 须实际解出他板块对象（如解边界直线与两直线交点），仅以题面给定顶点代入者记 C。

### 7.2.1 超纲思想方法红线

红线所禁的不是该节内容、也不是该类技巧，而是「**在不提示的情况下**要求学生自己想出它」。这类思想方法分为五类：

1. **讲义中没有教过的方法**（如例 ④ 参数化构造、⑦ 自补引理、⑩ 以未引入概念入手、⑫ 自造一般性结论作依据）。
2. **讲义中使用了但没有正式介绍引入的方法**（如例 ① ε／δ 存在性选取、② 上确界论证、③ 否定量词证无界、⑤ 有限集取最小者、⑥ 双向包含之分类穷尽、⑧ 定义之多层次纯符号展开）。
3. **讲义有涉及，但是极具深度、取自更高等数学的技巧与内容**（如例 ①、②、③、⑧）。
4. **反证法、逆否命题等基于数理逻辑的高阶证明技巧**（如例 ⑪）。
5. **在该题目需要注意到的独特复杂结构，或是复杂的构造方法**（如例 ④ 参数化构造、⑨ 未引导的复杂结构）。

这类方法须在**给足引导或提示**后才可使用；「引导」与「提示」两词被单独赋予不同定义（见 4.3「引导与提示方法」），须作区别；「设…为中点，先看…能推出什么」这类属**过渡提示与引导**；引导与提示的写法与可给时机亦见 4.3。

**举例（数量不限、非穷尽清单）**：下列各例为以往命题中实际遇到过的红线手法，每例写明**典型形态**与**处置**（即须以何种引导或提示交出该手法）；遇同类新手法时按上列五类归入，并照本节规则处理。

- ① **ε／δ 式「取充分小者、取一半」的存在性选取**（第 2、3 类）
	- 典型形态：论证须自行安排「先取一个充分小的量、再据它比较两值」的步骤，如「取充分小的 $h$，使 $f(x_0+h)$ 与 $f(x_0)$ 同号」，或「取 $\delta=\min\{1,\ \varepsilon/2\}$」。
	- 处置：属讲义未正式建立的深度内容；确需此类论证时（如增润节的有界性、最值存在性判别），须以分题台阶交出取法的顺序（「先取…，再看…的符号」），或于题干末以（提示：…）给出取法；未给引导即判错题。

- ② **上确界、下确界与完备性论证**（第 2、3 类）
	- 典型形态：以「该集合有上界，故必有最小上界」作为存在性依据，或以实数的完备性解释某取值可达。
	- 处置：讲义未建立该工具，须改写为以题干给出的端点、边界或具体构造直接判定；无法改写则换题。

- ③ **否定量词证无界**（第 2、3 类）
	- 典型形态：证明「无上界／无下界」时，须自行写出量词的否定（「对任意 $M$，都存在 $x$ 使 $f(x)>M$」）并据以取值验证。
	- 处置：先以分题给出否命题的式样，再让分题只做取值与验证；不给式样而要求学生自写量词否定者判红线。

- ④ **以 $(1-t)P_{1}+tP_{2}$ 参数化任意点**（第 1、5 类）
	- 典型形态：处理线段或区域上的「任意点」时，须自行引入参数 $t\in[0,1]$，把任意点写成 $(1-t)P_{1}+tP_{2}$，再求极值或证恒成立。
	- 处置：参数化对象与范围须由题干（分题台阶）交出——「设 $P$ 为该线段上任意一点，记 $P=(1-t)P_{1}+tP_{2}$，其中 $0\le t\le 1$」；由学生自想构造者判红线。

- ⑤ **有限集取最小者**（第 2 类）
	- 典型形态：于整数或格点集合中自行挑出「使某量最小」的元素，再据其建立不等式或导出矛盾。
	- 处置：讲义只在个别示例中出现过该做法、未作一般方法介绍；须以分题引导（「先取使…最小的那个元素，再看它能推出什么」）。

- ⑥ **双向包含之分类穷尽**（第 2 类）
	- 典型形态：证明两集合相等时，须自行组织「$A\subseteq B$ 且 $B\subseteq A$」两向并逐类穷尽。
	- 处置：把两向拆作分题（(a) 证 $A\subseteq B$；(b) 证 $B\subseteq A$）即为充足引导；不给台阶而要求学生自想双向法者判红线。

- ⑦ **自补引理**（第 1 类）
	- 典型形态：须自行拟出「某集合与其补集的交、并关系」型引理，并以它作后续推理的支点。
	- 处置：该引理须在题干给出，或以分题先证明；不得要求学生自拟并自证。

- ⑧ **定义之多层次纯符号展开**（第 2、3 类）
	- 典型形态：把一个定义连续展开数层后作纯符号推理（如把「有界」「连续」的定义嵌套展开再作比较）。
	- 处置：须给出台阶或提示；即便已给足，也**不得**据此把 T／E 档位上抬。

- ⑨ **「注意到未引导的复杂结构」**（第 5 类）
	- 典型形态：解法的关键落在某个未加提示的特殊结构上——自选反例的取值、自拟辅助构造式、自想到放缩方向、自发现可配对或对称的项。
	- 处置：该结构须由题干或分题明示（「注意到…」「试比较…」「先将…分组」）；若「注意到」这一步只能靠学生自悟，判错题。

- ⑩ **以未引入概念入手**（第 1 类；引导充足时正当使用）
	- 典型形态：解答须自行引入讲义未建立的记号或工具——同余记号 $a\equiv b\pmod m$、判别式 $B^{2}-4C$（属后续章节）、对因式分解讨论「系数范围／域」等。
	- 处置：一律改用讲义已建立的方法重写；无法改写则整题替换，**不得**以新概念充当简捷解法。

- ⑪ **反证法、逆否命题的自发使用**（第 4 类）
	- 典型形态：结论以反证法最省力，须学生自行构造反证的对象（如证明「质数有无穷多个」而自造 $p_{1}p_{2}\cdots p_{n}+1$），或须自行写出命题的逆否形式再论证。
	- 处置：于题干给出构造对象与构造式——如 4.3 提示示例「（提示：利用反证法以及考虑 $p_{1}p_{2}\cdots p_{n}+1$，其中 $p_{i}$ 均为质数。）」；不给提示而要求学生自想构造者判错题。

- ⑫ **自造一般性结论充作依据**（第 1 类）
	- 典型形态：把个别观察直接当作一般命题使用（如以「三个连续整数之积必含因子 2 与 3」作整除性论证的依据），而讲义并无该结论。
	- 处置：改以讲义已建立的条目论证（整除的定义、除法性质、线性组合性质等）；不能改写即整题替换。


**未给充足引导者判为错题**，须补引导或改用讲义已建之通用方法重写／换题；此类手法一律**不得作为 T／E 维的抬档依据**，档位只按「剔除超纲手法后、学生在引导下可及之作答」评定。**增润节内容（如 Ch28 §28.3.3 有界性、闭性与最值存在性判别）照常出题，属必出考点。**

### 7.3 打标流程

- **打标流程**：读题 → 写出完整答案 → 定主体级 → 按判据速查表调 ± → **每个分题与每个小分题独立打标并附判定理由**（每个维度各附一条明确、详实的判定理由，不可合为一条笼统理由；分题再拆 i,ii 小分题时，每个小分题单独标完整四维并附逐维理由，父分题层不设标记行）→ 大题总难度 = 各分题、小分题各维最大值（用于排序），只需注明「取各分题最大值」。
- **判定理由须与解答内容一致**：判定理由中自述的步数、所用手法、所引课题必须与「详细解答」逐项相符；理由称「无展开运算」而解答实有多层符号展开者属判定理由与解答不符，须改正。
### 7.4 难度标记显示位置（三份文件分工）

**三份文件分工總則（先讀此表，再看各子節）**：

| 文件 | 是否顯示難度 | 承載內容 | 細則 |
| --- | --- | --- | --- |
| 規劃 .md | 顯示 | 題面全文與四維檔位、逐維判定理由的**唯一權威來源**；（小）分題各標一次，大題末標總標記 | 7.4.1 |
| 正文 .tex（題目檔） | **不顯示** | 面向學生，不暴露難度；題號連續與標記框一律以規劃勾選為準 | 7.4.2 |
| 答案 .tex | 顯示 | 末級（分題／小分題）解答結束後**即時**各標一個 `difficulty`；大題末標總標記 | 7.4.3 |

  - **每个分题与每个小分题都要标对应的四维难度与判定理由**（分题拆出 (b)(i)(ii) 时，每个小分题独立打标，父层 (b) 不单设标记行）；大题总难度不需要说明判定理由，只需注明「取各分题最大值」；

#### 7.4.1 Markdown 規劃文檔（.md）

  - 规划文件（.md）：每个分题标四维标记 + 逐维判定理由（每维一行）；大题末标总标记，只需注明「取各分题最大值」。分题格式：`分題 (a)｜難度：**T C｜C D｜E C｜Q D**`，下方 `> 判定理由（T）：...` 等四行；小分题同样独立打标，标记行编号作 `分題 (b)(i)｜難度：**T C｜C D｜E C｜Q D**`（下方同样逐维理由四行），父分题 (b) 层不设标记行；大题格式：`> 题 N｜难度：**T ...｜C ...｜E ...｜Q ...**（取各分题最大值）`；

```
> 分題 (a)｜難度：**T C｜C D｜E C｜Q D**
> 
> 判定理由（T）：……
> 
> 判定理由（C）：……
> 
> 判定理由（E）：……
> 
> 判定理由（Q）：……

> 題 N｜難度：**T B-｜C C｜E C｜Q D**（取各分題最大值）
```
  - **算式與文字排版**：.md「詳細解答」的算式與文字排版依 **6.3.3／6.3.4** 執行——多步變形鏈以 `$\begin{aligned}[t]…\end{aligned}$` 每步一行並逐步附依據，`$\implies$` 開頭句單獨成行，文字段落以空行分隔（禁 `\\`），證明結束不加記號；.md 直接寫 `aligned` 環境為允許寫法（`check_norm_md.py` 已放寬該項禁令），逐行行內式亦可用；
  - **管線提示**：由規劃 .md 生成 .tex 的管線（各章一次性腳本）須能原樣搬運 `aligned` 區塊，不得把環境內的每一行當作獨立段落輸出。

#### 7.4.2 正文 .tex（題目檔）

  - 习题册（.tex 题目文件）：**不显示**难度标记（面向学生，不暴露难度）；題號連續用 `series=mainlist`／`resume*=mainlist`，標記框環境以規劃「標記框」勾選為準（見 5.1.5）。

#### 7.4.3 答案 .tex（顯示）

  - **標記位置（強制）**：該末級分題／小分題解答結束後**即時**標 `difficulty`，大題總標置於全題解答與主圖之後；把多枚標記堆在題末屬違規（Ch08 舊答案即因此錯位）；
  - **標記內容**：末級標一律附四行判定理由（見 6.4）；大題總標只寫四維檔位＋「（取各分題最大值）」，不附理由；
  - **task 類與無結構題**：只標整題一標（附四行理由，不加取最大值括號注）；
  - **歷史例外**：Ch26 答案為精簡風格（`difficulty` 只有檔位一行、易錯寫成段落），Ch27 起已恢復規範樣式，新章不得照搬 Ch26。
  - 答案（.tex 答案文件）：每个分题或小分题答案结束后用 `difficulty` 環境標該（小）分題四維標記與逐維判定理由，寫全中文名 `思維量（T）C ｜ 計算量（C）D ｜ 探索性（E）C ｜ 跨課題（Q）D`（小分题独立标，父分题层不设单独 `difficulty`）；大题答案结束后標總標記（取各（小）分题各维最大值）；

```
# 每个分题答案结束后，各标一个 difficulty（四维档位 + 逐维理由）

\item (a) ……分題解答……

\begin{difficulty}
    \textbf{難度}：思維量（T）C ｜ 計算量（C）D ｜ 探索性（E）C ｜ 跨課題（Q）D

    判定理由（T）：……
    
    判定理由（C）：……
    
    判定理由（E）：……
    
    判定理由（Q）：……
\end{difficulty}

\item (b) ……分題解答……

\begin{difficulty}
    \textbf{難度}：思維量（T）B- ｜ 計算量（C）C ｜ 探索性（E）C ｜ 跨課題（Q）D

    判定理由（T）：……
    
    判定理由（C）：……
    
    判定理由（E）：……
    
    判定理由（Q）：……
\end{difficulty}

# 大题答案结束后，最后再标一个总标记（只注明取各分题最大值）

    \textbf{難度}：思維量（T）B- ｜ 計算量（C）C ｜ 探索性（E）C ｜ 跨課題（Q）D（取各分題最大值）

```

  - **小分题（.tex）**：分題 (b) 含 (b)(i)(ii) 時，答案續用嵌套 enumerate，**每個小分題答案結束後**各標一個獨立 `difficulty` 環境（四維檔位＋逐維判定理由，格式同上）；父層 (b) 題頭及各小分題完成後均不設單獨 `difficulty`；大題總標記取全部分題／小分題標記的各維最大值。

### 7.5 排序与判定理由

- **排序（「难度线性递增」的量化）**：字典序 **T→C→Q→E**，同级按题号；章节内升序排列即「线性递增」。难度分布不设档位数量目标，仅保证递增。**宏观递增口径**：全章宏观趋势呈递增（D → C/C+ → B-/B/B+ → A-/A/A+）即达标；允许各节内 D 级基础 task 题穿插导致的局部回退（如 Q5 C → Q6 D、§7 内 B- 与 C+ 交错），无需因此重排题序。
- 每维判定理由须明确详实：**引用详细解答的具体环节**（推理链步数与各步内容、运算类型与步数、构造反例/矛盾源的步骤、动用的跨课题工具），说明该维主体级判定依据，注明「依赖前分题结论是否上浮」「± 的来由」；相似题引用判例、不重复打标。**大题总标记须严格取各分题与小分题各维最大值**（父分题不设标记，取值均来自末级；± 参与比较，机械无歧义）。
### 7.6 难度与框色统计表（强制）

**目的**：量化檢驗章節難度分布，防止整章偏易／偏難或檔位單一（如全章集中在 C 檔而幾乎無 B/A 檔）；為「難度線性遞增」的宏觀口徑與框色判定提供可核對的數據。

**統計方法**：
- 從規劃文件提取**題級總難度**（「`> 題 N｜難度`」行，即各分題／小分題四維最大值），按 T／C／E／Q 四維分別統計 D-／D／D+／C-／C／C+／B-／B／B+／A-／A／A+ 各檔計數；**不統計分題與小分題難度**（僅統計題目最終檔位與框色）；
- 框色統計：按各題「標記框」checkbox 勾選匯總（藍／紅／黑／無框計數），**並按章節分別統計各框色數量**，結果須與頭部「框色邊界」聲明一致；
- 可手動統計，或使用腳本（Ch21 先例：`.workbuddy/scripts/ch21_diff_stat.py`）。

**统计图表**：统计数据须转化为统计图表（四维分布柱状图／框色分布饼图等），统一存放于 `习题册草稿\统计图表\` 目录下，以 PNG 格式嵌入规划 Markdown 文档的「四、難度與框色統計表」板块中。图表生成脚本存放于 `.workbuddy\scripts\` 目录（Ch21 先例：`ch21_diff_stat.py`），可复用。


**產出（規劃文件必備板塊）**：在「三、題型結構規劃」之後新增「**四、難度與框色統計表**」板塊，包含：
1. **四維分布表**：題級總難度各檔計數（可附佔比）；
2. **按題號難度一覽**：題號＋四維總難度＋框色（便於核對難度排序與框色分布）；
3. **框色分布表**：藍／紅／黑／無框計數（按章節分別統計）；
4. **分布檢查結論**：①宏觀遞增（D → C/C+ → B-/B/B+）是否達標；②全章是否出現 B/A 檔題（綜合練習與理論習題承擔難度高峰）；③各檔是否過度集中——**B 檔與 C 檔各自佔比須 ≥ 30%**（統計以題級總難度為準，**題目任一維達到 B 檔（B-/B/B+）即計入 B 檔、任一維達到 C 檔（C-/C/C+）即計入 C 檔**，各自計數／全章總題數；B 或 C 任一佔比 < 30% 即視為「總體偏易」，須提升題目難度後重新統計）。

**使用時機**：規劃初稿完成時、任何難度調整後、提交用戶審批前必做；統計結果與檢查結論記入修訂記錄。

### 7.7 讲义节难度上限参考（强制）

> **定位**：課題講義每個 `##` 教學節（XX.X 級，如 23.1、23.2）標題正下方已標注「**本節難度上限**」四維評分行（格式 `> **本节难度上限**：T X ｜ C X ｜ E X ｜ Q X`，語義＝該節內容可支撐的題目難度上限，見姊妹文檔《課題講義寫作規範.md》4.6）。本章為其配套使用規範：**「各章小節」部分的題目難度以該節所標識的上限為上確界**。

- **適用範圍**：本節僅對規劃文件的**「各章小節」部分**生效；**「綜合練習」與「理論習題」部分不適用**（理論題/綜合題可自然突破節上限，不受此約束）；
- **對照依據**：唯一對照來源＝`DSE 課題講義/Chapter X 章名.md` 對應 `##` 節標題下的「本節難度上限」行（`###` 及以下不標、不作為對照粒度）；
- **上確界口徑**：「難度達到上限」的含義是——該節題目的四維難度**最高不突破**節上限（上確界：節內無題超過該檔），且**至少一題達到**該節上限檔位（上確界被取到）；即節上限是該節常規題的難度天花板，同時須有題目觸頂。**逐維口徑**：「不突破」＝節內每題的題級總難度各維均不超過節上限對應維；「達到」＝至少一題的題級總難度與節上限**逐維相同**（四維全等）；
- **節內難度梯度**：節上限是該節題目難度的**峰值錨點**，節內題目自基礎向峰值遞增佈局（配合 7.6 統計表的宏觀遞增檢查）；基礎批量 task 題（T D 級）為操練性質（見 4.4「基本解方程/基本運算題不拆細」與無框判定），不要求觸頂；
- **检查**：每节检查两条——①无题超过节上限（若超上限须降低难度或说明该题归属综合练习/理论习题部分）；②至少一题达到节上限（若全节未触顶，须提升至少一题至上限档）；
- **增润小节另立内容上限行**：讲义中自标「DSE 常规课程不作要求」「作为增润课题处理」「作答时不必写出论证」之 `###` 小节（如 Ch28 §28.1.4 含绝对值的不等式、§28.3.3 最优解的存在性），得于其标题下另立一行「本小节内容上限：T X｜C X｜E X｜Q X（增润）」。性质五条：①该行**不是** `##` 大节上限，不要求有题与之四维全同（**不参与触顶校验**）；②**增润小节之习题即以该行为上限，不受母节（大节）档位上限约束**，逐维只需不突破该行即可（增润课题本身不受母节档位上限的限制，不超过增润课题本身档位就行）；③大节上限仍按必修内容打标并以必修题触顶，增润题既不占用大节触顶、亦不以大节上限校验；④增润小节题目若涉及第四章／7.2.1「超纲思想方法红线」所列手法（ε／δ 存在性选取、上确界与完备性、否定量词、参数化构造、自补引理、注意到未引导之复杂结构等），**须在题面给足提示与引导**（分题台阶，或题干末以（提示：…）交出构造对象与构造式），且一律**不得以该类手法作为 T／E 抬档依据**；⑤**讲义该行只写档位本身**——依据、规范条款引用与口径说明一律不写进讲义，口径归本规范，越限复核归规划文件之「讲义节难度上限对照」板块。规划文件该板块须为增润小节单列一行，写明「本行为该节题目上限、不受母节约束、触顶豁免」。
- **檢查時機**：與 7.6 統計表同步執行（規劃初稿完成時、難度調整後、提交審批前）；檢查結論記入規劃文件「難度與框色統計表」板塊與修訂記錄。

## 八、超纲方法自检（强制流程）

**触发**：每章出题 / 改题 / 回填答案 / 详细解答升级时，必须执行。与「命题范围只取自讲义」原则配套——该原则管「概念/内容」层面的超纲，本环节补上「**方法**」层面的超纲。

**流程：**

1. **先读讲义**：通读本章讲义 + 全部前置章节讲义（**前置＝章號序在前的全部章節，含 Ch00**），列出已建立的「定义 / 定理 / 方法 / 技巧」清单；
2. **逐题核对**：题目答案中使用的每一种方法、定理、工具，必须在讲义中找到出处（本章讲义或前置章节讲义）；找不到出处即超纲；
3. **常见超纲陷阱（判例）**：
   - 「试除至 √n」平方根界限判断质数——讲义未教，超纲（Ch01 Q2）；正法为「完整测试法」或「合数等价条件定理：找分解式 $p=ab$」；
   - 「质因数分解取最低/最高次幂」求 gcd/lcm——讲义未教，超纲（Ch01 Q6/Q19）；正法为**短除法**（Ch00 核心技巧第 5 条：逐层提取公因数）或列因数/列倍数法；
   - 其他未见于讲义的速算法、口诀、技巧一律先查讲义再定；
4. **处理**：发现超纲 → 改写答案方法为讲义方法（不更动题目数据与考核方向）；若题目本身依赖超纲概念 → 不擅自改题，告知用户并提供选项；
5. **记录**：修訂記錄與日誌註明方法來源與判定（如「依 Ch00 核心技巧第 5 條」「講義未教，改為…」）。

## 九、TikZ 几何配图

### 9.1 Markdown 规划文档内规范

- Markdown 文件采用 Obsidian 加 TikZJax 插件预览。**代碼塊內容必須以 `\begin{document}` 開、`\end{document}` 結（` ```tikz ` 圍欄內依次為 `\begin{document}`、`\begin{tikzpicture}[scale=…]`、逐行命令、`\end{tikzpicture}`、`\end{document}`）——TikZJax 只渲染帶此外殼者，缺殼時預覽會顯示成原始文字**；本庫講義側插圖一律帶殼，可作對照；
- TikZJax 官方文档：<https://github.com/artisticat1/obsidian-tikzjax> ；
- 每道配图题，题干给出的信息必须足以独立还原配图。图只是展示，不承载题干未给的关键信息；
- **规划文件「配圖」要素的写法**：一律以結論詞起頭——需配圖寫 `**配圖**：有（一句話理由）`、其下空一行再附 TikZ 代碼塊（須帶上述 document 外殼方能在 Obsidian＋TikZJax 渲染）；不配圖題只寫 `**配圖**：無（簡述理由）`；**不得寫裸 `**配圖**` 而把理由直接續在下一段**；

### 9.2 配图判定标准

- **配图（仅此两大类）**：①题干描述具体几何图形（具顶点字母的三角形/四边形）；②可建模为直角三角形的现实情境（仰角/俯角/斜坡/影长/建筑物/灯塔/船等）；
- **不配图**：上述两大类以外的其余情况一律默认不配图——纯代数运算、恒等式证明、由比值求比值、特殊角求值、函数图像、统计图表、`task` 类批量小题，以及要求学生「自主构造」三角形的题（配图会提示答案）；
- 每题的配图判断以「**配圖**」要素逐题标注于规划文件正文（在「題目修改欄」前），并在文末附「配圖判定總表」汇总。

### 9.3 .tex 文件内规范

- **規劃 .md 的 ```tikz 塊轉入 .tex 時須先剝去 `\begin{document}`／`\end{document}` 兩行外殼**，再將 `tikzpicture` 原樣嵌入 `center` 環境（整塊搬運會令 .tex 內含 `\begin{document}` 而編譯失敗）；命令逐行、縮排照本章既有 `center`＋`tikzpicture` 樣式，`task` 類逐題各一個 `center`、不併排不壓單行；
- 顶点字母必标；不画顶点圆点；不标角度/边长数值（数值在题干）；**不标注题目所求的答案元素（如交点坐标、待求角度/边长），否则泄露答案（Ch22 题 22 先例）**；
- 不需要使用角度标记、直角记号、平行符号与等长符号，这些在题干中说明；
- 分题与小分题在排版上都要使用 enumerate，而非 Task 定义的环境。只有 task 类结构的题目需要用到 onecolunm, twocolunm, fourcolunm 环境。

## 十、`%%` 注释工作流

- `.tex` 修改注释 `%% 注释`；`.md` 异议注释 `%% 异议 %%`；
- **注释流程**：
  1. 用户以 `%%` 注释 + checkbox 修改栏勾选或在聊天框中给出注释，.md/.tex 均同；
  2. 读取注释，并凝练意图，需要分辨用户的哪些意图是局部的，哪些意图是全局性的，需要作为长期记忆作用在每一题上的（**全局性意图 → 更新本文档《习题册规划说明方案》相应条款并同步各章规划文件；局部性意图 → 仅修改对应题目**），并就此向用户提出对规划的修改（注意，仅仅是提出对规划的修改，具体是否落实需要征求用户的同意。）；
  3. 在规划文件中新增「十、注釋修改方案規劃」章节，将修改方案的规划同样按排版方式详细写入；
  4. 提交给用户审批；
  5a. 若用户同意方案：执行方案（落实**三处同步**——.tex 中文题面/英文题面/答案三处与 .md 规划文件同步修改，保证规划 .md／正文 .tex／答案 .tex 三份文件信息一致，见「一、大致工作流程」第 6 条定义），删除已处理的 `%%` 注释与勾选，复位所有的 checkbox，并合并方案章节为一行 `✅ 已執行（YYYY-MM-DD）`；
  5b. 用户提出异议：用户会在聊天栏或者文档中以 `%%` 注释提出意见，此时直接在该章节中落实你的修改，进一步给用户审批。直至同意修改方案后执行 5a；

### 四类模板使用要点

| 結構類型         | 題干形式                   | 分題                      | 答案組織                 | 難度標記                  |
| ------------ | ---------------------- | ----------------------- | -------------------- | --------------------- |
| 無結構（單一題）     | 完整問題直接提問               | 無                       | 單一連貫解答               | 只標大題總標記               |
| task 類       | 一句話指令 + (a)(b)(c)… 批量項 | 各項並列獨立，無聯動              | 統一規則 + 逐項套用          | 只標大題總標記（各項共用判準，重複不抬檔） |
| 簡單結構（a、b）    | 主題干只陳述信息               | 恰 (a)(b)，(b) 依賴 (a)     | 逐分題解答，(b) 首行引 (a) 結論 | 分題／小分題（如有）標記 + 大題總標記（取最大值）    |
| 複雜結構（a-b-c…） | 主題干只陳述信息               | ≥3 個分題，層層遞進；可含 i,ii 小分題 | 逐分題解答，後分題引用前分題結論     | 每（小）分題標記（父層不單標）+ 大題總標記（取最大值）   |
**填寫說明：**

- 結構類型四分類：無結構（單一題）／task 類（`\task` 多欄批量）／簡單結構（恰 a、b）／複雜結構（a-b-c 及以上）；比例 ≈ 2:7:1（task 另計）；task 類只用於批量的、重複的、機械性小題；
- 難度檔位：D/C/B/A 帶 ±，四維獨立，不合成總分；
- 小分題打標：小分題與分題同為打標基本單元——分題拆出 i,ii 小分題時，每個小分題獨立標四維＋逐維判定理由，父分題層不設單獨標記；大題總標記取全部（小）分題各維最大值（見 7.3／7.4）；
- 詳細解答的融合寫法：不要單列「解題思路」標題段，也不設獨立開篇策略段——策略、切入點、觀察等自然織入每一步推導，解答整體是一段詳細、教導式的講解；
- 配圖判定：僅兩大類需配圖——具體幾何圖形（具頂點字母三角形/四邊形）與可建模為直角三角形的現實情境；其餘情況（純計算 / 恒等式證明 / 由比值求比值 / 特殊角求值 / 函數圖像 / 統計圖表 / `task` 類批量）一律不配圖；
- 題目修改欄：每題必附，供用戶審批時勾選，具體建議寫在對應 checkbox 後。
- 易錯點注意：每條以「易錯：」開頭（.md 遇位三條即可）；落答案 .tex 時依 6.3.4 用 `\textbf{易錯點注意}`＋`itemize`，且不得夾在 `onecolunm` 環境內部。
