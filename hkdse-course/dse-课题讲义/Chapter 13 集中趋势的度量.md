# 13　集中趋势的度量（Measures of Central Tendency）

> 在前一章我们学习了如何用图表组织和呈现数据。然而，光看图是不够的：给定两组数据，哪一组的「中心」更高？哪一组的成绩「整体」更好？这些问题需要一个**单一的数值**来概括数据的集中位置。本章介绍三种最重要的集中趋势度量——**平均数 (Mean)**、**中位数 (Median)** 与 **众数 (Mode)**。同时，当数据以分组形式给出时，我们还需要掌握如何**估计**这些统计量。

前置：[[Chapter 12 数据的组织与表达|数据的组织与表达]]

本章的预备知识主要来自 [[Chapter 12 数据的组织与表达|数据的组织与表达]]（频数分布表、组中点、累积频数）以及基本的算术运算。学完本章后，你将能够：计算不分组数据的平均数、中位数与众数；正确使用加权平均数；理解数据变换（加减常数、乘除常数）对统计量的影响；以及利用分组数据的频数分布表来估计平均数、中位数，并识别众数组。

在开始之前，先看一个简单的问题感受集中趋势度量的必要性：

````ad-example
title: 示例 | Example


A 班与 B 班各有 $5$ 位学生，某次测验的分数如下：

A 班：$62,\; 68,\; 72,\; 76,\; 82$

B 班：$40,\; 55,\; 72,\; 85,\; 108$

仅凭肉眼，哪个班考得更好？

---

两班都有 $72$ 分的学生，但仅凭一个数据点无法判断整体水平。把两班的分数各自加起来除以 $5$：

A 班： $\dfrac{62 + 68 + 72 + 76 + 82}{5} = 72$ 分

B 班 ：$\dfrac{40 + 55 + 72 + 85 + 108}{5} = 72$ 分

平均数居然相同。但仔细观察：A 班分数集中在 $62$–$82$，B 班则分散在 $40$–$108$——B 班的 $40$ 和 $108$ 是两个极端值，把平均数「拉」到了和 A 班相同的水平。这就引出了一个关键问题：**只用平均数来描述数据是否充分？** 本章将系统回答这个问题。
````

## 13.1　不分组数据中的统计 (Statistics for Ungrouped Data)

> **本节难度上限**：T C+ ｜ C D ｜ E C ｜ Q B

> 不分组数据保留了每个原始观测值。我们先学习三种最基本的集中趋势度量，以及它们的性质。

### 13.1.1　算术平均数、中位数与众数 (Arithmetic Mean, Median, and Mode)

````ad-def
title: 定义（算术平均数） | Definition（Arithmetic Mean）

设一组数据为 $x_1, x_2, \dots, x_n$（$n \ge 1$），则其算术平均数（简称**平均数**）$\bar{x}$ 定义为：
$$\bar{x} = \frac{x_1 + x_2 + \cdots + x_n}{n}$$
> 平均数是最常用的集中趋势度量，直观含义是「把总和平均摊到每项」。
````

````ad-def
title: 定义（中位数） | Definition（Median）

将一组数据按大小顺序排列后，位于正中间位置的数值。

设排序后的数据为 $x_{(1)} \le x_{(2)} \le \cdots \le x_{(n)}$。
- 若 $n$ 为**奇数**，中位数为第 $\dfrac{n+1}{2}$ 个数据：$$\text{Median} = x_{(\frac{n+1}{2})}$$
- 若 $n$ 为**偶数**，中位数为第 $\dfrac{n}{2}$ 个与第 $\dfrac{n}{2}+1$ 个数据的算术平均数：$$\text{Median} = \dfrac{x_{(\frac{n}{2})} + x_{(\frac{n}{2}+1)}}{2}$$
````

> **关键提醒：** 求中位数的第一步永远是**排序**。许多学生直接取中间位置的原始数据，忘记排序，这是最常见的错误。

以下用几个例子体会中位数的计算：

````ad-example
title: 示例 | Example


求下列数据的中位数：

(a) $3,\; 7,\; 9,\; 5,\; 12$

(b) $20,\; 14,\; 8,\; 25,\; 10,\; 18$

---

(a) 排序：$3, 5, 7, 9, 12$。$n = 5$（奇数），中位数为第 $\frac{5+1}{2} = 3$ 个数据，即 $7$。

(b) 排序：$8, 10, 14, 18, 20, 25$。$n = 6$（偶数），中位数为第 $3$ 个（$14$）与第 $4$ 个（$18$）的平均：
$$\text{Median} = \frac{14 + 18}{2} = 16$$

> (b) 中注意：原始数据的第三个是 $8$、第四个是 $25$，若忘记排序直接取这两个平均 $\frac{8+25}{2}=16.5$，与正确答案 $16$ 不同。**排序不可省。**
````

````ad-example
title: 示例 | Example


以下干叶图（十位为干、个位为叶）给出了一组测验分数：

$$\begin{array}{r|l}
\text{十位} & \text{个位} \\
\hline
1 & 5\;\;8 \\
2 & 0\;\;2\;\;5\;\;7 \\
3 & 1\;\;4\;\;6\;\;9 \\
4 & 0\;\;3
\end{array}$$

(a) 共有多少个数据？

(b) 求中位数。

---

(a) 数叶：$2 + 4 + 4 + 2 = 12$ 个数据。

(b) $n = 12$（偶数），中位数为第 $6$ 个与第 $7$ 个数据的平均。还原干叶图：

$$15, 18, 20, 22, 25, 27, 31, 34, 36, 39, 40, 43$$

第 $6$ 个为 $27$，第 $7$ 个为 $31$：
$$\text{Median} = \frac{27 + 31}{2} = 29$$

> 干叶图已自动排序（各行内叶值从小到大排列），可直接定位。中位数 $29$ 的含义：有一半的学生分数高于 $29$，一半低于 $29$。
````

````ad-def
title: 定义（众数） | Definition（Mode）

数据中出现频数最高的数值。
- 一组数据可以有一个众数、多个众数，或没有众数（当所有数值的频数均相同时）。
- 众数是唯一可用于**非数值型数据**（如颜色、类别）的集中趋势度量。
````

````ad-example
title: 示例 | Example


以下是 $8$ 位学生每天花在温习上的时间（单位：小时）：

$$1.5,\; 2.0,\; 1.0,\; 3.5,\; 2.0,\; 2.5,\; 1.5,\; 2.0$$

求这组数据的平均数、中位数与众数。

---

**平均数：**
$$\bar{x} = \frac{1.5 + 2.0 + 1.0 + 3.5 + 2.0 + 2.5 + 1.5 + 2.0}{8} = \frac{16.0}{8} = 2.0$$

**中位数：** 先将数据从小到大排序：
$$1.0,\; 1.5,\; 1.5,\; 2.0,\; 2.0,\; 2.0,\; 2.5,\; 3.5$$
$n = 8$（偶数），中位数为第 $4$ 个与第 $5$ 个数据的平均：
$$\text{Median} = \frac{2.0 + 2.0}{2} = 2.0$$

**众数：** $2.0$ 出现了 $3$ 次（最多），故众数为 $2.0$。

本例中平均数、中位数、众数三者恰好相等，说明数据分布大致对称。
````

要谈数据偏离中心多少，先给「离差」一词立一个正式定义。

````ad-def
title: 定义（离差） | Definition（Deviation）

设一组数据为 $x_1, x_2, \dots, x_n$，其算术平均数为 $\bar{x}$，则差
$$x_i - \bar{x}$$
称为第 $i$ 个数据的**离差**，它衡量这个数据相对于平均数偏高或偏低多少。
````

平均数有一个非常重要的代数性质：

````ad-thm
title: 定理（离差之和为零） | Theorem（离差之和为零）


设 $\bar{x}$ 为数据 $x_1, x_2, \dots, x_n$ 的算术平均数，则各数据与平均数的离差之和为零：
$$(x_1 - \bar{x}) + (x_2 - \bar{x}) + \cdots + (x_n - \bar{x}) = 0$$
````

````ad-proof
title: 证明 | Proof

$$\begin{aligned} &(x_1 - \bar{x}) + (x_2 - \bar{x}) + \cdots + (x_n - \bar{x}) \\[1em]
&= (x_1 + x_2 + \cdots + x_n) - (\bar{x} + \bar{x} + \cdots + \bar{x}) \\[1em] &= n\bar{x} - n\bar{x} = 0 \end{aligned}$$
````

> **直观理解：** 平均数是数据的「平衡点」。以平均数为支点，左侧数据低于平均数的「赤字」恰好被右侧高于平均数的「盈余」抵消。这一性质也解释了为什么平均数对极端值敏感：一个极端的大值会产生很大的正离差，必须由其他数据的大量负离差来抵消，从而「拉高」了整个平均数。

````ad-thm
title: 定理（极端值的影响） | Theorem（极端值的影响）


算术平均数受数据中的**极端值 (Outliers)** 影响较大，因为每个数据均参与总和的计算。
中位数仅依赖排序后的位置，不受极端值影响，具有**稳健性 (Robustness)**。
众数仅依赖频数，亦不受极端值影响。
````

````ad-example
title: 示例 | Example


某公司的 $7$ 名员工的月薪（单位：千元）如下：

$$15,\; 18,\; 20,\; 22,\; 24,\; 25,\; 200$$

(a) 计算平均数与中位数。

(b) 哪一个更能反映该公司员工的「典型」月薪？为什么？

---

(a) **平均数：**
$$\bar{x} = \frac{15 + 18 + 20 + 22 + 24 + 25 + 200}{7} = \frac{324}{7} \approx 46.3 \; \text{千元}$$

**中位数：** 数据已排序，$n = 7$（奇数），第 $\frac{7+1}{2} = 4$ 个数据为 $22$ 千元。

(b) 中位数（$22$ 千元）更能反映典型月薪。原因：总经理的 $200$ 千元是极端值，将平均数「拉高」到 $46.3$ 千元——这个数字高于 $7$ 名员工中 $6$ 人的实际薪金，严重失实。中位数 $22$ 千元恰好是大多数员工的薪金水平。
````

### 13.1.2　加权平均数 (Weighted Mean)

> 普通平均数假设每个数据的「重要性」相同。但在现实世界中，不同数据往往有不同的重要性。例如计算 GPA 时，每个科目的**学分**就是它的权重。

````ad-def
title: 定义（加权平均数） | Definition（Weighted Mean）

设数据为 $x_1, x_2, \dots, x_k$，对应的非负权重为 $w_1, w_2, \dots, w_k$（其中至少有一个 $w_i > 0$），则加权平均数 $\bar{x}_w$ 定义为：
$$\bar{x}_w = \frac{w_1 x_1 + w_2 x_2 + \cdots + w_k x_k}{w_1 + w_2 + \cdots + w_k}$$

当所有权重相等（即 $w_1 = w_2 = \cdots = w_k$）时，加权平均数退化为普通的算术平均数。

权重反映各数据在整体中的**重要性**或**占比**。常见应用包括：按学分加权的平均绩点、按购买数量加权的平均单价。
````

````ad-example
title: 示例 | Example


某学生本学期的成绩如下：

| 科目 | 分数 | 学分 |
| :--- | :---: | :---: |
| 数学 | $85$ | $4$ |
| 英文 | $72$ | $3$ |
| 物理 | $90$ | $4$ |
| 历史 | $68$ | $2$ |

求该学生的加权平均分（按学分加权）。

---

$$\bar{x}_w = \frac{4 \times 85 + 3 \times 72 + 4 \times 90 + 2 \times 68}{4 + 3 + 4 + 2} = \frac{340 + 216 + 360 + 136}{13} = \frac{1052}{13} \approx 80.9$$

加权平均分约为 $80.9$ 分。对比普通平均（$\frac{85+72+90+68}{4} = 78.75$），加权平均分更高——这是因为高学分的数学和物理成绩较好，拉高了整体均值。

> **常见错误提醒：** 加权平均的分母是权重之和（$w_1 + w_2 + \cdots + w_k$），而非数据项数（$k$）。本题中分母是 $4+3+4+2=13$，不是 $4$。
````

### 13.1.3　数据变换对集中趋势的影响 (Effect of Data Transformation)

> 在实际数据分析中，我们经常需要对原始数据进行变换，例如将所有分数上调 $5$ 分，或将所有长度由厘米换算为米。这些操作会如何影响平均数、中位数和众数？

````ad-thm
title: 定理（加常数对集中趋势的影响） | Theorem（加常数对集中趋势的影响）


设一组数据为 $x_1, x_2, \dots, x_n$，其平均数、中位数、众数分别为 $\bar{x}$、$M$、$m_0$。
若对每个数据加上同一个常数 $c$，得新数据 $y_i = x_i + c$（$i = 1, 2, \dots, n$），则新数据的：
- 平均数 $\bar{y} = \bar{x} + c$
- 中位数 $M_y = M + c$
- 众数 $m_{0,y} = m_0 + c$
````

````ad-proof
title: 证明 | Proof

**平均数：**
$$\begin{aligned} \bar{y} &= \frac{(x_1 + c) + (x_2 + c) + \cdots + (x_n + c)}{n} \\ &= \frac{(x_1 + x_2 + \cdots + x_n) + nc}{n} \\ &= \frac{x_1 + x_2 + \cdots + x_n}{n} + c = \bar{x} + c \end{aligned}$$
---

**中位数：** 每个数据加 $c$ 不改变排序的相对次序（因为 $x_{(1)}+c \le x_{(2)}+c \le \dots \le x_{(n)}+c$），中间位置的数据亦加 $c$，故 $M_y = M + c$。

---

**众数：** 每个数据加 $c$ 不改变各数值的出现频数，故出现最多的数值亦加 $c$，即 $m_{0,y} = m_0 + c$。
````

````ad-thm
title: 定理（乘常数对集中趋势的影响） | Theorem（乘常数对集中趋势的影响）


设一组数据为 $x_1, x_2, \dots, x_n$，其平均数、中位数、众数分别为 $\bar{x}$、$M$、$m_0$。
若对每个数据乘上同一个非零常数 $k$，得新数据 $y_i = kx_i$，则新数据的：
- 平均数 $\bar{y} = k\bar{x}$
- 中位数 $M_y = kM$（若 $k > 0$）
- 中位数 $M_y = kM$（若 $k < 0$ 亦然，但须注意排序方向反转）
- 众数 $m_{0,y} = km_0$
````

````ad-proof
title: 证明 | Proof

**平均数：**
$$\bar{y} = \frac{kx_1 + kx_2 + \cdots + kx_n}{n} = k \cdot \frac{x_1 + x_2 + \cdots + x_n}{n} = k\bar{x}$$

---

**中位数：** 若 $k > 0$，排序次序不变（$kx_{(1)} \le kx_{(2)} \le \dots \le kx_{(n)}$），中间位置的值乘 $k$，故 $M_y = kM$。

若 $k < 0$，排序反转（最大的变最小、最小的变最大），但中间位置仍对应原始排序中相同位置的那个数据，该数据乘以 $k$，故 $M_y = kM$ 仍成立。

---

**众数：** 乘 $k$ 不改变出现频数，出现最多的数值乘 $k$，即 $m_{0,y} = km_0$。
````

````ad-example
title: 示例 | Example


一组 $5$ 个数据为：$10,\; 20,\; 30,\; 40,\; 50$。

(a) 求原始数据的平均数与中位数。

(b) 若每个数据加 $8$ 分，求新数据的平均数与中位数。

(c) 若每个数据乘以 $0.5$，求新数据的平均数与中位数。

---

(a) $\bar{x} = \dfrac{10+20+30+40+50}{5} = 30$。数据已排序，$M = 30$。

(b) 根据加常数定理：
1. 新平均数 $= 30 + 8 = 38$，
2. 新中位数 $= 30 + 8 = 38$。

> 验证：新数据为 $18, 28, 38, 48, 58$，$\bar{y} = \frac{18+28+38+48+58}{5} = 38$ ✓，$M_y = 38$ ✓。

(c) 根据乘常数定理：
1. 新平均数 $= 0.5 \times 30 = 15$，
2. 新中位数 $= 0.5 \times 30 = 15$。

> 验证：新数据为 $5, 10, 15, 20, 25$，$\bar{y} = \frac{5+10+15+20+25}{5} = 15$ ✓，$M_y = 15$ ✓。

````

上面两条定理只交代集中趋势。若问「每组数据同加或同乘一个常数，分布域、四分位数间距、标准差与方差跟着怎样变」，见 [[Chapter 33 离差的度量|离差的度量]] §33.4。

## 13.2　分组数据中的统计 (Statistics for Grouped Data)

> **本节难度上限**：T C ｜ C D ｜ E C ｜ Q B

> 当数据以频数分布表的形式呈现时，我们无法获取每个数据的准确值，因此所有统计量均为**估计量**。本章的估计基于一个假设：**同组内的数据在组区间内均匀分布**。

### 13.2.1　众数组 (Modal Class)

````ad-def
title: 定义（众数组） | Definition（Modal Class）

在分组数据的频数分布表中，频数最高的组区间称为**众数组**。

众数组反映数据集中出现的大致范围，而非一个精确的数值。可在直方图中直接识别：最高频数的条形所对应的组区间即为众数组。
````

````ad-example
title: 示例 | Example


以下是 $60$ 名学生的体重分布（单位：kg）：

| 体重 (kg) | 频数 |
| :--- | :---: |
| $40$–$44$ | $5$ |
| $45$–$49$ | $12$ |
| $50$–$54$ | $22$ |
| $55$–$59$ | $15$ |
| $60$–$64$ | $6$ |

(a) 指出众数组。

(b) 这告诉我们什么信息？

---

(a) 频数最高的是 $50$–$54$ kg（频数 $= 22$），故众数组为 $50$–$54$ kg。

(b) 这表示大多数学生的体重集中在 $50$–$54$ kg 这一范围内，是班上「最典型」的体重区间。
````

### 13.2.2　分组数据的估算平均数 (Estimated Mean for Grouped Data)

> 在分组数据中，我们不知道组内每个具体数值，只能假设每个数据等于其所在组的**组中点 (Class Mark)**，然后以频数为权重求加权平均数。

````ad-def
title: 定义（分组数据的估算平均数） | Definition（分组数据的估算平均数）


设数据分为 $k$ 组，第 $i$ 组的组中点为 $m_i$，频数为 $f_i$（$i = 1, 2, \dots, k$），总频数 $N = f_1 + f_2 + \cdots + f_k$。则估算平均数为：
$$\bar{x}_{\text{est}} = \frac{f_1 m_1 + f_2 m_2 + \cdots + f_k m_k}{f_1 + f_2 + \cdots + f_k}$$

此为加权平均数的特殊情形，其中每组的组中点为 $x$ 值，频数为权重。
````

````ad-example
title: 示例 | Example


以下是 $50$ 位学生某次测验的分数分布：

| 分数 | 频数 |
| :--- | :---: |
| $0$–$19$ | $4$ |
| $20$–$39$ | $10$ |
| $40$–$59$ | $18$ |
| $60$–$79$ | $12$ |
| $80$–$99$ | $6$ |

求这组数据的估算平均分。

---

先计算每组的组中点：

| 分数 | 组中点 $m_i$ | 频数 $f_i$ | $f_i m_i$ |
| :--- | :---: | :---: | :---: |
| $0$–$19$ | $9.5$ | $4$ | $38$ |
| $20$–$39$ | $29.5$ | $10$ | $295$ |
| $40$–$59$ | $49.5$ | $18$ | $891$ |
| $60$–$79$ | $69.5$ | $12$ | $834$ |
| $80$–$99$ | $89.5$ | $6$ | $537$ |

总和：$f_1 m_1 + f_2 m_2 + \cdots + f_5 m_5 = 38 + 295 + 891 + 834 + 537 = 2595$，$f_1 + f_2 + \cdots + f_5 = 50$。

$$\bar{x}_{\text{est}} = \frac{2595}{50} = 51.9$$

估算平均分为 $51.9$ 分。

> 这是**估计值**，因为我们用组中点代替了组内的实际分数。如果组距较小、数据在组内大致均匀分布，这个估计会比较准确。
````

### 13.2.3　分组数据的中位数组 (Median Class for Grouped Data)

> 在分组数据中，我们无法精确计算中位数，但可以判断中位数落在哪个组区间。这一步只需要**累积频数**——前面的数据一个一个数过去，数到第 $\frac{N}{2}$ 个停在哪组，那就是中位数所在组。

````ad-lem
title: 引理（定位中位数组） | Lemma（Locating the Median Class）


1. 计算总频数 $N = f_1 + f_2 + \cdots + f_k$。
2. 计算中位数的位置：第 $\dfrac{N}{2}$ 个数据。
3. 自第一组起，将频数逐一累加：$f_1, f_1+f_2, f_1+f_2+f_3, \dots$，**首次达到或超过 $\dfrac{N}{2}$ 的组**即为中位数所在组（中位数组）。
````

````ad-example
title: 示例 | Example


某次考试分数的频数分布如下，判断中位数落在哪一组：

| 分数 | 频数 |
| :--- | :---: |
| $0$–$10$ | $5$ |
| $10$–$20$ | $12$ |
| $20$–$30$ | $20$ |
| $30$–$40$ | $10$ |
| $40$–$50$ | $3$ |

---

$N = 5+12+20+10+3 = 50$，中位数位置 $= \dfrac{50}{2} = 25$。

累加频数：
- 第一组累计：$5$，仍未到 $25$
- 第二组累计：$5+12=17$，仍未到 $25$
- 第三组累计：$17+20=37 \ge 25$ → 中位数落在 $20$–$30$ 这一组。

> 答「中位数在 $20$–$30$ 分组」即可。无需进一步求出具体数值。
````

````ad-example
title: 示例 | Example


以下是 $40$ 个灯泡的寿命数据（单位：小时）的频数分布：

| 寿命 (h) | 频数 |
| :--- | :---: |
| $100$–$199$ | $6$ |
| $200$–$299$ | $8$ |
| $300$–$399$ | $14$ |
| $400$–$499$ | $9$ |
| $500$–$599$ | $3$ |

(a) 求众数组。

(b) 求估算平均数。

(c) 判断中位数落在哪一组。

---

(a) 频数最高的是 $300$–$399$ h（频数 $= 14$），故众数组为 $300$–$399$ h。

(b) 组中点计算：

| 寿命 | 组中点 $m_i$ | $f_i$ | $f_i m_i$ |
| :--- | :---: | :---: | :---: |
| $100$–$199$ | $149.5$ | $6$ | $897$ |
| $200$–$299$ | $249.5$ | $8$ | $1996$ |
| $300$–$399$ | $349.5$ | $14$ | $4893$ |
| $400$–$499$ | $449.5$ | $9$ | $4045.5$ |
| $500$–$599$ | $549.5$ | $3$ | $1648.5$ |

$$\bar{x}_{\text{est}} = \frac{897 + 1996 + 4893 + 4045.5 + 1648.5}{40} = \frac{13480}{40} = 337$$

(c) $N = 40$，中位数位置 $= 20$。

累加频数：$6 < 20$；$6+8=14 < 20$；$14+14=28 \ge 20$ → 中位数落在 $300$–$399$ 这一组。
````

## 第十三章总结

1. **算术平均数：** $\bar{x} = \dfrac{x_1 + x_2 + \cdots + x_n}{n}$。离差之和为零。对极端值**敏感**——任一极端值都会显著改变平均数。

2. **中位数：** 排序后居中的值。奇数 $n$ 取第 $\frac{n+1}{2}$ 个，偶数 $n$ 取中间两个的平均。具有**稳健性**，不受极端值影响。

3. **众数：** 频数最高的值。可有多个或没有。是唯一可用于**非数值型数据**的集中趋势度量。

4. **加权平均数：** $\bar{x}_w = \dfrac{w_1 x_1 + w_2 x_2 + \cdots + w_k x_k}{w_1 + w_2 + \cdots + w_k}$。当权重相等时退化为普通平均数。分母是权重**总和**，不是项目个数。

5. **数据变换的影响：**
   - 加常数 $c$：平均数、中位数、众数均加 $c$。
   - 乘常数 $k$：平均数、中位数、众数均乘 $k$。

6. **分组数据：**
   - **众数组**：频数最高的组区间，反映集中趋势的大致范围。
   - **估算平均数**：以组中点 $m_i$ 为代表值，$\bar{x}_{\text{est}} = \dfrac{f_1 m_1 + f_2 m_2 + \cdots + f_k m_k}{f_1 + f_2 + \cdots + f_k}$。
   - **中位数组**：利用累积频数定位中位数所在组，自第一组累加频数，首次达到或超过 $\frac{N}{2}$ 的组即为中位数组。
