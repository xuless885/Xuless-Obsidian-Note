# 12　数据的组织与表达（Organization and Presentation of Data）

> 统计学 (Statistics) 是一门关于「从数据中提取信息」的学问。在日常生活中，我们每天都会遇到大量的数据：考试成绩、气温变化、身高体重、销量统计。这些数据本身只是一堆数字，只有经过适当的组织和表达，才能变成有用的信息。本章介绍两种核心技能：「数据的分类」，即理解数据的本质属性；以及「数据的表达」，即用图表将数据的分布一目了然地呈现出来。

前置：[[Chapter 7 率、比及百分法|率、比及百分法]]

本章的预备知识主要是 [[Chapter 7 率、比及百分法|率与比]]（用于频率计算），不涉及更高级的统计概念。学完本章后，你将能够：正确区分离散数据与连续数据，独立绘制和解读干叶图、直方图、频数多边形及累积频数曲线 (Ogive)。

在开始之前，先看一个简单的例子来感受「表达方式决定理解」：

````ad-example
title: 示例 | Example


以下是某班 20 位学生的数学测验分数（满分为 100）：

$$72,\; 85,\; 63,\; 91,\; 58,\; 76,\; 82,\; 69,\; 95,\; 74,\; 67,\; 88,\; 73,\; 59,\; 81,\; 90,\; 64,\; 78,\; 87,\; 70$$

只是看这串数字，能否快速判断：
- 最高分和最低分分别是多少？
- 大部分同学的分数集中在哪个范围？
- 这次测验的整体表现如何？

---

把数据从小到大排序：$58, 59, 63, 64, 67, 69, 70, 72, 73, 74, 76, 78, 81, 82, 85, 87, 88, 90, 91, 95$。

我们马上能看到：最低 $58$，最高 $95$。中间十几位同学的分数集中在 $69$ 到 $88$ 之间。整体来看，这是一个不错的测验：大部分同学都在及格线以上。

问题是，**把数据排序并逐一列出**虽然比乱序好，但数据一多（比如全年级 200 人）就力不从心了。这正是本章要解决的问题：用更高效的图表来组织和呈现数据。
````

## 12.1　数据的分类 (Classification of Data)

> **本节难度上限**：T C ｜ C D ｜ E D ｜ Q B

> 在画图之前，必须先回答一个更基本的问题：这些数据「长什么样」？不同类型的数需要不同的处理方式，用错方法，结论可能会出现严重错误。

### 12.1.1　连续与离散数据 (Continuous and Discrete Data)


这是数据最根本的分类维度：按取值的性质，数据分为 **离散** 与 **连续** 两大类。

````ad-def
title: 定义（离散数据） | Definition（Discrete Data）

取值仅限于有限个或可数无穷个孤立值的数据。离散数据通过 **计数** 获得，两个相邻的可能取值之间不存在中间值。
````

例如：一个班的学生人数（不可能有 $32.7$ 个人）、鞋码（只有 $39, 40, 41, \dots$，没有 $39.3$ 码）、掷骰子的点数（只有 $1, 2, 3, 4, 5, 6$）。

````ad-def
title: 定义（连续数据） | Definition（Continuous Data）

可在某一区间内取任意实数值的数据。连续数据通过 **测量** 获得。
````

例如：身高（可以是 $175.5$ cm，也可以是 $175.53$ cm，只要测量工具足够精密）、体重（$60.2$ kg）、时间（$9.58$ s）。

> **区分要点：** 计数的结果是离散的（你不会说「教室里有 $28.4$ 个学生」），测量的结果是连续的（长度原则上可以无限细分）。特别要注意：连续数据经过四舍五入后，表面上看起来像离散的（如身高记录为整数厘米），但这不代表它变成了离散数据。判断依据是数据的 **来源**（计数还是测量），而非表面的取值形式。买鸡蛋数个数是离散，用秤称鸡蛋重量是连续。

````ad-example
title: 示例 | Example


判断以下数据是离散数据还是连续数据：

(a) 学校图书馆的藏书数量

(b) 今天室外气温（单位：°C）

(c) 某次考试的分数（0–100 整数）

(d) 同学们每天花在社交媒体上的时间

---

(a) **离散**：书本按「本」计数，不存在 $523.7$ 本书。

(b) **连续**：温度通过测量获得，可以是 $23.6^\circ\text{C}$、$23.61^\circ\text{C}$ 等。

(c) **离散**：考试分数按「分」计数，老师不会打出 $72.3$ 分。虽然分数范围很大，但取值只有 $0, 1, 2, \dots, 100$ 这些孤立值。

(d) **连续**：时间通过测量获得，可以是 $45.2$ 分钟、$45.23$ 分钟等。
````

### 频数 (Frequency)


在整理数据之前，需要先了解一个最基本的概念：**频数**。无论是离散还是连续数据，当我们想要知道"某个值出现了多少次"时，就是在讨论频数。

````ad-def
title: 定义（频数） | Definition（Frequency）

在数据集中，某特定取值或某取值区间内所包含的数据个数。通常用符号 $f$ 表示。
````

简而言之，频数量化了数据集中某些数据出现的次数。

````ad-example
title: 示例 | Example


某班 $20$ 位学生的血型记录如下：

$$O,\; A,\; B,\; A,\; O,\; O,\; AB,\; A,\; B,\; O,\; A,\; B,\; B,\; O,\; A,\; AB,\; O,\; A,\; O,\; B$$

(a) 将这些数据整理为频数表。

(b) 哪种血型的人数最多？占总人数的百分之几？

---

(a) 统计每种血型出现的次数，得到频数表：

| 血型 | 频数 |
| :---: | :---: |
| A | $6$ |
| B | $5$ |
| O | $7$ |
| AB | $2$ |

> 总频数 $= 6 + 5 + 7 + 2 = 20$，与班级人数一致。

(b) O 型人数最多，共 $7$ 人，占比 $= \dfrac{7}{20} \times 100\% = 35\%$。
````

> 频数是整个统计学中最基础的概念。后续的干叶图、直方图、累积频数曲线等工具，本质上都是用不同的方式展示"频数如何随着数据取值的不同而变化"。

### 12.1.2　分组与不分组数据 (Grouped and Ungrouped Data)


按数据的组织形式，可以分为 **不分组** 与 **分组** 两大类。

````ad-def
title: 定义（不分组数据） | Definition（Ungrouped Data）

未经分类处理的原始数据列表。每个数据点均保留其精确值。

适用于数据量较少、可逐一检视的情形。例如：$10$ 个人的身高数据可以直接列出。
````

分组数据涉及几个重要术语：

````ad-def
title: 定义（组区间与相关术语） | Definition（Class Interval and Related Terms）

将数据范围划分为若干个互不重叠的区间，每个区间称为一个 **组区间 (Class Interval)**。例如，数据为整数时，常取 $10$–$19$、$20$–$29$ 等作为组区间。

- **组限 (Class Limits)**：组区间的上、下端点。如上例中组区间的组限为 $10$ 和 $19$。

- **组界 (Class Boundaries)**：绘图时所使用的边界值。为确保直方图中各矩形条紧密相邻、无间隙，组界通常取至比原始数据多一位小数的精度。对于整数数据，组界一般取组限 $\pm\; 0.5$。如上例中组区间 $10$–$19$ 的组界为 $9.5$–$19.5$。

- **组距 (Class Width)**：上组界与下组界之差，即 $\text{组距} = \text{上组界} - \text{下组界}$。

- **组中点 (Class Mark)**：组区间的中心值，$\displaystyle \text{组中点} = \frac{\text{下组界} + \text{上组界}}{2}$。

- **组区间记法：** 常见以不等式表示组区间，如 $10 \le x \le 19$、$20 \le x \le 29$，或 $1 \le x < 2$、$2 \le x < 3$。
````

````ad-def
title: 定义（分组数据） | Definition（Grouped Data）

将数据归入若干个 **组区间** 后，仅记录各区间内数据的 **频数 (Frequency)**，即落在这个区��内的数据个数。

适用于数据量庞大或数据为连续型时。例如：全年级 $200$ 人的身高数据，分组后变成 $6$–$10$ 个组区间，每一行只保留一个区间和对应的频数。
````

````ad-example
title: 示例 | Example

以下是一间店铺连续 $10$ 天的营业额（单位：万元）：

$$3.2,\; 4.1,\; 2.8,\; 5.0,\; 3.6,\; 4.5,\; 2.9,\; 5.3,\; 3.8,\; 4.0$$

这是不分组数据还是分组数据？若将这些数据以 $2.5$–$3.4$、$3.5$–$4.4$、$4.5$–$5.4$ 分组，会变成什么形式？

---

原始数据是 **不分组数据**：每个数据点都保留了精确值（如 $3.2$ 万元）。

分组后变成 **分组数据**，形式如下：

| 组区间 | 频数 |
| :--- | :---: |
| $2.5$–$3.4$ | $3$（包含 $2.8, 2.9, 3.2$） |
| $3.5$–$4.4$ | $4$（包含 $3.6, 3.8, 4.0, 4.1$） |
| $4.5$–$5.4$ | $3$（包含 $4.5, 5.0, 5.3$） |

分组后我们不再知道每个具体数值，但能一眼看出哪一组的营业额天数最多。
````

````ad-example
title: 示例 | Example


某班 $30$ 位学生的身高数据（单位：cm）如下：

$$152,\; 165,\; 170,\; 158,\; 175,\; 160,\; 168,\; 155,\; 172,\; 163,$$
$$166,\; 159,\; 178,\; 161,\; 173,\; 157,\; 170,\; 164,\; 169,\; 156,$$
$$174,\; 162,\; 167,\; 171,\; 160,\; 165,\; 158,\; 176,\; 168,\; 153$$

若以组距 $5$ cm 进行分组，写出组区间 $150$–$154$、$155$–$159$ 的组限、组界和组中点。

---

组区间 $150$–$154$：
- 组限 = $150$–$154$
- 组界 = $149.5$–$154.5$
- 组距 = $5$
- 组中点 = $\dfrac{149.5 + 154.5}{2} = 152$

组区间 $155$–$159$：
- 组限 = $155$–$159$
- 组界 = $154.5$–$159.5$
- 组距 = $5$
- 组中点 = $\dfrac{154.5 + 159.5}{2} = 157$

> 相邻组区间的组界共享（上一组的上组界 $154.5$ 等于下一组的下组界），确保直方图中矩形条紧密相连、无间隙。

> 组界即区间端点，相邻区间通过端点自然衔接（如 $154$ 是上一组的上组界、下一组的下组界），完整覆盖数据范围。
````

## 12.2　数据的表达 (Presentation of Data)

> **本节难度上限**：T C+ ｜ C D ｜ E C ｜ Q B

> 现在我们知道数据分什么类型、可以怎么分组，接下来是本章的重点：如何用图表呈现数据。本节介绍四种核心工具，从「保留全部原始数据」的干叶图，到「用于估计分位数」的累积频数曲线 (Ogive)，循序渐进。

### 12.2.1　干叶图 (Stem-and-Leaf Diagram)


干叶图是一种简单而强大的数据展示方式。与后面要学的直方图不同，**干叶图保留了每一个原始数据**，你不仅能看到分布，还能精确还原出每一个数值。

````ad-def
title: 定义（干叶图） | Definition（Stem-and-Leaf Diagram）

将每个数据分为 **干 (Stem)**（高位部分）与 **叶 (Leaf)**（低位部分，通常为个位），以纵列列出干值、横向排列对应叶值的方式展示数据分布的统计图表。
````

画干叶图的核心思路是：把数据的十位和百位当作「干」，个位当作「叶」，就像一棵倒下的树：主干（十位）纵向排列，叶子（个位）从旁长出。

干叶图的绘制步骤如下：

````ad-lem
title: 引理（干叶图的绘制方法） | Lemma（干叶图的绘制方法）


1. **选定干与叶：** 确定高位与低位的分割点。一般以十位及以上为干，个位为叶。
2. **排列干值：** 按从小到大的顺序纵向写出所有出现过的干值。
3. **填入叶值：** 将每个数据的低位数字按所属的干行填入，并在每行内按从小到大的顺序排列。
````

````ad-example
title: 示例 | Example


以下是 $15$ 位学生的英文默书分数：

$$23,\; 31,\; 45,\; 28,\; 36,\; 42,\; 31,\; 38,\; 25,\; 40,\; 33,\; 29,\; 41,\; 31,\; 37$$

(a) 绘制这组数据的干叶图（十位为干、个位为叶）。

(b) 从干叶图中找出最低分和最高分。
(c) 分数出现在哪个十位段的人数最多？

---

(a) **步骤 1：** 确定干值：$2, 3, 4$（十位数）。

**步骤 2：** 将每个数据的个位填入对应的干行，并按从小到大排序：

$$\begin{array}{r|l}
\text{十位} & \text{个位} \\
\hline
2 & 3\;\;5\;\;8\;\;9 \\
3 & 1\;\;1\;\;1\;\;3\;\;6\;\;7\;\;8 \\
4 & 0\;\;1\;\;2\;\;5
\end{array}$$

(b) 最低分：$23$（干 $2$、叶最小者为 $3$）；最高分：$45$（干 $4$、叶最大者为 $5$）。

(c) 干 $3$ 行有 $7$ 片叶（$7$ 位学生），人数最多。这意味着大多数同学的分数落在 $30$–$39$ 这个范围。
````

> **观察 (Observation)：干叶图的性质**
>
> 从上面这个例子我们可以体会到干叶图的重要特点：每个原始数据均可从干叶图中唯一地还原（例如 $3 \mid 1$ 还原为 $31$），干叶图 **不损失数据讯息**。

````ad-example
title: 示例 | Example


某班学生的体重（单位：kg）数据以如下的干叶图呈现（干为十位，叶为个位）：

$$\begin{array}{r|l}
\text{十位} & \text{个位} \\
\hline
4 & 5\;\;7\;\;8\;\;9 \\
5 & 0\;\;1\;\;2\;\;3\;\;3\;\;5\;\;6\;\;8 \\
6 & 1\;\;2\;\;4\;\;6\;\;7 \\
7 & 0\;\;3
\end{array}$$

(a) 全班共有多少人？

(b) 体重在 $60$ kg 或以上的学生占全班的百分之几？

---

(a) 数叶：干 $4$ 有 $4$ 片，干 $5$ 有 $8$ 片，干 $6$ 有 $5$ 片，干 $7$ 有 $2$ 片。总共 $4 + 8 + 5 + 2 = 19$ 人。

(b) 体重 $\ge 60$ kg 对应干 $6$ 和干 $7$，共 $5 + 2 = 7$ 人。占比 $= \dfrac{7}{19} \times 100\% \approx 36.8\%$。
````

### 12.2.2　频数分布表与直方图 (Frequency Distribution Table and Histogram)


当数据量很大时，干叶图会变得很长，不方便阅读。此时更好的做法是：将数据分组，只记录各组有多少个数据，这就是 **频数分布表**，然后基于频数分布表画出 **直方图**。

#### 频数分布表 (Frequency Distribution Table)

````ad-def
title: 定义（频数分布表） | Definition（Frequency Distribution Table）

将数据按组区间划分后，列出各组区间及其对应频数的表格。字段通常包含：组区间、组界、组中点、频数。
````

````ad-example
title: 示例 | Example


某次考试中，$50$ 位学生的成绩经分组后得到如下频数分布表：

| 分数 | 频数 |
| :--- | :---: |
| $0$–$19$ | $4$ |
| $20$–$39$ | $10$ |
| $40$–$59$ | $18$ |
| $60$–$79$ | $12$ |
| $80$–$99$ | $6$ |

从表中可以直接看出：大多数学生（$18$ 人）的成绩位于 $40$–$59$ 分之间。这就是频数分布表的作用：将原始数据浓缩为区间与频数，一眼看出数据的集中趋势。
````

#### 直方图 (Histogram)

````ad-def
title: 定义（直方图） | Definition（Histogram）

以相邻矩形条（无间隙）表示分组数据频数分布的统计图。横轴为组界（连续尺度），纵轴为频数或频率。

**关键特征：** 矩形条之间 **紧密相连**（无间隙），这是直方图与棒形图 (Bar Chart) 的根本区别。
````

> 事实上，直方图分为两种：频数直方图与频率直方图。区别在于纵轴是频数还是频率，本课程约定：讨论的所有直方图均为**频数直方图**。
> 
> 在频数直方图中，组距相等时，矩形的高度直接代表各组的频数。

 **注意：直方图与棒形图的区分 (Histogram vs Bar Chart)**

| 特性   | 直方图 (Histogram) | 棒形图 (Bar Chart) |
| :--- | :-------------- | :-------------- |
| 数据类型 | 连续数据（分组）        | 离散或分类数据         |
| 横轴尺度 | 连续数值尺度          | 类别（无序或有序）       |
| 条形间距 | 无间隙（相邻）         | 有间隙             |

> 简而言之：**连续数据用直方图，分类数据用棒形图。** 身高、体重、时间等连续变量用直方图；血型、颜色、科目等分类变量用棒形图。

````ad-example
title: 示例 | Example


以下是 $20$ 位学生每天花在阅读上的时间（单位：分钟）：

$$32,\; 45,\; 28,\; 51,\; 38,\; 42,\; 55,\; 30,\; 47,\; 35,$$
$$41,\; 53,\; 29,\; 48,\; 36,\; 44,\; 50,\; 33,\; 46,\; 39$$

(a) 以 $25$–$29$、$30$–$34$、$35$–$39$、$40$–$44$、$45$–$49$、$50$–$54$、$55$–$59$ 为组区间，制作频数分布表（须列出组界、组中点及频数）。

(b) 据此绘制直方图。

---

(a) 频数分布表：

| 组区间 | 组界 | 组中点 | 频数 |
| :--- | :--- | :---: | :---: |
| $25$–$29$ | $24.5$–$29.5$ | $27$ | $2$ |
| $30$–$34$ | $29.5$–$34.5$ | $32$ | $3$ |
| $35$–$39$ | $34.5$–$39.5$ | $37$ | $4$ |
| $40$–$44$ | $39.5$–$44.5$ | $42$ | $3$ |
| $45$–$49$ | $44.5$–$49.5$ | $47$ | $4$ |
| $50$–$54$ | $49.5$–$54.5$ | $52$ | $3$ |
| $55$–$59$ | $54.5$–$59.5$ | $57$ | $1$ |

> 验证：总频数 $= 2 + 3 + 4 + 3 + 4 + 3 + 1 = 20$，与数据总数一致。

(b) 画法：
- 横轴标注组界（$24.5, 29.5, 34.5, \dots, 59.5$）。
- 纵轴标注频数。
- 在每一组界区间上画矩形条，高度为该组的频数。
- 各矩形条紧密相连，无间隙。

![[Ch12_histogram.svg|591]]

因为各组组距相等（均为 $5$）。矩形高度代表频数。
````

````ad-example
title: 示例 | Example


以下是统计中常见的错误，请判断：

「学校统计了各年级学生最喜欢的颜色，并画了一张直方图来展示。」

这个做法正确吗？

---

不正确。颜色（红、蓝、绿、黄等）是 **分类数据**，不是连续数据。分类数据应该用 **棒形图 (Bar Chart)**，条形之间应有间隙。直方图只能用于连续分组数据。

````

### 12.2.3　频数多边形与频数曲线 (Frequency Polygon and Frequency Curve)


在直方图的基础上，如果我们在每个矩形的顶边中点标一个点，然后用线段连起来，就得到了 **频数多边形**。它的作用是更直观地显示数据分布的「形状」。

````ad-def
title: 定义（频数多边形） | Definition（Frequency Polygon）

以直方图中各矩形条顶边的 **中点** 为顶点，用线段依次连接而成的折线图。首尾两端通常延伸至横轴（频数为 $0$ 的点），形成闭合多边形。
````

频数多边形的绘制步骤：

````ad-lem
title: 引理（绘制频数多边形的步骤） | Lemma（绘制频数多边形的步骤）


1. 在直方图上标出每个矩形条顶边的中点，即坐标为 $($组中点$,$ 频数$)$ 的点。
2. 在首组之前及末组之后各添加一个频数为 $0$ 的中点（取相邻组距的一半处）。
3. 用直线段依序连接所有标出的点。
````

````ad-def
title: 定义（频数曲线） | Definition（Frequency Curve）

当数据量极大且组距趋近于零时，频数多边形趋近于一条平滑的曲线，称为频数曲线。频数曲线反映了总体数据在理想情况下的分布型态。
````

**常见分布型态：** 通过频数多边形或频数曲线的形状，可以直观判断数据的分布特征：
 - **对称分布 / Symmetric**（钟形 / Bell-shaped）：数据在中心处最集中，向两侧对称减少
 - **正偏 / Positively Skewed**（右偏 / Right-skewed）：尾部向右延伸，大部分数据集中在左侧
 - **负偏 / Negatively Skewed**（左偏 / Left-skewed）：尾部向左延伸，大部分数据集中在右侧

````ad-example
title: 示例 | Example


基于 12.2.2 例子中的频数分布表，绘制频数多边形。

| 组区间 | 组界 | 组中点 | 频数 |
| :--- | :--- | :---: | :---: |
| $25$–$29$ | $24.5$–$29.5$ | $27$ | $2$ |
| $30$–$34$ | $29.5$–$34.5$ | $32$ | $3$ |
| $35$–$39$ | $34.5$–$39.5$ | $37$ | $4$ |
| $40$–$44$ | $39.5$–$44.5$ | $42$ | $3$ |
| $45$–$49$ | $44.5$–$49.5$ | $47$ | $4$ |
| $50$–$54$ | $49.5$–$54.5$ | $52$ | $3$ |
| $55$–$59$ | $54.5$–$59.5$ | $57$ | $1$ |

**步骤 1：** 在坐标平面上标出这 $7$ 个点：$(27, 2)$、$(32, 3)$、$(37, 4)$、$(42, 3)$、$(47, 4)$、$(52, 3)$、$(57, 1)$。

**步骤 2：** 添加两个额外点：在首组之前取 $(22,0)$（因为首组组中点为 $27$，前一组的组中点应比 $27$ 低 $5$，邻组距 $5$），在末组之后取 $(62,0)$。
````

### 12.2.4　累积频数与累积频数曲线 (Cumulative Frequency and Ogive)


前面看到的直方图告诉我们「每个组区间有多少数据」，但有时我们需要回答「不超过某个值的数据有多少」这类问题。这就需要 **累积频数** 的概念。

````ad-def
title: 定义（累积频数） | Definition（Cumulative Frequency）

对于按数值从小到大排列的数据，某一值的累积频数是 **小于或等于该值**（或小于该值）的所有数据的频数之和。

在分组数据中，第 $k$ 组的累积频数为前 $k$ 组频数之和：
$$\text{CF}_k = f_1 + f_2 + \cdots + f_k$$
其中 $f_i$ 为第 $i$ 组的频数。
````

````ad-def
title: 定义（累积频数多边形／曲线） | Definition（Cumulative Frequency Polygon / Curve）

，亦称 **Ogive**：以各组的 **上组界** 为横坐标、对应累积频数为纵坐标，依次绘制点并用线段（或平滑曲线）连接所得的图形。
````

````ad-lem
title: 引理（绘制 Ogive 的步骤） | Lemma（绘制 Ogive 的步骤）


1. 构建频数分布表，添加「累积频数」一栏。
2. 逐组计算累积频数：$\text{CF}_1 = f_1$，$\text{CF}_2 = f_1 + f_2$，依此类推。
3. 以各组 **上组界** 为 $x$ 坐标、对应累积频数为 $y$ 坐标，标出数据点。
4. 将各点用平滑曲线（或直线段）连接。曲线从第一个 **下组界**（累积频数 $= 0$）开始，至最后一个上组界结束。
````

````ad-thm
title: 定理（Ogive 的形状性质） | Theorem（Ogive 的形状性质）


由于累积频数是非递减的（随 $x$ 增加，累积频数只增不减），Ogive 始终呈 **上升** 趋势。
````

> **注意：** Ogive 的横坐标使用 **上组界**，而非组中点（这一点与频数多边形完全不同）。曲线起点为第一个组区间的下组界（累积频数 $= 0$）。

````ad-example
title: 示例 | Example


以下是 $50$ 名考生在某次考试中的分数分布：

| 分数区间 | 频数 |

| $10$–$19$ | $5$ |
| $20$–$29$ | $8$ |
| $30$–$39$ | $12$ |
| $40$–$49$ | $10$ |
| $50$–$59$ | $7$ |
| $60$–$69$ | $4$ |
| $70$–$79$ | $2$ |

(a) 完成累积频数分布表（须列出上组界及累积频数）。

(b) 绘制对应的累积频数分布曲线 (Ogive)。

---

(a) 累积频数分布表：

| 分数区间 | 上组界 | 频数 | 累积频数 |
| :--- | :---: | :---: | :---: |
| $0$–$9$ | $9.5$ | $2$ | $2$ |
| $10$–$19$ | $19.5$ | $5$ | $7$ |
| $20$–$29$ | $29.5$ | $8$ | $15$ |
| $30$–$39$ | $39.5$ | $12$ | $27$ |
| $40$–$49$ | $49.5$ | $10$ | $37$ |
| $50$–$59$ | $59.5$ | $7$ | $44$ |
| $60$–$69$ | $69.5$ | $4$ | $48$ |
| $70$–$79$ | $79.5$ | $2$ | $50$ |

曲线始终呈上升趋势（累积频数非递减）。从图中可以读中位数：在纵轴 $25$（总频数 $= 50$ 的一半）处引水平线交曲线于一点，该点的横坐标即中位数的估计值，约 $37.8$ 分。
````

````ad-example
title: 示例 | Example


根据上题的累积频数表回答：

(a) 有多少考生的分数不超过上组界 $39.5$ 分？

(b) 得分在 $59.5$ 分以上的考生有多少人？

---

(a) 查表，上组界 $39.5$ 对应的累积频数为 $27$，即有 $27$ 人的分数不超过 $39.5$ 分。

(b) 查表，上组界 $59.5$ 对应的累积频数为 $44$，即有 $44$ 人的分数不超过 $59.5$ 分。因此得分在 $59.5$ 分以上的人数为 $50 - 44 = 6$ 人。
````

## 第十二章总结

1. **数据的分类（12.1）：**
   - **离散数据**：计数所得，取值为孤立点（如人数、鞋码、骰子点数）。
   - **连续数据**：测量所得，可在区间内取任意值（如身高、体重、时间）。
   - **不分组数据**：保留每个原始数据点。
   - **分组数据**：以组区间归纳，仅记录频数。组界即区间端点，通过调节区间宽度实现完整覆盖。DSE 也常以不等式 $10 \le x \le 19$ 等形式表示组区间。

2. **干叶图（12.2.1）：** 将数据分为干（高位）与叶（低位），直接以位值标记表头。保留全部原始数据，旋转 $90^\circ$ 可大致判断分布形状。

3. **频数分布表与直方图（12.2.2）：** 分组后以频数分布表组织数据，直方图以相邻无间隙的矩形条展示。与棒形图的核心区别：直方图用于连续数据（条形相邻），棒形图用于分类/离散数据（条形有间隙）。

4. **频数多边形与频数曲线（12.2.3）：** 连接各组中点处的频数，首尾延伸至横轴。当组距趋零时趋近于平滑的频数曲线，可判断数据的对称性及偏态方向。

5. **累积频数与 Ogive（12.2.4）：** 累积频数为前 $k$ 组频数之和。Ogive 以各组 **上组界** 为横轴、累积频数为纵轴，始终呈上升趋势。
