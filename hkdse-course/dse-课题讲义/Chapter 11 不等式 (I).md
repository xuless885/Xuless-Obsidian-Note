# 11　不等式（I）（Inequalities I）


> 上一章学会了如何解一元一次方程。方程的解只有一个，但现实生活中，更多时候答案不是一个点，而是一个范围：「至少带 50 元」「温度不超过 100°C」……不等式正是描述这种「范围」的语言。本章在上一章序公理的基础上，系统化不等式的求解方法。与解方程 90% 的步骤相同，仅在最后一步「除以系数」时多一个关于正负的判断。

## 11.1　实数的序性质回顾 (Review of Order Properties of Real Numbers)

> **本节难度上限**：T C+ ｜ C C ｜ E C ｜ Q C

> 本节回顾 Ch01 中建立的序公理及相关定理。完整内容见 [[Chapter 1 数系(I)#1.4|Ch01 §1.4 比较不同的数大小的方法]]，此处仅列出本章所需的核心结论。

````ad-axi
title: 公理（序公理） | Axiom（Order Axiom）

对任意实数 $x, y$：
1. （三歧性 / Trichotomy）$x > y$、$x < y$、$x = y$ 恰一成立。
2. （乘法性质 / Multiplication Property）$x > 0,\; y > 0 \implies xy > 0$。
3. $x > y \iff y < x$。
4. （加法性质 / Addition Property）$x > y \implies x + z > y + z$。
5. （传递性 / Transitivity）$x > y,\; y > z \implies x > z$。
````

````ad-thm
title: 定理（序运算性质） | Theorem（序运算性质）


1. $a > b \iff a - b > 0$；$a < b \iff a - b < 0$。（作差法）
2. $x > y$ 且 $z > 0 \implies xz > yz$。（不等式两边乘除以正数，方向不变）
3. $x > y \implies -x < -y$。（乘以 $-1$，不等号反转，即变号法则）
4. $x > y$ 且 $z < 0 \implies xz < yz$。（不等式两边乘除以负数，方向反转）

（将「$>$」「$<$」替换为「$\ge$」「$\le$」，上述定理仍成立。）
````

> 以上公理与定理构成不等式运算的全部逻辑基础。本章的核心任务是在此基础上，将不等式的求解系统化。

## 11.2　一元一次不等式 (Linear Inequalities in One Variable)

> **本节难度上限**：T B- ｜ C C ｜ E C ｜ Q C

### 11.2.1　定义及求解法 (Definition and Solving Method)

> 本节定义一元一次不等式，建立其求解算法，并与 Ch05 中一元一次方程的解法进行系统对比。

````ad-def
title: 定义（一元一次不等式） | Definition（Linear Inequality in One Variable）

对于由「$>$」「$<$」「$\ge$」「$\le$」连接两个多项式所构成的不等式 $P_1 > P_2$（或 $P_1 < P_2$, $P_1 \ge P_2$, $P_1 \le P_2$），设 $Q = P_1 - P_2$ 为化简后的多项式（最简表示）。我们称 $$P_1 > P_2$$ 为**一元一次不等式**当且仅当 $Q$ 是一元一次多项式。
````

> 例如 $2x + 3 > 5x - 4$，计算 $(2x+3) - (5x-4) = -3x + 7$，为单变量一次多项式，因此该不等式是一元一次不等式。

````ad-example
title: 示例 | Example


判断下列哪些是一元一次不等式：
1. $3x + 2 > 0$
2. $x^2 + 1 > 0$
3. $2x + 3y \le 5$
4. $3(x + 1) > 2x - 4$

---

逐项计算 $P_1 - P_2$ 的最简表示：

1. $3x + 2 - 0 = 3x + 2$，为一元一次多项式。**是**一元一次不等式。
2. $x^2 + 1 - 0 = x^2 + 1$，为一元二次多项式。**否**。
3. $2x + 3y - 5$，为二元一次多项式。**否**。
4. $3(x + 1) - (2x - 4) = 3x + 3 - 2x + 4 = x + 7$，为一元一次多项式。**是**一元一次不等式。
````

````ad-thm
title: 定理（一元一次不等式的标准形式） | Theorem（一元一次不等式的标准形式）

一元一次不等式可化为 $ax + b > 0$（或 $ax + b < 0$, $ax + b \ge 0$, $ax + b \le 0$）的形式，其中 $a, b$ 为实数且 $a \neq 0$。
````

````ad-proof
title: 证明 | Proof

$P_1 > P_2$ 为一元一次不等式 $\iff P_1 - P_2$ 是一元一次多项式 $\iff P_1 - P_2 = ax + b$，其中 $a, b$ 为实数且 $a \neq 0$。

而 $P_1 > P_2 \iff P_1 - P_2 > 0$（作差法），即 $ax + b > 0$。其余三种不等号同理。
````

````ad-example
title: 示例 | Example


将不等式 $3(x - 1) \le 2(x + 4)$ 化为标准形式，并确定 $a, b$。

---

移项至左边：

$$3(x - 1) - 2(x + 4) \le 0$$

去括号：

$$3x - 3 - 2x - 8 \le 0$$

合并同类项：

$$x - 11 \le 0$$

此即标准形式 $ax + b \le 0$，其中 $a = 1$，$b = -11$。
````

````ad-def
title: 定义（不等式的解） | Definition（Solution of an Inequality）

使不等式成立的未知数的取值，称为该不等式的**解**。
> 与方程不同，方程的解通常为有限个，而不等式的解通常有**无穷多个**，在数轴上对应一段连续的范围。
````

````ad-example
title: 示例 | Example


验证 $x = 5$ 和 $x = 2$ 是否为不等式 $3x + 1 > 10$ 的解。

---

当 $x = 5$ 时：$3(5) + 1 = 16 > 10$，不等式成立，故 $x = 5$ 是解。

当 $x = 2$ 时：$3(2) + 1 = 7$，$7 > 10$ 不成立，故 $x = 2$ 不是解。
````

````ad-thm
title: 定理（解的公式） | Theorem（Formula for the Solution）

一元一次不等式 $ax + b > 0$（$a \neq 0$）的解为：
- 若 $a > 0$，则 $\displaystyle x > -\frac{b}{a}$。
- 若 $a < 0$，则 $\displaystyle x < -\frac{b}{a}$。
````

````ad-proof
title: 证明 | Proof

由序公理加法性质，两边同时加 $-b$ 得 $ax > -b$。
- 若 $a > 0$，由定理（除以正数时不等号的方向不变）两边除以 $a$，不等号方向不变，得 $x > -b/a$。
- 若 $a < 0$，由定理（除以负数时不等号的方向反转）两边除以 $a$，不等号方向改变，得 $x < -b/a$。
````

````ad-example
title: 示例 | Example


用解的公式解不等式 $2x + 6 > 0$。

---

这里 $a = 2 > 0$，$b = 6$。由解的公式：

$$x > -\frac{b}{a} = -\frac{6}{2} = -3$$

故解为 $x > -3$。
````

````ad-example
title: 示例 | Example


用解的公式解不等式 $-3x + 9 \le 0$。

---

这里 $a = -3 < 0$，$b = 9$。由解的公式（$a < 0$，方向改变）：

$$x \ge -\frac{b}{a} = -\frac{9}{-3} = 3$$

故解为 $x \ge 3$。
````

> 该定理同时说明了为何一元一次不等式的解必为一个无限延伸的范围（即所有大于或小于某个数的实数）。

进一步地，我们可以将解一元一次不等式的过程系统化表达为以下五个步骤：

**方法（Method）：解一元一次不等式**

与解一元一次方程的步骤高度一致，唯一差异在于**系数化为 1** 时须判断系数正负：

| 步骤        | 操作                         | 与解方程的异同                             |
| --------- | -------------------------- | ----------------------------------- |
| 1. 去分母    | 两边乘各分母的最小公倍数               | 相同（乘正数，方向不变）                        |
| 2. 去括号    | 利用分配律展开                    | 相同                                  |
| 3. 移项     | 将含未知数的项移至一边，常数项移至另一边       | 相同（基于序公理加法性质，移项本身不变号）               |
| 4. 合并同类项  | 化为 $ax > b$ 或 $ax < b$ 的形式 | 相同                                  |
| 5. 系数化为 1 | 两边同除以 $a$                  | ⚠️ **不同**，若 $a>0$ 方向不变，若 $a<0$ 方向改变 |

> 第 5 步是本方法的核心。与方程解法相比，80% 的步骤完全一致，仅在最后的「除以系数」时需多一个判断：系数为正则方向不变，系数为负则方向反转。

````ad-example
title: 示例 | Example


解不等式 $3x + 5 > 14$。

---

按照五步法：
1. 无需去分母。
2. 无需去括号。
3. 移项：$3x > 14 - 5$，即 $3x > 9$。
4. 合并同类项：已为 $3x > 9$ 形式。
5. 系数化为 1：系数 $3 > 0$，方向不变。$x > 9/3$，即 $x > 3$。

因此所有大于 $3$ 的实数均满足该不等式。
````

````ad-example
title: 示例 | Example


解不等式 $-2x + 7 \le 1$。

---

按照五步法：
1. 无需去分母。
2. 无需去括号。
3. 移项：$-2x \le 1 - 7$，即 $-2x \le -6$。
4. 合并同类项：已为 $-2x \le -6$ 形式。
5. 系数化为 1：系数 $-2 < 0$，⚠️ **方向改变**。
$x \ge (-6)/(-2)$，即 $x \ge 3$。

因此所有大于或等于 $3$ 的实数均满足该不等式。
````

````ad-example
title: 示例 | Example


解不等式 $\displaystyle \frac{2x - 1}{3} - \frac{x + 2}{4} > 1$。

---

1. 去分母：两边乘 12（LCM of 3, 4）：$4(2x - 1) - 3(x + 2) > 12$。
2. 去括号：$8x - 4 - 3x - 6 > 12$。
3. 移项：$8x - 3x > 12 + 4 + 6$，即 $5x > 22$。
4. 合并：已为 $5x > 22$ 形式。
5. 系数化为 1：系数 $5 > 0$，方向不变。$x > 22/5$。

因此所有大于 $22/5$ 的实数均满足该不等式。
````

### 11.2.2　几何表示 (Geometric Representation)

> 将不等式解转化为数轴上的图形，以几何直觉辅助理解解的范围。

````ad-def
title: 定义（数轴上的图示规则） | Definition（Rules for Number Line Representation）


1. **方向：** $>$ 或 $\ge$ 向右画箭头 $\rightarrow$；$<$ 或 $\le$ 向左画箭头 $\leftarrow$。
2. **端点：**
  - **空心圆 (Open Circle, $\circ$)：** 表示**不包含**该端点（对应 $>$ 或 $<$，即严格不等式）。
  - **实心点 (Solid Dot, $\bullet$)：** 表示**包含**该端点（对应 $\ge$ 或 $\le$）。
````

**图示对照表 (Summary of Representations)**

| 不等式 | 端点类型 | 数轴方向 |
|:------:|:--------:|:--------:|
| $x > a$ | 空心 $\circ$ | 向右 $\rightarrow$ |
| $x \ge a$ | 实心 $\bullet$ | 向右 $\rightarrow$ |
| $x < a$ | 空心 $\circ$ | 向左 $\leftarrow$ |
| $x \le a$ | 实心 $\bullet$ | 向左 $\leftarrow$ |
| $a < x < b$ | 两端空心 $\circ$ | — |
| $a \le x < b$ | 左实右空 | — |
| $a < x \le b$ | 左空右实 | — |
| $a \le x \le b$ | 两端实心 $\bullet$ | — |

````ad-example
title: 示例 | Example


将不等式 $x > -2$ 的解以数轴表示。

---

```tikz
\begin{document}
\begin{tikzpicture}[>=stealth]
\draw[->] (-3.6,0) -- (3.6,0);
\foreach \x in {-3,-2,...,3}{\draw (\x,0.08) -- (\x,-0.08) node[below] {\x};}
\draw (-2,0) -- (-2,0.7);
\draw[->] (-2,0.7) -- (3.3,0.7);
\draw[fill=white] (-2,0.7) circle (2pt);
\node[above] at (0.8,0.7) {$x>-2$};
\end{tikzpicture}
\end{document}
```

图 11-1：$x > -2$ 的解——在数线上方 $x = -2$ 处以空心圆 $\circ$ 为起点，向右画箭头。

- **数轴图示：** 在 $x = -2$ 处以空心圆为起点，向右画箭头。
- **解释：** $>$ 为严格不等式，端点 $-2$ 不包含，故用空心圆 $\circ$；向右箭头表示 $x$ 可取所有大于 $-2$ 的实数。解可写作 $x > -2$。
````

````ad-example
title: 示例 | Example


将不等式 $-1 \le x < 4$ 的解以数轴表示。

---

```tikz
\begin{document}
\begin{tikzpicture}[>=stealth]
\draw[->] (-2.6,0) -- (5.6,0);
\foreach \x in {-2,-1,...,5}{\draw (\x,0.08) -- (\x,-0.08) node[below] {\x};}
\draw (-1,0) -- (-1,0.7);

```

图 11-2：$-1 \le x < 4$ 的解——在数线上方以实心点 $\bullet$（$x = -1$）与空心圆 $\circ$（$x = 4$）为端点，以线段连接。

- **数轴图示：** 在 $x = -1$ 处以实心点为起点，在 $x = 4$ 处以空心圆为终点，两点之间以线段连接。
- **解释：** $\le$ 包含端点 $-1$，故用实心点 $\bullet$；$<$ 不包含端点 $4$，故用空心圆 $\circ$。解可写作 $-1 \le x < 4$。
````

## 11.3　不等式技巧 (Inequality Techniques)

> **本节难度上限**：T B- ｜ C C ｜ E C ｜ Q C

> 本节介绍一些基于序性质与平方非负性的常用不等式技巧，为后续章节中的不等式证明打下基础。

### 11.3.1　平方的非负性 (Non-negativity of Squares)

````ad-thm
title: 定理（平方的非负性） | Theorem（Non-negativity of Squares）


对任意实数 $x$，$x^2 \ge 0$，且等号成立当且仅当 $x = 0$。
````

````ad-proof
title: 证明 | Proof

分三种情形讨论：

1. **$x > 0$：** 由序公理乘法性质，$x \cdot x > 0$，即 $x^2 > 0$。
2. **$x < 0$：** 由变号法则，$-x > 0$。由序公理乘法性质，$(-x)(-x) > 0$。而 $(-x)(-x) = x^2$（负负得正，已在 [[Chapter 1 数系(I)|Ch01]] 中证），故 $x^2 > 0$。
3. **$x = 0$：** $x^2 = 0$。

综上，$x^2 \ge 0$，且等号成立当且仅当 $x = 0$。
````

````ad-example
title: 示例 | Example


证明 $x^2 + 1 \ge 1$ 对所有实数 $x$ 成立。

---

由平方的非负性，$x^2 \ge 0$。两边同加 $1$ 得 $x^2 + 1 \ge 1$。
````

### 11.3.2　由平方非负性证明不等式 (Proving Inequalities via Non-negativity)

````ad-thm
title: 定理（基本不等式） | Theorem（Basic Inequality）


对任意实数 $a, b$，$a^2 + b^2 \ge 2ab$，且等号成立当且仅当 $a = b$。
````

````ad-proof
title: 证明 | Proof

由平方的非负性，$(a - b)^2 \ge 0$。

展开 $(a - b)^2 = a^2 - 2ab + b^2$，故 $a^2 - 2ab + b^2 \ge 0$。

由序公理加法性质，两边同加 $2ab$ 得 $a^2 + b^2 \ge 2ab$。

等号成立当且仅当 $(a - b)^2 = 0$，即 $a = b$。
````

````ad-example
title: 示例 | Example


证明 $x^2 + 4 \ge 4x$ 对所有实数 $x$ 成立。

---

注意 $x^2 - 4x + 4 = (x - 2)^2$，故 $(x - 2)^2 \ge 0$（平方的非负性），即 $x^2 - 4x + 4 \ge 0$。

移项得 $x^2 + 4 \ge 4x$。
````

````ad-example
title: 示例 | Example


证明 $a^2 + 1 \ge 2a$ 对所有实数 $a$ 成立。

---

这是基本不等式 $a^2 + b^2 \ge 2ab$ 中令 $b = 1$ 的特例：

$$a^2 + 1^2 \ge 2a \cdot 1$$

即 $a^2 + 1 \ge 2a$。
````

````ad-example
title: 示例 | Example


证明 $2(a^2 + b^2) \ge (a + b)^2$ 对所有实数 $a, b$ 成立。

---

计算差值：

$$2(a^2 + b^2) - (a + b)^2 = 2a^2 + 2b^2 - a^2 - 2ab - b^2 = a^2 - 2ab + b^2 = (a - b)^2$$

由平方的非负性，$(a - b)^2 \ge 0$，故 $2(a^2 + b^2) \ge (a + b)^2$。
````

### 11.3.3　放缩法 (Bounding)
> 放缩法的核心思想：利用已知的不等关系，将表达式中的某些项「放大」或「缩小」，从而得到所需的不等式。最基本的应用是利用 $x^2 \ge 0$，将平方项替换为 $0$，得到表达式的下界。

````ad-thm
title: 定理（配方恒等式） | Theorem（Completing the Square）

对任意实数 $x$ 与 $a$，$x^2 + 2ax \equiv (x + a)^2 - a^2$；对任意实数 $c$，$x^2 + 2ax + c \equiv (x + a)^2 + (c - a^2)$。

> 配方必须先以本恒等式为依据（展开即可验证），不得对含字母系数的式子凭空配方。
````

````ad-proof
title: 证明 | Proof

展开右边（完全平方公式）：

$$(x + a)^2 - a^2 = x^2 + 2ax + a^2 - a^2 = x^2 + 2ax$$

两边同加 $c$ 即得第二式。
````

````ad-example
title: 示例 | Example


证明 $x^2 + 5 > 4$ 对所有实数 $x$ 成立。

---

由 $x^2 \ge 0$，将 $x^2$ 放缩为 $0$：

$$x^2 + 5 \ge 0 + 5 = 5 > 4$$

故 $x^2 + 5 > 4$。
````

````ad-example
title: 示例 | Example


证明 $x^2 + 2x + 3 > 0$ 对所有实数 $x$ 成立。

---

由配方恒等式，取 $a = 1$、$c = 3$（此时 $c - a^2 = 2$）：$x^2 + 2x + 3 = (x + 1)^2 + 2$。

由平方的非负性，$(x + 1)^2 \ge 0$，将 $(x + 1)^2$ 放缩为 $0$：

$$(x + 1)^2 + 2 \ge 0 + 2 = 2 > 0$$

故 $x^2 + 2x + 3 > 0$。
````

### 11.3.4　同向不等式的加法 (Addition of Same-Direction Inequalities)

````ad-thm
title: 定理（同向不等式的加法） | Theorem（Addition of Same-Direction Inequalities）


若 $a > b$ 且 $c > d$，则 $a + c > b + d$。
````

````ad-proof
title: 证明 | Proof

由序公理加法性质，$a > b \implies a + c > b + c$。

又 $c > d$，两边同加 $b$ 得 $b + c > b + d$。

由传递性，$a + c > b + d$。
````

> 同向不等式可以相加，但不能直接相乘。例如 $-1 > -2$ 且 $-1 > -3$，但 $(-1)(-1) = 1 < 6 = (-2)(-3)$。乘法情形须考虑各项正负，留待后续章节讨论。

````ad-example
title: 示例 | Example


已知 $x > 3$ 且 $y > 5$，求 $x + y$ 的范围。

---

由同向不等式的加法：

$$x + y > 3 + 5 = 8$$

故 $x + y > 8$。
````

````ad-example
title: 示例 | Example


已知 $a > 2$ 且 $b > -1$，求 $a + b$ 的范围。

---

由同向不等式的加法：

$$a + b > 2 + (-1) = 1$$

故 $a + b > 1$。
````

## 11.4　章末总结

1. **序性质回顾：** 三歧性与传递性构成实数的全序结构。加法保持序、正数乘法保持序、负数乘法逆转序——三条性质是不等式运算的全部逻辑基础。
2. **变号法则：** $x > y \implies -x < -y$。乘以 $-1$（或移项到对面）不等号反转，初学者最频繁的错误即遗漏此步。
3. **一元一次不等式：** 由不等号连接两个多项式所构成，化简后所得多项式若为一元一次多项式，则为一元一次不等式。其求解步骤与解一元一次方程 90% 一致，仅在「系数化为 1」时须根据 $a$ 的正负决定是否变号。
4. **解的公式：** $a > 0$ 时解为 $x > -b/a$；$a < 0$ 时解为 $x < -b/a$。一元一次不等式的解必为一个无限延伸的范围。
5. **几何表示：** 不等式解以数轴图示——空心圆 $\circ$ 对应严格不等式，实心点 $\bullet$ 对应非严格不等式。
6. **不等式技巧：** 平方恒非负（$x^2 \ge 0$）是证明不等式的基本工具。由此可得基本不等式 $a^2 + b^2 \ge 2ab$。放缩法利用 $x^2 \ge 0$ 将平方项替换为 $0$ 以获得下界；配方须以恒等式 $x^2 + 2ax \equiv (x + a)^2 - a^2$ 为依据。同向不等式可相加但不能直接相乘。
