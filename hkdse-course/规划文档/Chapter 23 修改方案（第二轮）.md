## 二、逐类详细方案

### A. 定义修正：实多项式 vs 实系数多项式（L46-49）

**注释原文：**
> 实多项式跟实系数多项式是不同的，讲义后面说了实系数多项式的共轭复根，但这跟这里的定义有矛盾，因为这里的实系数多项式不能接受复数输入。需要修复。
> 建议单独拎出 "实系数多项式" 到下方的术语板块。

**问题分析：**

当前定义（二）单变量实多项式为 $P: \mathbb{R} \to \mathbb{R}$，即定义域和值域都是实数。但后面 §23.4.2③ 的共轭根定理讨论"实系数多项式"时，$P(x)$ 接受复数输入（$z \in \mathbb{C}$），只是系数为实数。两者矛盾。

**修改方案：**

重构「多项式函数」定义的三个部分：

**（一）单变量多项式**（不变）：$P: \mathbb{C} \to \mathbb{C}$，$P(z) = a_n z^n + \cdots + a_0$，$a_i \in \mathbb{C}$，集合记 $\mathbb{C}[z]$。

**（二）单变量实多项式**（修改）：$P: \mathbb{R} \to \mathbb{R}$，$P(x) = a_n x^n + \cdots + a_0$，$a_i \in \mathbb{R}$，集合记 $\mathbb{R}[x]$。**强调**：这是一个**实函数**——只接受实数输入，输出实数。当后面讨论复根时，需要将 $P$ 视为复多项式（见下方"实系数多项式"）。

**（三）术语**（新增"实系数多项式"条目）：
- 原有术语（首项、首项系数、常数项、零多项式、次数）保持不变
- **新增**：**实系数多项式 (real-coefficient polynomial)**：系数 $a_i \in \mathbb{R}$ 的单变量多项式，即 $\mathbb{R}[x]$ 中的元素。**注意**：实系数多项式作为 $\mathbb{C}[z]$ 的子集，可以接受复数输入（$P(z)$，$z \in \mathbb{C}$），只是系数为实数。这与（二）中的"单变量实多项式"（$\mathbb{R} \to \mathbb{R}$ 的实函数）不同——后者不能接受复数输入。
- 共轭根定理（§23.4.2③）讨论的是**实系数多项式**（$\mathbb{R}[x]$），而非"实多项式函数"（$\mathbb{R} \to \mathbb{R}$）。

**（二）与（三）之间加过渡段**：说明"实多项式"与"实系数多项式"的区别——前者是函数（$\mathbb{R} \to \mathbb{R}$），后者是代数对象（$\mathbb{R}[x] \subset \mathbb{C}[z]$），后者可以接受复数输入。

### C. 长除法示例增强：逐步构造列式（L246-248）

**注释原文：**
> 下面的三个例子中，我希望一步步构造长除法列式的过程。

**问题分析：**

当前三个长除法示例中，文字步骤与最终列式分离——文字描述"第一轮""第二轮"等过程，最终给一个完整的 array 竖式。用户希望看到列式如何逐步构建。

**修改方案：**

为每个示例添加逐步演变的列式。以示例 1（$(z^3 - 2z^2 + 3z - 1) \div (z - 2)$）为例：

**初始列式**（被除式与除式就位，商式为空）：

$$\begin{array}{r} \phantom{z^2 + 3} \\[-3pt] z - 2 \,\overline{\big)\, z^3 - 2z^2 + 3z - 1} \end{array}$$

**第一轮后**（商式首项 $z^2$，相减得 $3z - 1$）：

$$\begin{array}{r} z^2 \phantom{{}+3} \\[-3pt] z - 2 \,\overline{\big)\, z^3 - 2z^2 + 3z - 1} \\[-3pt] \underline{-(z^3 - 2z^2\phantom{{}+3z-1})} \\ 3z - 1 \end{array}$$

**第二轮后**（商式加 $+3$，相减得 $5$）：

$$\begin{array}{r} z^2 + 3 \\[-3pt] z - 2 \,\overline{\big)\, z^3 - 2z^2 + 3z - 1} \\[-3pt] \underline{-(z^3 - 2z^2\phantom{{}+3z-1})} \\ 3z - 1 \\ \underline{-(3z - 6)} \\ 5 \end{array}$$

**三个示例均如此处理：**

1. **示例 1**（$(z^3 - 2z^2 + 3z - 1) \div (z - 2)$）：初始 → 第一轮 → 第二轮（终态）
2. **示例 2**（$(z^4 + 1) \div (z^2 + 1)$）：初始 → 第一轮 → 第二轮（终态）
3. **示例 3**（$(z^3 - 3z^2 + 3z - 1) \div (z - 1)$）：初始 → 第一轮 → 第二轮 → 第三轮（终态）

每个示例的文字步骤保留，在对应步骤后插入当前列式状态。最终列式保留在示例末尾。

### D. 新增章节：待定系数法求商式与余式（L329-335）

**注释原文：**
> 新建一个章节，讲述如何利用对比系数法（或叫待定系数法）求对应的商式跟余式。
> 1. 对内容详细度的要求跟这份讲义一样，相当于续写内容。
> 2. 同时要搭配大量示例与题目。
> 3. 要注明这跟第四章、第六章介绍的对比系数法本质相同。只不过是基于多项式除法算法进行的。
> 4. 需要特别讲明技巧：要利用多项式的次数限制，设出多向式的结构。

**修改方案：**

新增 **§23.2.3　待定系数法求商式与余式**，位于 §23.2.2（长除法）之后。

#### 内容结构

**引入段：**
> 长除法提供了执行除法算法的具体步骤，但需要逐项计算。当除式次数较高或被除式较复杂时，长除法可能繁琐。本节介绍另一种方法——**待定系数法 (method of undetermined coefficients)**：利用除法算式 $P(z) \equiv D(z) Q(z) + R(z)$ 是恒等式的性质，设出 $Q(z)$ 与 $R(z)$ 的一般形式（含待定系数），展开比较系数求解。

**核心原理：**

由除法算法，$P(z) \equiv D(z) Q(z) + R(z)$，其中 $\deg R < \deg D$。若 $P, D$ 已知，$Q, R$ 未知，则：
1. $\deg Q = \deg P - \deg D$（次数确定）
2. $\deg R < \deg D$（次数限制）
3. 由此可设 $Q(z)$ 与 $R(z)$ 的一般形式（含待定系数）
4. 代入除法算式展开，比较对应系数，得到方程组求解

**与第四章、第六章的联系：**

对比系数法在第四章（多项式相等的等价条件）和第六章（恒等式中待定系数求未知量）已介绍。此处将其应用于除法算式，本质相同：两个多项式恒等当且仅当对应系数相等。区别在于：此处利用**次数限制**确定 $Q$ 与 $R$ 的结构，这是除法算法赋予的额外信息。

**技巧强调：**

设商式与余式的结构时，关键是利用次数限制：
- 若 $\deg P = n$，$\deg D = d$，则 $\deg Q = n - d$，设 $Q(z) = q_{n-d} z^{n-d} + \cdots + q_1 z + q_0$
- $\deg R < d$，设 $R(z) = r_{d-1} z^{d-1} + \cdots + r_1 z + r_0$（当 $d = 1$ 时 $R = r_0$ 为常数）

**Admonition 环境：**
- `ad-alg`：待定系数法求商式与余式的步骤
- `ad-note`：与 Ch04/Ch06 对比系数法的联系
- `ad-example`：3-4 道例题

**例题设计：**

1. **示例 1**：除式为一次式。求 $(2z^3 - 3z^2 + z - 5) \div (z - 1)$ 的商式与余式。
   - 设 $Q(z) = az^2 + bz + c$，$R = r$，展开 $(z-1)(az^2+bz+c) + r$ 比较系数。

2. **示例 2**：除式为二次式。求 $(z^4 + 2z^3 - z + 3) \div (z^2 + z + 1)$ 的商式与余式。
   - 设 $Q(z) = az^2 + bz + c$，$R(z) = dz + e$，展开 $(z^2+z+1)(az^2+bz+c) + (dz+e)$ 比较系数。

3. **示例 3**：含零系数项。求 $(z^3 + 1) \div (z^2 - 1)$ 的商式与余式。
   - 被除式缺 $z^2$ 项与 $z$ 项，设 $Q(z) = az + b$，$R(z) = cz + d$。

4. **示例 4**：验证结果。用长除法验证示例 1 的结果，对比两种方法。
