### §23.1　单变量多项式的记法与基本概念

**内容：**
- 回顾 Ch04：多项式由单项式的和构成。当仅含一个变量时，即为单变量多项式
- **定义（单变量多项式）**：形如 $P: \mathbb{C} \to \mathbb{C},\ P(z) = a_n z^n + \cdots + a_1 z + a_0$ 的函数，$a_i \in \mathbb{C}$（或 $\mathbb{R}$），$n \in \mathbb{N}_0$
  - 首项、首项系数、常数项、零多项式
  - 全体单变量多项式构成的集合记为 $\mathbb{C}[z]$（或 $\mathbb{R}[z]$）
  - 次数 $\deg P$；零多项式定义 $\deg 0 = -1$
- **将多项式视为函数的意义**：多项式定义了一个映射，使「代入求值」$P(a)$ 成为函数求值的自然结果
- **变量记号约定**：本章以 $z$ 为通用变量；当明确限定 $\mathbb{R}$ 时写回 $x$
- **定义（首一多项式）**：首项系数为 $1$ 的非零多项式；任意非零多项式可化为首一形式
- **定理（单变量多项式相等的等价条件）**：次数相同 + 各项系数相等（Ch04 定理 4.2 的特例）

**Admonition 环境：**
- `ad-def`：单变量多项式、首一多项式
- `ad-thm`：多项式相等的等价条件
- `ad-note`：将多项式视为函数的意义、变量记号约定

**例题设计：**
1. 判断给定表达式是否为单变量多项式；若是，指出次数、首项系数、常数项
2. 将多项式化为首一形式

### §23.2　单变量多项式的除法

**内容：**
- 类比整数的带余除法，单变量多项式也存在唯一的除法算法
- **定理（多项式除法算法）**：设 $P(z), D(z) \neq 0$，存在唯一的 $Q(z)$ 和 $R(z)$ 使 $P(z) = D(z) Q(z) + R(z)$，其中 $\deg R < \deg D$ 或 $R = 0$
  - 被除式、除式、商式、余式
  - 证明（存在性用归纳，唯一性用反证）——存在性证明可详述，唯一性简述
- **定义（整除）**：$D(z) \mid P(z) \iff \exists Q(z),\ P = DQ \iff$ 余式 $R = 0$
  - 因式、倍式
- **长除法**（ad-alg）：步骤化呈现——降幂排列 → 首项相除得商项 → 乘除式后相减 → 重复至余式次数 < 除式次数
  - 与整数长除法的类比（位值 vs 幂次）

**Admonition 环境：**
- `ad-thm`：除法算法
- `ad-proof`：除法算法（存在性 + 唯一性）
- `ad-def`：整除
- `ad-alg`：长除法步骤
- `ad-note`：与整数除法的类比

**例题设计：**
1. 用长除法求 $P(z) \div D(z)$ 的商式与余式（如 $(z^3 - 2z^2 + 3z - 1) \div (z - 2)$）
2. 求 $P(z) \div (z^2 + 1)$ 的商式与余式（除式为二次式，余式为一次式）
3. 判断 $D(z)$ 是否整除 $P(z)$

### §23.3　余式定理

**内容：**
- 当除式为一次式 $(z-a)$ 时，除法算法有简洁推论
- **定理（余式定理）**：$P(z)$ 除以 $(z-a)$ 的余式 $= P(a)$
  - 证明：$P(z) = (z-a) Q(z) + R$，$\deg R < 1$ 故 $R$ 为常数；代入 $z = a$ 得 $R = P(a)$
- **推论**：$P(z)$ 除以 $(az-b)$ 的余式 $= P(b/a)$（$a \neq 0$）
- 余式定理的意义：无需执行长除法即可计算余式——仅需代入求值

**Admonition 环境：**
- `ad-thm`：余式定理
- `ad-proof`：余式定理证明
- `ad-cor`：$(az-b)$ 的余式
- `ad-note`：余式定理的意义

**例题设计：**
1. 已知 $P(z) = z^3 - 4z^2 + 5z - 2$，求 $P(z) \div (z-1)$ 的余式（代入 $P(1)$）
2. 已知 $P(z) \div (2z - 3)$ 的余式为 $5$，求 $P(3/2)$
3. 求 $P(z)$ 除以 $(z^2 + 1)$ 的余式（**非一次式**，须用长除法；此题对比余式定理的适用范围）

### §23.4　因式与根的关系

> 本节是本章核心。先建立因式定理（因式与根的基本双向等价），再分 $\mathbb{R}$ 和 $\mathbb{C}$ 两个层次深化根与因式的结构关系，最后将理论应用于系统化分解多项式。

#### §23.4.1　因式定理

**内容：**
- **定理（因式定理）**：$(z-a) \mid P(z) \iff P(a) = 0$
  - 证明：由余式定理，余式 $= P(a)$；整除 $\iff$ 余式 $= 0 \iff P(a) = 0$
- **定义（多项式的根）**：若 $P(a) = 0$，称 $a$ 为 $P(z)$ 的根（零点）
- 因式定理建立了根与因式之间的第一层联系——每个根对应一个一次因式

**Admonition 环境：**
- `ad-thm`：因式定理
- `ad-proof`：因式定理证明
- `ad-def`：根

**例题设计：**
1. 判断 $(z-2)$ 是否为 $P(z) = z^3 - z - 6$ 的因式
2. 已知 $(z+1)$ 是 $P(z) = z^3 + kz^2 - 3z - 4$ 的因式，求 $k$

#### §23.4.2　根与因式的深层关系

> 因式定理告诉我们「一个根 $\iff$ 一个一次因式」。本节分两个层次深化：先在 $\mathbb{R}$ 上讨论重根、根数上界及结构定理，再提升至 $\mathbb{C}$ 彻底解决根的结构问题，最后回到 $\mathbb{R}$ 明确不可约因式分类。

**① 重根与因式的整除性质**

- **定义（重根与重数）**：若 $(z-a)^m \mid P(z)$ 但 $(z-a)^{m+1} \nmid P(z)$，称 $a$ 为 $m$ 重根
  - 单根（$m=1$）、二重根（$m=2$）、重根（$m \ge 2$）
  - 重数概念对 $\mathbb{R}$ 和 $\mathbb{C}$ 均适用
- **定理（因式的整除传递性）**：若 $(z-a) \mid A(z)B(z)$ 且 $(z-a) \nmid A(z)$，则 $(z-a) \mid B(z)$
  - 证明：$P(a) = A(a)B(a) = 0$，$A(a) \neq 0$ 故 $B(a) = 0$
  - **与数论的对照**：此定理是欧几里得引理（Ch01）的多项式版本——一次因式在多项式中扮演质数的角色
  - 对照表：数论（$\mathbb{Z}$）vs 多项式（$\mathbb{C}[z]$）

**Admonition 环境：**
- `ad-def`：重根与重数
- `ad-thm`：因式的整除传递性
- `ad-proof`：整除传递性证明
- `ad-note`：与欧几里得引理的对照（含对照表）

**② 实数域 $\mathbb{R}$ 上的结构**

- **定理（$n$ 次多项式的根数上界）**：非零 $n$ 次多项式在 $\mathbb{R}$（或任意域）中至多有 $n$ 个不同的根
  - 证明：$k$ 个不同根 $\implies \prod (x-a_i) \mid P(x) \implies k \le n$
  - 推论：根多于 $n$ 个 $\implies$ 零多项式
- **定理（实数域上的根—因式结构）**：$P(x) = a_n \prod (x-a_i)^{m_i} \cdot Q(x)$，$Q(x)$ 无实根
  - 证明思路：反复应用因式定理及除法算法
  - 注：$Q(x)$ 无实根不意味不可再分解（如 $x^4+1$），须提升至 $\mathbb{C}$ 彻底解决

**Admonition 环境：**
- `ad-thm`：根数上界、$\mathbb{R}$ 上的根—因式结构
- `ad-proof`：根数上界证明
- `ad-note`：$Q(x)$ 无实根的局限

**③ 提升至复数域 $\mathbb{C}$**

- 回顾 Ch17：$\mathbb{C}$ 是 $\mathbb{R}$ 的扩张，使每个非常数多项式都有根
- **定理（代数基本定理）**：次数 $n \ge 1$ 的复系数多项式在 $\mathbb{C}$ 中至少有一个根
  - 证明超出 DSE 范围，作为已知事实接受
- **推论（$\mathbb{C}$ 上的完全因式分解）**：$P(z) = a_n (z-z_1)(z-z_2)\cdots(z-z_n)$（计重数）
  - 证明思路：反复应用代数基本定理及除法算法
  - 对照定理 23.8：$\mathbb{R}$ 上 $Q(x)$ 未必为常数；$\mathbb{C}$ 上 $Q(z) = a_n$（常数）
- **定理（共轭根定理）**：实系数多项式的非实复根成对出现（$z$ 与 $\overline{z}$ 同为根且重数相同）
  - 证明：$P(\overline{z}) = \overline{P(z)} = \overline{0} = 0$（利用 $\overline{a_i} = a_i$ 及共轭运算性质）
- **推论（实系数多项式在 $\mathbb{R}$ 上的不可约因式）**：仅有两类——一次式 $(x-a)$ 及 $\Delta < 0$ 的二次式 $x^2+px+q$
  - 证明思路：由完全分解 + 共轭根定理，成对复根对应实系数二次式

**Admonition 环境：**
- `ad-thm`：代数基本定理、共轭根定理
- `ad-cor`：$\mathbb{C}$ 上完全分解、$\mathbb{R}$ 上不可约因式
- `ad-proof`：共轭根定理证明
- `ad-note`：代数基本定理超纲说明、与定理 23.8 的对照

**TikZ 插图：**
- 图 23-2：复平面上共轭根对的 Argand diagram（$z = a+bi$ 与 $\overline{z} = a-bi$ 关于实轴对称）

**④ $\mathbb{R}$ 与 $\mathbb{C}$ 的小结**

- 对照表：域 / 根的存在性 / 因式分解结构 / 不可约因式
- 三种表示方式对照：标准展开式 / $\mathbb{R}$ 上的根—因式式 / $\mathbb{C}$ 上的完全分解

**例题设计：**
1. 判断 $z = 2$ 是 $P(z) = z^3 - 4z^2 + 5z - 2$ 的几重根
2. 已知 $P(x) = x^3 - 3x^2 + 4$ 有一个实根 $x = -1$，完成在 $\mathbb{R}$ 上的因式分解
3. 实系数多项式 $P(x) = x^4 - 5x^3 + 9x^2 - 7x + 2$ 已知一根为 $2+i$，求 $P(x)$ 在 $\mathbb{R}$ 上的因式分解
4. 判断 $x^4 + 1$ 在 $\mathbb{R}$ 上是否可约；若可约，给出分解

#### §23.4.3　因式定理与除法算法的协同：分解多项式

**内容：**
- 因式定理负责「检测」——判断 $(z-a)$ 是否为因式
- 除法算法负责「提取」——将该因式从多项式中分离
- 两者协同构成「检测 → 提取」的迭代循环
- 分工对照表：步骤 / 所用定理 / 作用
- **算法（利用除法算法分解多项式）**：
  1. 寻找候选根（有理根定理备注：$\pm p/q$，$p \mid a_0$，$q \mid a_n$；实务上亦可试 $P(0), P(\pm 1), \dots$）
  2. 检测（因式定理）：代入 $a$，若 $P(a) = 0$ 则 $(z-a)$ 为因式
  3. 提取（除法算法）：长除法得 $P(z) = (z-a) Q(z)$，$\deg Q = \deg P - 1$
  4. 检查重数：对 $Q(z)$ 再次检测 $Q(a)$
  5. 迭代：以 $Q(z)$ 为新的 $P(z)$ 继续
  - 终止条件：$\mathbb{R}$ 上无法再找到有理根或剩余二次式；$\mathbb{C}$ 上由代数基本定理保证完全分解
- 算法的效率来自除法算法的降次性质——每次降次 $1$，保证有限终止

**Admonition 环境：**
- `ad-alg`：分解多项式的算法
- `ad-note`：算法有限终止性说明、有理根定理备注

**例题设计：**
1. 完全分解 $P(x) = x^3 - 6x^2 + 11x - 6$（根为 $1, 2, 3$）
2. 完全分解 $P(x) = x^4 - 2x^3 - 3x^2 + 4x + 4$（含二重根）
3. 分解 $P(x) = x^3 + x - 2$（有一个实根，剩余二次式判别式 $< 0$）

### §23.5　最大公因式与最小公倍式

**内容：**
- 将整数的 HCF 与 LCM 概念迁移至单变量多项式
- 核心方法依赖**完全因式分解**——在 $\mathbb{R}$ 上分解至一次及不可约二次因式，在 $\mathbb{C}$ 上分解至一次因式

#### §23.5.1　最大公因式

- **定义（单变量多项式的 HCF）**：$P(x) = k \prod f_i(x)^{p_i}$，$Q(x) = \ell \prod f_i(x)^{q_i}$（首一形式），则 $\text{HCF}(P,Q) = \prod f_i(x)^{\min(p_i, q_i)}$
- **算法（求 HCF）**：完全因式分解 → 归一化首一 → 找公共因式 → 取最低次幂 → 系数取 H.C.F.

#### §23.5.2　最小公倍式

- **定义（单变量多项式的 LCM）**：$\text{LCM}(P,Q) = \prod f_i(x)^{\max(p_i, q_i)}$
- **算法（求 LCM）**：完全因式分解 → 归一化首一 → 找所有因式 → 取最高次幂 → 系数取 L.C.M.

#### §23.5.3　HCF 与 LCM 的关系

- **定理**：$\text{HCF}(P,Q) \cdot \text{LCM}(P,Q) \sim P(x) \cdot Q(x)$（忽略常数因子）
  - 证明思路：$\min(p_i, q_i) + \max(p_i, q_i) = p_i + q_i$

#### §23.5.4　与整数的类比

- 对照表：概念 / 整数 / 单变量多项式
- 基本构成单元、规范化约定、HCF、LCM、HCF×LCM

#### §23.5.5　有理函数的运算（应用）

- 回顾 Ch04 代数分式：先因式分解再约分
- 约分：分子分母同除以 HCF
- 通分：分母取 LCM
- 加减乘除：约分与通分的综合应用

**Admonition 环境：**
- `ad-def`：HCF、LCM
- `ad-alg`：求 HCF 步骤、求 LCM 步骤
- `ad-thm`：HCF·LCM 关系
- `ad-proof`：HCF·LCM 关系证明思路
- `ad-note`：与整数的类比（含对照表）

**例题设计：**
1. 求 $P(x) = x^2 - 4$ 与 $Q(x) = x^2 + 4x + 4$ 的 HCF 与 LCM
2. 化简有理分式 $\dfrac{x^2 - 1}{x^2 + 2x + 1}$（约分应用）
3. 计算 $\dfrac{1}{x^2 - 1} + \dfrac{1}{x - 1}$（通分应用）

## 八、备课提示预案

1. **变量记号 $z$ 的引入**：本章以 $z$ 为通用变量，因所述定理对 $\mathbb{C}$ 和 $\mathbb{R}$ 均成立。须在 §23.1 明确约定：当上下文限定 $\mathbb{R}$ 时写回 $x$。提醒学生 $z$ 与 $x$ 的切换不是随意的，而是域的标识。

2. **除法算法的定位**：除法算法是本章的核心结构定理——它保证了商式与余式的存在性与唯一性，是余式定理与因式定理的理论根基。存在性证明用归纳法（对 $\deg P$），唯一性用反证法。建议存在性详讲，唯一性简述。

3. **余式定理 vs 长除法**：余式定理仅适用于除式为一次式 $(z-a)$ 的情形。当除式为高次式（如 $z^2+1$）时，必须用长除法。这是学生常犯的错误——见 §23.3 例题 3。

4. **因式定理的「检测—提取」循环**：因式定理负责检测（判断 $(z-a)$ 是否为因式），除法算法负责提取（将该因式分离）。每次提取降次 $1$，保证有限终止。这是系统化分解多项式的核心机制，须让学生动手执行完整流程。

5. **$\mathbb{R}$ vs $\mathbb{C}$ 的对照**：本章最深刻的结论是「实系数多项式在 $\mathbb{C}$ 上可完全分解为一次因式之积，在 $\mathbb{R}$ 上则分解为一次式与 $\Delta<0$ 的二次式之积」。须用对照表强化，并用具体例子（如 $x^4+1$）说明 $Q(x)$ 无实根但仍可分解为二次式。

6. **共轭根定理的证明**：此证明简洁优美，展示了共轭运算的性质（$\overline{a_i} = a_i$ 对实系数成立）。建议完整呈现，作为「实系数」条件的关键应用。

7. **代数基本定理的处理**：证明超出 DSE 范围（需复分析或拓扑学），作为已知事实接受。须明确告知学生这是「接受」而非「证明」，避免误解。

8. **HCF/LCM 与整数的类比**：多项式 HCF/LCM 与整数 HCF/LCM 在结构上完全平行。建议用对照表呈现，帮助学生迁移已有知识。规范化约定：整数取正质数，多项式归一化为首一形式。

9. **有理根定理的定位**：作为寻找候选根的系统化工具，给结论但不证明。实务上亦可从 $P(0), P(\pm 1), P(\pm 2), \dots$ 逐个测试。强调这是「候选」，仍须用因式定理验证。

10. **TikZ 插图**：本章共 2 张插图。图 23-1 展示单根与重根的图像特征（穿过 $x$ 轴 vs 相切），帮助学生直观理解重数。图 23-2 展示复平面上的共轭根对，强化「成对出现」的几何直观。
