#### 題 1（`task` 類）——對象與命題的區分

**題干**

判斷以下各項是對象還是命題。

(a) 天空；

(b) 今天是星期三；

(c) $7$；

(d) $3 + 5 = 8$；

(e) 下雨；

(f) $x$；

(g) 小明身高 $160 \text{ cm}$；

(h) 這朵花是紅色的。

**考核目標**

掌握「對象不構成陳述句、命題是可判真假的陳述句」的區分；以日常詞語與數學式判斷。

**詳細解答**

(a) 對象。
「天空」是名詞，不構成陳述句，故只是對象。

(b) 命題。
它完整陳述了「今天是星期三」這一事實，原則上可判真假（雖需知道今天星期幾才能判定），故為命題。

(c) 對象。
數字 $7$ 是符號，本身不陳述任何事，故只是對象。

(d) 命題。
$3 + 5 = 8$ 是完整陳述句，且可判定（$3 + 5$ 確為 $8$，為真）。

(e) 命題。
「下雨」在此作陳述句用，可理解為「正在下雨」這類可判真假的陳述。

(f) 對象。
變量 $x$ 是符號，不構成陳述句，故只是對象。

(g) 命題。
它陳述了「小明身高 $160 \text{ cm}$」這一事實，可判真假（對照實際量度結果）。

(h) 命題。
它陳述了花的顏色，可判真假（觀察花即可）。

**易錯點注意**
- 易錯：把「命題」誤解為「必須已知真假」——命題只需**原則上可判真假**（如 (b)「今天是星期三」），不必當下知道答案。
- 易錯：把 (e)「下雨」當作對象——它作名詞用時確是對象，但本題句意是作陳述（正在下雨）。
- 易錯：把變量 $x$（(f)）當成命題——變量只是佔位符號，不陳述事實，這是日後區分開放命題的關鍵。

(d) $y$ 大於 $10$。

(e) 小明的書包重量為 $w \text{ kg}$。

句中不含變量，真假已確定（為真）。

(d) 開放命題。
句中含變量 $y$，真值隨 $y$ 的取值而定。

(e) 開放命題。
句中含變量 $w$（書包重量未指明），真值隨 $w$ 而定。

#### 題 3（`task` 類）——命題真值的判斷

**題干**

判斷下列命題的真值，以 $\mathbb{T}$（真）或 $\mathbb{F}$（假）表示。

(a) 太陽從東邊升起。

(b) $2 + 2 = 5$

(c) 狗是哺乳動物。

(d) $100$ 小於 $50$。

(e) 小明是小明的父親。

(f) 正方形的四條邊長度相等。

**考核目標**

以生活常識與算術事實判斷命題真假；理解「命題不一定要為真，只需可判真假」。

**詳細解答**

(a) $\mathbb{T}$。
太陽從東邊升起是天文事實，為真。

(b) $\mathbb{F}$。
$2 + 2 = 4 \neq 5$，為假。

(c) $\mathbb{T}$。
狗屬哺乳動物，為真。

(d) $\mathbb{F}$。
$100 > 50$，故「$100$ 小於 $50$」為假。

(e) $\mathbb{F}$。
父親不可能與自己兒子同一人（人不能是自己的父親），為假。

(f) $\mathbb{T}$。
正方形四邊等長是定義性質，為真。

**易錯點注意**
- 易錯：把「命題」與「真命題」混為一談——本題 (b)(d)(e) 為假，但它們仍是命題（可判真假）。
- 易錯：對 (e) 猶豫——人不能是自己的父親，這是反身矛盾，必為假。
- 易錯：判斷 (f) 時依賴記憶而非定義——正方形「四邊等長」是定義的一部分，直接由定義保證為真。

#### 題 5（`task` 類）——「$=$」與「$\iff$」用法

**題干**

以下各句中的「$=$」或「$\iff$」用法是否正確？若不正確，簡述原因。

(a) $3 + 2 = 5$

(b) $(\text{太陽從東邊升起}) = (\text{地球自轉})$

(c) $P(x) = (x \leq 10)$

(d) $(x \text{ 大於 } 5) \iff (x \text{ 不小於或等於 } 5)$

(e) $P \iff Q$ 表示「命題 $P$ 與命題 $Q$ 真值一致」。

(f) $(3 + 5 = 8) = (2 + 6 = 8)$

**考核目標**

理解「$=$ 只能作用於對象，命題之間用 $\iff$」的約定；識別定義性用法。

**詳細解答**

(a) 正確。
$3+2$ 與 $5$ 均為對象（數值），「$=$」用於斷言兩對象一致，$3+2 = 5$ 成立。

(b) 不正確。
「太陽從東邊升起」與「地球自轉」均為**命題**，兩命題之間不應用「$=$」；應寫作「（太陽從東邊升起）$\iff$（地球自轉）」以表示邏輯等價。

(c) 正確。
此處「$=$」用於**定義指派**：將命題符號 $P(x)$ 指定為開放命題 $(x \leq 10)$，屬對象（符號）之間的指定，用法正確。

(d) 正確。
「$x$ 大於 $5$」與「$x$ 不小於或等於 $5$」均為命題，兩命題之間以「$\iff$」表示邏輯等價，用法正確。

(e) 正確。
此句是對記號「$\iff$」的**定義性說明**：「$P \iff Q$ 表示 $P$ 與 $Q$ 真值一致」，屬元語言陳述，正確。

(f) 不正確。
$(3+5=8)$ 與 $(2+6=8)$ 均為**命題**，兩命題之間不應用「$=$」；正確寫法為「$(3+5=8) \iff (2+6=8)$」。

**易錯點注意**
- 易錯：誤以為「$=$」可用於任何相等的語句——命題之間必須用「$\iff$」（(b)(f) 的陷阱）。
- 易錯：混淆「定義指派」（(c) 中 $P(x)$ 被定義為某命題）與「命題間等價」——前者用 $=$，後者用 $\iff$。
- 易錯：在 (e) 中以為「$P \iff Q$」是等式——它陳述的是兩個命題的真值關係，不是對象相等。

(b) $P \land Q$

(d) $P \to Q$

(b) $P \land Q$：今天下雨且小明帶傘。

(d) $P \to Q$：若今天下雨，則小明帶傘。
條件句以「若…則…」表述。

(e) $P \leftrightarrow Q$：今天下雨當且僅當小明帶傘。

(f) $\neg Q \land P$：小明沒有帶傘且今天下雨。

**題干**

(a) $P = (\text{小明在跑步})$，$Q = (\text{小明在運動})$

(b) $P = (x = 3 + 2)$，$Q = (x = 5)$

(c) $P = (x \text{ 是正方形})$，$Q = (x \text{ 是長方形})$

(d) $P = (\text{天在下雨})$，$Q = (\text{地面是濕的})$

**考核目標**

判斷蘊含與等價關係；以「$P$ 真時 $Q$ 是否必真」判定蘊含。

**詳細解答**

(a) $P \implies Q$。
跑步是運動的一種，小明在跑步則必在運動，方向成立。
$Q \implies P$ 不成立。
運動未必是跑步（游泳、跳繩都是運動而非跑步），可舉反例：小明在游泳。
故不邏輯等價。

(b) $P \iff Q$。
$3 + 2 = 5$，故「$x = 3+2$」與「$x = 5$」陳述同一事實，兩方向均成立。
故邏輯等價。

(c) $P \implies Q$。
正方形是特殊的長方形（四邊相等且四角直角的長方形），是正方形則必是長方形。
$Q \implies P$ 不成立。
長方形不一定是正方形，可舉反例：長 $4$ 闊 $2$ 的長方形不是正方形。
故不邏輯等價。

(d) $P \implies Q$。
下雨會使地面變濕（在通常情境下），方向成立。
$Q \implies P$ 不成立。
地面濕未必因為下雨，可舉反例：灑水車灑過地面也會濕。
故不邏輯等價。

- 易錯：只檢查 $P \implies Q$ 就斷言等價——等價須**兩方向**都成立（(a)(c)(d) 均因逆方向不成立而不等價）。

#### 題 10（複雜結構類）——等式公理的應用

**題干**

根據等式公理（反身性、對稱性、傳遞性），判斷下列推理是否正確。

(a) 由反身性，可得 $5 = 5$。正確嗎？

(b) 由對稱性，若 $a = b$，則 $b = a$。若已知「小明的年齡 $=$ 小華的年齡」，能否得出「小華的年齡 $=$ 小明的年齡」？

(c) 由傳遞性，若 $a = b$ 且 $b = c$，則 $a = c$。若已知 $1 + 2 = 3$ 且 $3 = 2 + 1$，能否推出 $1 + 2 = 2 + 1$？

(d) $x = y$ 與 $y = x$ 是否互為對方成立的必要條件？依據甚麼公理？

**考核目標**

將三條等式公理應用於具體情境；理解「必要條件」與對稱性的關係。

**詳細解答**

(a) 正確。
$5 = 5$ 是「任何對象等於自身」的直接實例，由反身性公理保證。

(b) 可以。
已知「小明的年齡 $=$ 小華的年齡」，這正是 $a = b$ 的形式（$a$＝小明年齡，$b$＝小華年齡）。
由對稱性公理 $a = b \iff b = a$，得「小華的年齡 $=$ 小明的年齡」。

(c) 可以。
令 $a = 1+2$、$b = 3$、$c = 2+1$。
已知 $a = b$（$1+2 = 3$）且 $b = c$（$3 = 2+1$），由傳遞性公理得 $a = c$，即 $1 + 2 = 2 + 1$。

(d) 是。
「$x = y$ 是 $y = x$ 成立的必要條件」即「$y = x \implies x = y$」。
由對稱性公理 $a = b \iff b = a$，兩者互為充要條件（既充分又必要），故 $x = y$ 確為 $y = x$ 的必要條件，依據對稱性公理。

#### 題 11（複雜結構類）——萊布尼茨定律的應用

**題干**

運用萊布尼茨定律（同一者不可分原理）回答以下問題。

(a) 已知 $2 + 3 = 5$。若 $5$ 是奇數，則 $2 + 3$ 是甚麼數？依據甚麼定律？

(b) 已知小明與小華是同一個人（即「小明 $=$ 小華」）。若「小明喜歡吃蘋果」為真，則可推斷「小華喜歡吃蘋果」為真嗎？為甚麼？

(c) 已知 $a = b$，且 $a + 3 = 10$。能否推出 $b + 3 = 10$？依據甚麼？

(d) 已知 $x = 4$，且 $P(A) = (A^2 = 16)$。$P(x)$ 的真值為何？

**考核目標**

將萊布尼茨定律應用於具體情境；理解「相同對象具相同性質」。

**詳細解答**

(a) $2 + 3$ 也是奇數。
設性質命題 $P(A) = (A \text{ 是奇數})$。

小明 $=$ 小華（同一人）。

#### 題 12（複雜結構類）——公理、定理、推論、引理的概念

**題干**

簡要回答以下問題。

(a) 甚麼是公理（Axiom）？公理需要被證明嗎？

(b) 甚麼是定理（Theorem）？定理與公理有甚麼區別？

(c) 甚麼是推論（Corollary）？試舉一例。

(d) 甚麼是引理（Lemma）？它的作用與定理有何不同？

**考核目標**

掌握四個元概念的定義與相互區別。

**詳細解答**

(a) 公理是被定義為真命題的命題，是數學推理的出發點。
公理不需要被證明——它是推理系統的預設前提，一切證明都以公理為起點。

(b) 定理是在既定公理下的真命題。
定理與公理的區別在於**證明地位**：定理必須從公理出發經過邏輯證明才能確立，而公理是直接承認為真的前提，毋須證明。

(c) 推論是從定理直接推出的結論，通常無需冗長證明。
例：推論「$0 + a = a$」——由加法交換律，$0 + a = a + 0$；再由加法單位元 $a + 0 = a$，故 $0 + a = a$。

(d) 引理是為證明某個主要定理而準備的輔助命題。
引理與定理的作用不同：引理本身通常不是最終目標，而是證明過程中的「墊腳石」，先證引理再借助它證主定理；定理則是被證明的目標結論。

**易錯點注意**
- 易錯：把公理當成「可證明的」——公理正是因不可由更基本命題推出才被設定為前提。
- 易錯：推論的舉例須**確實由定理直接推出**，不可任意舉例；(c) 中 $0 + a = a$ 須展示由 $a - a = 0$ 推出的過程。
- 易錯：混淆引理與推論——推論是定理的「往下」即時結果，引理是主定理的「往上」準備工具，兩者方向相反。

#### 題 16（複雜結構類）——公因數與最大公因數

**題干**

(a) 求 $18$ 與 $24$ 的公因數。

(b) 求 $\gcd(18, 24)$（最大公因數）。

(c) 用短除法求 $\gcd(36, 60)$。

**考核目標**

列舉公因數；求最大公因數；短除法。

**詳細解答**

(a) $18$ 的因數：$1, 2, 3, 6, 9, 18$。
$24$ 的因數：$1, 2, 3, 4, 6, 8, 12, 24$。
取交集：$18$ 與 $24$ 的公因數為 $1, 2, 3, 6$。

(b) 由 (a) 的公因數 $1, 2, 3, 6$，取最大者：$\gcd(18, 24) = 6$。

(c) 短除法：逐層提取 $36$ 與 $60$ 的公因數——兩數均為偶數，先除 $2$；$18$ 與 $30$ 再除 $2$；$9$ 與 $15$ 的公因數為 $3$，除 $3$：
$$\begin{array}{c|cc}
2 & 36 & 60 \\ \hline
2 & 18 & 30 \\ \hline
3 & 9 & 15 \\ \hline
  & 3 & 5
\end{array}$$
最後一列 $3$ 與 $5$ 互質，停止。
$\gcd(36, 60) = 2 \times 2 \times 3 = 12$。

**易錯點注意**
- 易錯：(a) 列舉時漏掉 $1$——$1$ 是任何數的因數，恆為公因數。
- 易錯：(c) 短除後把**最後一列的數也乘進去**——$\gcd$ 只乘左側除數（$2 \times 2 \times 3$），最後一列 $3$ 與 $5$ 不參與（那是 $\operatorname{lcm}$ 才要乘）。
- 易錯：短除中途除以非公因數——除數必須同時整除兩數（如 $36$ 與 $60$ 除以 $5$ 會出錯，因 $5$ 不整除 $36$）；除以較大的公因數（如 $6$）雖可行，但規範流程是逐層提取公因數直至互質。

#### 題 17（`task` 類）——四則運算的計算

**題干**

計算下列各式。

(a) $15 + 6 \times 3$

(b) $(8 + 12) \div 4$

(c) $7 \times (2 + 3) - 4$

(d) $24 \div 6 + 5 \times 2$

(e) $100 - 3 \times (4 + 6)$

(f) $2^3 \times 3 + 12 \div 2^2$

**考核目標**

掌握四則運算的優先級（先乘除後加減、有括號先算括號內）與乘方。

**詳細解答**

(a) $15 + 6 \times 3$
先算乘法：$6 \times 3 = 18$。
$\implies 15 + 18 = 33$。

(b) $(8 + 12) \div 4$
先算括號：$8 + 12 = 20$。
$\implies 20 \div 4 = 5$。

(c) $7 \times (2 + 3) - 4$
先算括號：$2 + 3 = 5$。
$\implies 7 \times 5 - 4 = 35 - 4 = 31$。

(d) $24 \div 6 + 5 \times 2$
乘除同級，由左至右：$24 \div 6 = 4$、$5 \times 2 = 10$。
$\implies 4 + 10 = 14$。

(e) $100 - 3 \times (4 + 6)$
先算括號：$4 + 6 = 10$。
$\implies 100 - 3 \times 10 = 100 - 30 = 70$。

(f) $2^3 \times 3 + 12 \div 2^2$
先算乘方：$2^3 = 8$、$2^2 = 4$。
$\implies 8 \times 3 + 12 \div 4 = 24 + 3 = 27$。

**易錯點注意**
- 易錯：(a)(e) 中「先乘後加」——不可由左至右盲目計算（$15 + 6$ 再乘 $3$ 是錯的）。
- 易錯：(d) 中乘除「由左至右」——$24 \div 6 \times 2$ 這類式必須依次算，但本題乘除不互相干擾，先算兩邊再相加亦可。
- 易錯：(f) 中把 $12 \div 2^2$ 誤算為 $(12 \div 2)^2$——乘方優先於除法，先算 $2^2 = 4$ 再除。

**難度**

#### 題 21（複雜結構類）——反證法證明生活與數學命題

**題干**

使用反證法證明以下命題。

(a) 已知：(1) 星期六學校不上課；(2) 小明今早去了學校上課。
證明今天不是星期六。

(b) 已知：(1) 若小美在家，則客廳的燈是亮著的；(2) 客廳的燈沒有亮。
證明小美不在家。

(c) 證明不存在最小的正分數。
（提示：假設存在最小的正分數 $r$，考慮 $\frac{r}{2}$ 是否更小。）

(d) 設 $n$ 為自然數。證明若 $3n$ 是奇數，則 $n$ 必為奇數。
（提示：假設 $n$ 是偶數，即 $n = 2k$，然後推導出矛盾。）

**考核目標**

掌握反證法的結構（假設否定 → 推導矛盾 → 推翻假設）；應用於生活與數學命題。

**詳細解答**

(a) 假設今天星期六。
由 (1)，星期六學校不上課，即小明今天不應上學。
但 (2) 說小明今早去了學校上課，與上述推論矛盾。
故假設不成立，今天不是星期六。

(b) 假設小美在家。
由 (1)，若小美在家則客廳燈亮，故推得客廳燈亮。
但 (2) 指明客廳燈沒有亮，矛盾。
故假設不成立，小美不在家。

(c) 假設存在最小的正分數，記為 $r$。
考慮 $\dfrac{r}{2}$：由於 $r > 0$，$\dfrac{r}{2} > 0$，故 $\dfrac{r}{2}$ 也是正分數；且 $\dfrac{r}{2} < r$（正數除以 $2$ 必小於自身）。
這與「$r$ 是最小的正分數」（任何正分數都不小於 $r$）矛盾。
故不存在最小的正分數。

(d) 假設 $n$ 是偶數，即存在自然數 $k$ 使 $n = 2k$。

但前提說 $3n$ 是奇數，矛盾。
故假設不成立，$n$ 必為奇數。

#### 題 24（簡單結構類）——反證法與逆命題陷阱

**題干**

使用反證法證明以下命題。

(a) 已知：(1) 若一件貨品有減價標籤，則它的售價比原價低；(2) 一個價值 $\$200$ 的書包上沒有任何減價標籤。
小明說：「這個書包一定是以原價出售。」小明的說法正確嗎？用反證法說明。

(b) 已知：(1) 若天氣預報說會下雨，則小明會帶傘；(2) 小明今天沒有帶傘。
證明今天天氣預報沒有說會下雨。

**考核目標**

識別逆命題陷阱（條件 (1) 是充分條件非充要條件）；正確應用反證法。

**詳細解答**

(a) 小明的説法不正確。
條件 (1)「若有減價標籤 $\to$ 售價比原價低」的**逆命題**「售價比原價低 $\to$ 有減價標籤」並不必然成立（商店可以口頭優惠、會員折扣等方式降價而不貼標籤）。
用反證法檢驗：假設書包並非以原價出售（即書包有折扣）。
但條件 (2)「書包上沒有任何減價標籤」與「書包有折扣」**不構成矛盾**——書包可以有折扣而無標籤（如會員折扣、臨時口頭優惠）。
由於無法推出矛盾，反證法不能證實小明的説法，故小明的推理不成立。

(b) 假設今天天氣預報說了會下雨。
由 (1)，若天氣預報說會下雨，則小明會帶傘，故推得小明今天帶傘。
但 (2) 說小明今天沒有帶傘，矛盾。
故假設不成立，今天天氣預報沒有說會下雨。

**易錯點注意**
- 易錯：(a) 中以為「書包沒有標籤」就推出「書包以原價出售」——這是誤用逆命題；「$A \to B$」真不等於「$\neg A \to \neg B$」真。

- 易錯：(b) 中把條件 (1) 倒過來用（「沒帶傘 $\to$ 沒說下雨」）——(b) 恰好可由逆否命題成立（原條件句與其逆否等價），但要意識到這是逆否而非逆命題。

#### 題 25（簡單結構類）——反證法證明數學命題

使用反證法證明以下數學命題。

(a) 證明若 $n$ 為自然數且 $n$ 可被 $6$ 整除，則 $n$ 必可被 $3$ 整除。
（提示：假設 $n$ 不可被 $3$ 整除。）

(b) 證明$1$ 不是偶數。
（提示：偶數的定義是可被 $2$ 整除的數。）

**考核目標**

**詳細解答**

(a) 假設 $n$ 不可被 $3$ 整除。
但已知 $n$ 可被 $6$ 整除，即存在自然數 $k$ 使得 $n = 6k$。
則 $n = 6k = 3(2k)$，因 $2k$ 是自然數，故 $n$ 可被 $3$ 整除。
這與假設「$n$ 不可被 $3$ 整除」矛盾。
故假設不成立，$n$ 必可被 $3$ 整除。

(b) 偶數的定義是可被 $2$ 整除的數。
假設 $1$ 是偶數，即存在自然數 $k$ 使得 $1 = 2k$。
解 $k = \dfrac{1}{2}$，不是自然數，與「$k$ 為自然數」矛盾。
故假設不成立，$1$ 不是偶數。

- 易錯：(b) 中忽略「$k$ 為自然數」的條件——$1 = 2k$ 解得 $k = \frac{1}{2}$，正是因 $\frac{1}{2}$ 非自然數才構成矛盾。

(b) $P = (\text{小明有發燒})$，$Q = (\text{小明需看醫生})$

#### 題 27（複雜結構類）——逆命題與逆否命題的區分

**題干**

考慮以下條件句：

$$P \to Q,\quad\text{其中 } P = (\text{三角形 } ABC \text{ 是等邊三角形}),\; Q = (\text{三角形 } ABC \text{ 是等腰三角形})$$

(a) 原命題 $P \to Q$ 是否為真命題？為甚麼？

(b) 寫出此條件句的逆命題（$Q \to P$）。逆命題是否為真？若不為真，舉出反例。

(c) 寫出此條件句的逆否命題（$\neg Q \to \neg P$）。逆否命題與原命題 $P \to Q$ 是否邏輯等價？

(d) 完成以下真值表以驗證 (c) 的結論：

$$
\begin{array}{|c|c||c|c|c|c|c|}
\hline
P & Q & P \to Q & Q \to P & \neg Q & \neg P & \neg Q \to \neg P \\
\hline
 \mathbb{T} & \mathbb{T} &   &   &   &   &   \\
\hline
 \mathbb{T} & \mathbb{F} &   &   &   &   &   \\
\hline
 \mathbb{F} & \mathbb{T} &   &   &   &   &   \\
\hline
 \mathbb{F} & \mathbb{F} &   &   &   &   &   \\
\hline
\end{array}
$$

觀察哪兩列的真值始終一致？哪兩列不一定一致？

**考核目標**

區分原命題、逆命題、逆否命題；以真值表驗證逆否命題的等價性。

**詳細解答**

(a) 是真命題。
等邊三角形的三條邊長度均相等，故其中**至少**有兩條邊相等（事實上有三條），滿足等腰三角形「至少有兩條邊相等」的定義。
故 $P \to Q$ 為真。

(b) 逆命題：若三角形 $ABC$ 是等腰三角形，則三角形 $ABC$ 是等邊三角形。
不為真。
反例：三邊長為 $3, 3, 4$ 的三角形——兩條邊相等（$3 = 3$）故是等腰三角形，但第三邊 $4 \neq 3$，不是等邊三角形。

(c) 逆否命題：若三角形 $ABC$ 不是等腰三角形，則三角形 $ABC$ 不是等邊三角形。
逆否命題與原命題 $P \to Q$ 邏輯等價（定理：$P \to Q \iff \neg Q \to \neg P$）。

(d) 完成真值表：先填 $P, Q$ 四種組合，再算 $\neg P$、$\neg Q$，由條件句規則（前件真後件假才為假）填 $P \to Q$、$Q \to P$、$\neg Q \to \neg P$：

$$
\begin{array}{|c|c||c|c|c|c|c|}
\hline
P & Q & P \to Q & Q \to P & \neg Q & \neg P & \neg Q \to \neg P \\
\hline
 \mathbb{T} & \mathbb{T} & \mathbb{T} & \mathbb{T} & \mathbb{F} & \mathbb{F} & \mathbb{T} \\
\hline
 \mathbb{T} & \mathbb{F} & \mathbb{F} & \mathbb{T} & \mathbb{T} & \mathbb{F} & \mathbb{F} \\
\hline
 \mathbb{F} & \mathbb{T} & \mathbb{T} & \mathbb{F} & \mathbb{F} & \mathbb{T} & \mathbb{T} \\
\hline
 \mathbb{F} & \mathbb{F} & \mathbb{T} & \mathbb{T} & \mathbb{T} & \mathbb{T} & \mathbb{T} \\
\hline
\end{array}
$$

觀察：$P \to Q$ 與 $\neg Q \to \neg P$ 兩列真值**始終一致**（第 1–4 行分別為 $\mathbb{T},\mathbb{F},\mathbb{T},\mathbb{T}$，完全相同），故邏輯等價。
$P \to Q$ 與 $Q \to P$ 不一定一致——如第 3 行：$P \to Q = \mathbb{T}$ 但 $Q \to P = \mathbb{F}$。

**易錯點注意**
- 易錯：(b) 反例須同時滿足「是等腰」與「不是等邊」——$3, 3, 4$ 恰合資格；若舉 $3, 4, 5$（全不等）則連等腰都不是，反例無效。
- 易錯：(d) 填條件句時只在「前件真、後件假」時填 $\mathbb{F}$——第 3 行 $Q \to P$ 中 $Q = \mathbb{T}$ 而 $P = \mathbb{F}$，故為 $\mathbb{F}$。
- 易錯：比較「原命題 vs 逆命題」兩列時漏看第 3 行——等價性要求**每一行**都一致，一行不一致即不等價。

**難度**

> 分題 (a)｜難度：**T C｜C D｜E C｜Q C**

#### 題 28（無結構類）——反證法與逆否命題法的辨識

**題干**

設 $n$ 為自然數。閱讀以下關於命題「若 $n^2$ 是奇數，則 $n$ 是奇數」的證明，指出其使用了反證法還是逆否命題法：

**證明一：**假設 $n$ 是偶數，即 $n = 2k$（$k$ 為自然數）。
則 $n^2 = (2k)^2 = 4k^2 = 2(2k^2)$，故 $n^2$ 是偶數。
由此，原命題「若 $n^2$ 是奇數，則 $n$ 是奇數」得證。

**證明二：**
假設 $n^2$ 是奇數但 $n$ 不是奇數（即 $n$ 是偶數）。則 $n = 2k$，$n^2 = 4k^2$ 是偶數，與假設「$n^2$ 是奇數」矛盾。
故假設不成立，$n$ 必為奇數。

**考核目標**

辨識反證法與逆否命題法的結構差異。

**詳細解答**

證明一使用了**逆否命題法**。
它假設的是「$n$ 是偶數」（$n^2$ 是奇數的**結論**之否定，即 $\neg P$ 形式），直接推導 $n^2 = (2k)^2 = 4k^2 = 2(2k^2)$ 是偶數，即證得逆否命題「若 $n$ 是偶數，則 $n^2$ 是偶數」，全程**未涉及任何矛盾**，屬正向證明。
（注意：原命題「$n^2$ 是奇數 $\to$ $n$ 是奇數」的逆否正是「$n$ 是偶數 $\to$ $n^2$ 是偶數」。）

證明二使用了**反證法**。
它假設「$n^2$ 是奇數但 $n$ 不是奇數（即 $n$ 是偶數）」，即前提與結論的否定同時成立；由此推導 $n = 2k$、$n^2 = 4k^2$ 是偶數，與假設中「$n^2$ 是奇數」構成矛盾（$n^2$ 既是奇數又是偶數）。
因假設導致矛盾，故推翻假設，$n$ 必為奇數。

**易錯點注意**
- 易錯：把證明一誤判為反證法——反證法必須出現「矛盾」；證明一只是「證逆否命題」，全程無矛盾。
- 易錯：未認出證明一證的正是逆否命題——先寫出原命題的逆否形式（$n$ 偶 $\to$ $n^2$ 偶），再與證明一比對。

#### 題 33（簡單結構類）——充分性＋必要性策略

**題干**

利用「充分性 + 必要性」的策略（即 $P \iff Q \iff (P \implies Q) \land (Q \implies P)$），證明以下命題。

(a) 設 $n$ 為自然數。證明$n$ 是偶數，當且僅當 $n^2$ 是偶數。
（提示：必要性可用逆否命題法。）

(b) 證明$x + 2 = 5 \iff 2x + 4 = 10$。

**考核目標**

掌握充分性＋必要性的雙向證明策略；必要性可用逆否命題法。

**詳細解答**

(a) 設 $P = $（$n$ 是偶數），$Q = $（$n^2$ 是偶數）。

**充分性**（$P \implies Q$）：設 $n$ 是偶數，即存在自然數 $k$ 使得 $n = 2k$。
則 $n^2 = (2k)^2 = 4k^2 = 2(2k^2)$，因 $2k^2$ 是自然數，故 $n^2$ 是偶數，$Q$ 成立。

**必要性**（$Q \implies P$）：用逆否命題法，改證 $\neg P \implies \neg Q$。
設 $n$ 不是偶數（即 $n$ 是奇數），則存在自然數 $k$ 使得 $n = 2k + 1$。
則 $n^2 = (2k+1)^2 = 4k^2 + 4k + 1 = 2(2k^2 + 2k) + 1$，形如「$2 \times$ 自然數 $+\,1$」，故為奇數，不是偶數，即 $\neg Q$ 成立。
由 $\neg P \implies \neg Q$ 及逆否命題等價性，得 $Q \implies P$。

由充分性與必要性，$P \iff Q$。

(b) **充分性**（$x + 2 = 5 \implies 2x + 4 = 10$）：
設 $x + 2 = 5$。
由等式性質，兩邊同乘 $2$：$2(x + 2) = 2 \times 5$，即 $2x + 4 = 10$。

**必要性**（$2x + 4 = 10 \implies x + 2 = 5$）：
設 $2x + 4 = 10$。
由等式性質，兩邊同乘 $\dfrac{1}{2}$（注意 $2 \neq 0$，可除）：$\dfrac{1}{2}(2x + 4) = \dfrac{1}{2} \times 10$，即 $x + 2 = 5$。

由充分性與必要性，$x + 2 = 5 \iff 2x + 4 = 10$。

**易錯點注意**
- 易錯：(a) 必要性若直接證 $n^2$ 偶 $\to$ $n$ 偶較難下手——改用逆否命題法（證「$n$ 奇 $\to$ $n^2$ 奇」）是關鍵策略。
- 易錯：(a) 展開 $(2k+1)^2 = 4k^2 + 4k + 1$ 時漏交叉項 $4k$——展開須逐項：$(2k)^2 + 2 \times 2k \times 1 + 1^2$。
- 易錯：(b) 必要性兩邊「同乘 $\frac{1}{2}$」須說明 $2 \neq 0$——等式性質 $ac = bc \iff a = b$ 要求 $c \neq 0$。

#### 題 34（簡單結構類）——現實情景的充分性＋必要性

**題干**

(a) 小明說：「我會去露營，當且僅當週末天晴且我有空。」設 $P = $（小明去露營），$Q = $（週末天晴），$R = $（小明有空）。將小明的陳述寫為邏輯符號形式，並用充分性和必要性兩步證明此陳述。

(b) 小明又說：「$n$ 是偶數，當且僅當 $n$ 可被 $4$ 整除。」設 $P = $（$n$ 是偶數），$Q = $（$n$ 可被 $4$ 整除）。$P \iff Q$ 是否成立？分別證明充分性與必要性（或舉出反例）。

**考核目標**

將日常陳述符號化並以充分性＋必要性證明；識別不成立的等價並舉反例。

**詳細解答**

(a) 小明的陳述可寫為：$P \iff (Q \land R)$。

**充分性**（$P \implies Q \land R$）：若小明去露營，則週末天晴且他有空。
理由是「露營是他承諾在條件滿足時才做的事」——若週末不天晴或他沒有空，他不會去露營；故他去了露營，兩條件必同時成立。

**必要性**（$Q \land R \implies P$）：若週末天晴且小明有空，則小明去露營。
理由是「兩條件同時滿足時他就會去露營」——這是題意所給的約定。

因此 $P \iff (Q \land R)$ 成立。

(b) $P \iff Q$ 不成立。

**充分性**（$Q \implies P$）：若 $n$ 可被 $4$ 整除，則 $n$ 可被 $2$ 整除。
成立：$n = 4k = 2(2k)$，因 $2k$ 是自然數，故 $n$ 可被 $2$ 整除。

**必要性**（$P \implies Q$）：若 $n$ 是偶數，則 $n$ 可被 $4$ 整除。
不成立。
反例：$n = 2$ 是偶數（$2 = 2 \times 1$），但 $2$ 不可被 $4$ 整除；$n = 6$ 亦然。

由於必要性不成立，$P \iff Q$ 不成立（「$n$ 是偶數」只是「$n$ 可被 $4$ 整除」的必要條件，而非充要條件）。

#### 題 35（`task` 類）——代數式與等式的區分

**題干**

判斷以下各項是代數式還是等式。若是等式，進一步判斷它是普通命題還是開放命題（方程）。

(a) $3x + 2$

(b) $3x + 2 = 11$

(c) $a + b = b + a$

(d) $2y - 7$

(e) $5 = 2 + 3$

(f) $x^2 = 16$

**考核目標**

應用「代數式 ↔ 對象、等式 ↔ 命題、方程 ↔ 開放命題」的框架。

**詳細解答**

(a) 代數式（對象）。
$3x + 2$ 不含「$=$」，是含變量的式子，屬代數式（對象），不是命題。

(b) 等式，是開放命題（方程）。
含「$=$」連接 $3x + 2$ 與 $11$，且含變量 $x$，真值隨 $x$ 而定，故為方程。

(c) 等式，是普通命題（恆真，加法交換律）。
含「$=$」，但不含變量（$a, b$ 在此表示任意數，屬恆等式陳述），真值恆真，故為普通命題。

(d) 代數式（對象）。
$2y - 7$ 不含「$=$」，是代數式。

(e) 等式，是普通命題（恆真）。
含「$=$」，不含變量，$5 = 2 + 3$ 恆真。

(f) 等式，是開放命題（方程）。
含「$=$」且含變量 $x$，$x^2 = 16$ 的真值隨 $x$ 而定，故為方程。

**易錯點注意**

- 易錯：只憑「含 $=$」就判「方程」——方程還須**含變量**；(e) $5 = 2 + 3$ 是等式但非方程。
- 易錯：把代數式（如 (a) $3x + 2$）當成命題——代數式是對象，本身不陳述真假。

#### 題 36（複雜結構類）——等式與方程的關係

**題干**

回答以下問題。

(a) 等式 $3 + 4 = 7$ 是方程嗎？為甚麼？

(d) 一個方程必然是一個等式嗎？為甚麼？

**考核目標**

釐清等式（以 $=$ 連接）與方程（含變量的等式）的包含關係。

**詳細解答**

#### 題 39（複雜結構類）——列方程解應用題

#### 題 40（簡單結構類）——等式性質的證明

**題干**

已知等式的性質：$a = b \implies a + c = b + c$，以及 $a = b \iff ac = bc$（$c \neq 0$）。

(a) 若 $a = b$ 且 $c = d$，證明 $a + c = b + d$。

(b) 若 $ac = bc$，是否可推出 $a = b$？若 $c = 0$ 時結論是否仍然成立？解釋原因。

**考核目標**

以等式性質與萊布尼茨定律證明新結論；討論 $c = 0$ 的特殊情形。

**詳細解答**

(a) 若 $a = b$ 且 $c = d$：
由 $a = b$，據等式性質（兩邊同加 $c$），得 $a + c = b + c$。
由 $c = d$，據萊布尼茨定律（以 $d$ 替換 $c$），得 $b + c = b + d$。
由傳遞性（$a + c = b + c$ 且 $b + c = b + d$），得 $a + c = b + d$。

(b) 當 $c \neq 0$ 時，$ac = bc$ 兩邊同乘 $\dfrac{1}{c}$（$c \neq 0$ 故 $\frac{1}{c}$ 有意義）：
$\dfrac{1}{c} \times ac = \dfrac{1}{c} \times bc$ $\implies$ $a = b$，結論成立。
但當 $c = 0$ 時，$ac = bc$ 即 $a \times 0 = b \times 0$，即 $0 = 0$ 恆成立，與 $a, b$ 取值無關，無法推出 $a = b$。
例：$a = 3$、$b = 5$、$c = 0$，則 $ac = 0 = bc$ 成立，但 $a = 3 \neq 5 = b$。
故 $c = 0$ 時結論不成立。

**易錯點注意**
- 易錯：(a) 中兩步變形的依據混淆——第一步（加 $c$）用**等式性質**，第二步（換 $d$）用**萊布尼茨定律**，不可只寫「由 $a = b$ 且 $c = d$ 得 $a + c = b + d$」而無依據。
- 易錯：(b) 中直接「兩邊除 $c$」不提 $c \neq 0$——除以 $0$ 無意義，必須先分類討論 $c = 0$ 與 $c \neq 0$。
- 易錯：(b) 反例須同時滿足「$ac = bc$」與「$a \neq b$」——$a = 3$、$b = 5$、$c = 0$ 恰合資格。

#### 題 41（複雜結構類）——開放命題的分析

**題干**

設開放命題 $P(x) = (3x - 7 = 11)$ 及 $Q(x) = (2x + 1 = 11)$。

(a) 求 $P(x)$ 為真時 $x$ 的值。

(b) 求 $Q(x)$ 為真時 $x$ 的值。

(c) 是否存在 $x$ 使得 $P(x) \land Q(x)$ 為真？

(d) $P(x) \implies Q(x)$ 是否成立？解釋原因。

**考核目標**

求解開放命題；分析兩開放命題的交集與蘊含關係。

**詳細解答**

(a) $P(x)$ 為真時：$3x - 7 = 11$。
兩邊同加 $7$：$3x = 18$。
兩邊同除 $3$：$x = 6$。
故 $P(x)$ 為真當且僅當 $x = 6$。

(b) $Q(x)$ 為真時：$2x + 1 = 11$。
兩邊同減 $1$：$2x = 10$。
兩邊同除 $2$：$x = 5$。
故 $Q(x)$ 為真當且僅當 $x = 5$。

(c) 不存在。
$P(x) \land Q(x)$ 為真要求同一 $x$ 同時滿足 $P$ 與 $Q$：需 $x = 6$（由 (a)）且 $x = 5$（由 (b)）。
$6 \neq 5$，兩條件互斥，故不存在這樣的 $x$。

(d) 不成立。
$P(x) \implies Q(x)$ 為真要求「凡使 $P$ 真的 $x$ 都使 $Q$ 真」。
由 (a)，使 $P$ 真的唯一 $x$ 是 $6$；但 $Q(6) = (2 \times 6 + 1 = 11) = (13 = 11) = \mathbb{F}$。
故存在使 $P$ 真而 $Q$ 假的 $x$（$x = 6$），$P(x) \implies Q(x)$ 不成立。

**易錯點注意**
- 易錯：(c) 中把「$P \land Q$ 無解」誤解為「$P$ 或 $Q$ 無解」——$P$、$Q$ 各自有解（$6$ 與 $5$），只是無**共同**解。
- 易錯：(d) 中只用「$x = 6$ 使 $Q$ 假」就下結論——須先說明「$x = 6$ 是使 $P$ 真的**唯一**值」，否則反例不構成對「全稱蘊含」的否證。
- 易錯：檢驗 $Q(6)$ 時算錯——$2 \times 6 + 1 = 13 \neq 11$，代入後要重新計算。
