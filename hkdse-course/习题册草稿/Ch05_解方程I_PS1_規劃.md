### §5.1 方程的基本概念

#### 題 1（`task` 類）——方程的判斷

**題干**

判斷下列各代數式是否為方程。如否，簡述原因。

(a) $x + 5$

(b) $2x + 3 = 7$

(c) $xy = 1$

(d) $2 + 3 = 5$

(e) $x^2 - 1$

(f) $3a - 4b = 0$

(g) $\dfrac{x}{2} + 1$

(h) $0 = 0$

**考核目標**

掌握方程定義（含未知數的等式），能區分方程、等式與代數式。

**詳細解答**

依方程定義（講義 5.1.1）：方程是含有未知數的等式，兩條件缺一不可——須以 $=$ 連接，且含變量。

(a) $x + 5$：不以 $=$ 連接，是代數式而非方程。

(b) $2x + 3 = 7$：以 $=$ 連接且含變量 $x$，是方程。

(c) $xy = 1$：以 $=$ 連接且含變量 $x, y$，是方程。

(d) $2 + 3 = 5$：是等式但不含變量，不是方程。

(e) $x^2 - 1$：不以 $=$ 連接，是代數式而非方程。

(f) $3a - 4b = 0$：以 $=$ 連接且含變量 $a, b$，是方程。

(g) $\dfrac{x}{2} + 1$：不以 $=$ 連接，是代數式而非方程。

(h) $0 = 0$：是等式但不含變量，不是方程。

**易錯點注意**

- 易錯：把「是等式」與「是方程」混為一談——等式（如 $2 + 3 = 5$、$0 = 0$）不含變量，不是方程；方程必須同時含有變量。
- 易錯：把「以 $=$ 連接」遺漏——代數式（如 $x + 5$、$x^2 - 1$）只是表達式，不是方程。

**難度**

> 題 1｜難度：**T C｜C D｜E C｜Q D**
> 判定理由（T）：解答每項需「看是否以 $=$ 連接→看是否含變量」兩條件（解答的兩條件檢驗），鏈長 2 步。
> 判定理由（C）：無計算。
> 判定理由（E）：判斷策略（兩條件並舉）須自行選擇，屬方法選擇層。
> 判定理由（Q）：方程單課題。

#### 題 2（`task` 類）——變量與元

**題干**

對於下列各方程，分別寫出其變量與元。

(a) $x - 2y = 1$

(b) $x^2 - 5x + 25 = 0$

(c) $x^2 + 2xyz + y^2 = 0$

(d) $3p + q - r = 7$

(e) $m^2 = 9$

(f) $a + b = c + d$

**考核目標**

掌握變量與元（變量數）的區分。

**詳細解答**

依定義（講義 5.1.1）：方程中出現的變量即為變量，變量的數量即為「元」。

(a) $x - 2y = 1$：出現變量 $x, y$，共 $2$ 個，是二元方程。

(b) $x^2 - 5x + 25 = 0$：出現變量 $x$，共 $1$ 個，是一元方程。

(c) $x^2 + 2xyz + y^2 = 0$：出現變量 $x, y, z$，共 $3$ 個，是三元方程。

(d) $3p + q - r = 7$：出現變量 $p, q, r$，共 $3$ 個，是三元方程。

(e) $m^2 = 9$：出現變量 $m$，共 $1$ 個，是一元方程。

(f) $a + b = c + d$：出現變量 $a, b, c, d$，共 $4$ 個，是四元方程。

**易錯點注意**

- 易錯：把不同字母全部當成變量即可，但需逐一列出不遺漏——(c) 中 $x, y, z$ 三個都要寫；(d) 中 $p, q, r$ 三個都要寫。
- 易錯：把「次數」與「元」混淆——(b) 中 $x^2$ 次數為 $2$，但元數仍為 $1$；元數只看變量種類數量。

**難度**

> 判定理由（C）：無計算。
> 判定理由（E）：辨識變量並數元須自行進行，屬方法選擇層。
> 判定理由（Q）：方程單課題。

#### 題 3（`task` 類）——最簡表示與次數

**題干**

將下列各方程化為最簡表示 $Q = 0$，並寫出其次數。

(a) $2x + 3 = 5x - 4$

(b) $x - 2 = 3x$

(c) $3(x - 1) = 2x + 1$

(d) $2x + 1 = 5$

(e) $x^2 + y = 1$

(f) $4x - 3 = 2x + 5$

**考核目標**

將方程化為 $Q = 0$ 的最簡表示並確定其次數。

**詳細解答**

依定義（講義 5.1.3）：最簡表示 $Q = 0$ 中 $Q$ 為 $P_1 - P_2$ 的最簡多項式，方程的次數即 $Q$ 的次數。

(a) $2x + 3 = 5x - 4$

$Q = (2x + 3) - (5x - 4) = 2x + 3 - 5x + 4 = -3x + 7$。

$\implies$ 最簡表示：$-3x + 7 = 0$；次數：$1$。

(b) $x - 2 = 3x$

$Q = (x - 2) - 3x = -2x - 2$。

$\implies$ 最簡表示：$-2x - 2 = 0$；次數：$1$。

(c) $3(x - 1) = 2x + 1$

$Q = 3(x - 1) - (2x + 1) = 3x - 3 - 2x - 1 = x - 4$。

$\implies$ 最簡表示：$x - 4 = 0$；次數：$1$。

(d) $2x + 1 = 5$

$Q = (2x + 1) - 5 = 2x - 4$。

$\implies$ 最簡表示：$2x - 4 = 0$；次數：$1$。

(e) $x^2 + y = 1$

$Q = (x^2 + y) - 1 = x^2 + y - 1$。

$\implies$ 最簡表示：$x^2 + y - 1 = 0$；次數：$2$（$x^2$ 項次數最高）。

(f) $4x - 3 = 2x + 5$

$Q = (4x - 3) - (2x + 5) = 2x - 8$。

$\implies$ 最簡表示：$2x - 8 = 0$；次數：$1$。

**易錯點注意**

- 易錯：計算 $P_1 - P_2$ 時括號處理出錯——$(2x + 3) - (5x - 4)$ 須展開為 $2x + 3 - 5x + 4$，第二括號內 $-4$ 變號為 $+4$。
- 易錯：次數看錯——(e) 中 $x^2 + y - 1$ 含 $x^2$ 項，次數為 $2$，不可只數變量數。

**難度**

> 題 3｜難度：**T C｜C C｜E C｜Q D**
> 判定理由（T）：解答每項需「作差→合併化簡→定次數」三步（解答的作差＋化簡＋判次數），鏈長 2–3 步。

> 判定理由（E）：最簡化流程（作差化簡）須自行組織，屬方法選擇層。
> 判定理由（Q）：方程單課題。

#### 題 4（`task` 類）——一元一次方程判斷

**題干**

判斷下列各方程是否為一元一次方程。

(a) $3x + 1 = 5$

(b) $x^2 = 9$

(c) $2x - 3y = 7$

(d) $\dfrac{x}{2} + 1 = 3$

(e) $x + 1 = x + 2$

(f) $0 \cdot x = 0$

**考核目標**

掌握一元一次方程的判定（最簡表示為一元一次多項式，即一元、一次、係數非零）。

**詳細解答**

依定義（講義 5.2.1）：化為最簡表示 $Q = 0$ 後，$Q$ 是一元一次多項式才是一元一次方程。

(a) $3x + 1 = 5$

$Q = (3x + 1) - 5 = 3x - 4$，一元一次，$x$ 的係數 $3 \neq 0$。

$\implies$ 是。

(b) $x^2 = 9$

$Q = x^2 - 9$，次數為 $2$。

$\implies$ 不是（二次方程）。

(c) $2x - 3y = 7$

$Q = 2x - 3y - 7$，含兩個變量。

$\implies$ 不是（二元方程）。

(d) $\dfrac{x}{2} + 1 = 3$

$Q = \dfrac{x}{2} - 2$，即 $\dfrac{1}{2}x - 2$，一元一次，係數 $\dfrac{1}{2} \neq 0$。

$\implies$ 是。

(e) $x + 1 = x + 2$

$Q = (x + 1) - (x + 2) = -1$，即 $0 = 1$，$x$ 項完全抵消。

$\implies$ 不是（無 $x$ 項，實為矛盾等式，無解）。

(f) $0 \cdot x = 0$

$Q = 0 \cdot x - 0 = 0$，即 $0 = 0$，$x$ 的係數為 $0$。

$\implies$ 不是（$x$ 項係數為 $0$，實為恆等式，無窮多解）。

**易錯點注意**

- 易錯：(e)(f) 兩項特殊情形——$x$ 項係數為 $0$ 時最簡表示不含 $x$，不屬一元一次方程（一為矛盾 $0 = 1$，一為恆等式 $0 = 0$）。
- 易錯：須先化最簡表示再判斷——(d) 中 $\dfrac{x}{2} + 1 = 3$ 看似含分式，化簡後 $\dfrac{1}{2}x - 2 = 0$ 仍是一元一次方程。

**難度**

> 題 4｜難度：**T C｜C C｜E C｜Q D**
> 判定理由（T）：解答每項需「化最簡→查元數→查次數→查係數」多步（解答的化簡＋三條件檢驗），含特殊情形 (e)(f)，鏈長 2–3 步。
> 判定理由（C）：代數式化簡，每項 2–3 步。
> 判定理由（E）：特殊情形（係數為零）須自行辨析，屬方法選擇層。
> 判定理由（Q）：方程單課題。

#### 題 5（複雜結構類）——驗根

**題干**

驗證下列各給定的值是否為方程的根。

(a) $x = 2$ 是否為 $3x - 1 = 5$ 的根？

(b) $x = 1,\ y = 6$ 是否為 $xy + 2x^2 - 8 = 0$ 的根？

(c) $x = -1$ 是否為 $2x + 3 = 1$ 的根？

(d) $x = 3,\ y = -1$ 是否為 $2x - y = 7$ 的根？

**考核目標**

代入給定值驗證是否為方程的根（解）。

**詳細解答**

依定義（講義 5.1.4）：若變量取值使等式成立（兩邊相等），則該取值為方程的根。逐項代入計算即可。

(a) 代入 $x = 2$：

$3(2) - 1 = 6 - 1 = 5$，與右邊 $5$ 相等。

$\implies$ 等式成立，$x = 2$ 是根。

(b) 代入 $x = 1, y = 6$：

$(1)(6) + 2(1)^2 - 8 = 6 + 2 - 8 = 0$，等號右邊為 $0$。

$\implies$ 等式成立，$x = 1, y = 6$ 是根。

(c) 代入 $x = -1$：

$2(-1) + 3 = -2 + 3 = 1$，與右邊 $1$ 相等。

#### 題 6（複雜結構類）——恆等與等價判斷

**題干**

判斷下列各句的對錯，並簡述理由。

(a) 方程是含有未知數的等式。

(b) 等式的兩邊同時乘以同一個數，所得等式與原等式等價。

(c) 方程的最簡表示是唯一的。

(d) $x + 1 = x + 2$ 是一元一次方程。

**考核目標**

辨析方程、等價變換、最簡表示、一元一次方程的概念。

**詳細解答**

(a) 依定義（講義 5.1.1），方程是含有未知數的等式，兩條件俱全。

$\implies$ 對。

(b) 須檢查「同一個數」是否允許為 $0$。若乘的數為 $0$，兩邊同乘得 $0 = 0$，對任意取值都成立，與原等式不再等價（如 $x = 1$ 乘 $0$ 得 $0 = 0$，解集由 $\{1\}$ 變為全體實數）。依講義 5.1.2，等式的性質要求乘的數非零。

$\implies$ 錯。正確說法：兩邊同乘**非零**實數才保證等價。

(c) 最簡表示由 $P_1 - P_2$ 取最簡多項式得來（講義 5.1.3）。多項式的最簡表示（合併同類項後按降冪排列）是唯一的，故 $Q = 0$ 唯一。

$\implies$ 對。

(d) 化最簡：$Q = (x + 1) - (x + 2) = -1$，即 $0 = 1$。最簡表示不含 $x$ 項（$x$ 項係數為 $0$），實為矛盾等式，無解，不屬一元一次方程（講義 5.2.1：須 $x$ 項係數非零）。

$\implies$ 錯。$x + 1 = x + 2$ 不是一元一次方程。

**易錯點注意**

#### 題 7（`task` 類）——基本一元一次方程

**題干**

解下列一元一次方程。

(a) $x + 5 = 12$

(b) $2x - 3 = 7$

(c) $3x + 1 = x + 5$

(d) $5x - 2 = 3x + 4$

(e) $-x + 7 = 2$

(f) $4 - x = x + 2$

**考核目標**

移項求解一元一次方程。

**詳細解答**

解一元一次方程依標準步驟（講義 5.2.2）：移項（含未知數項與常數項分置兩邊、變號）→合併同類項→係數化為 $1$。原式抄入首行。

(a) $x + 5 = 12$

兩邊同減 $5$（移項，$+5$ 變 $-5$）：

$x = 12 - 5$。

$\implies x = 7$。

(b) $2x - 3 = 7$

兩邊同加 $3$（移項，$-3$ 變 $+3$）：

$2x = 7 + 3 = 10$。

兩邊同除以 $2$（係數化為 $1$）：

$\implies x = 5$。

(c) $3x + 1 = x + 5$

把含 $x$ 項移到左邊、常數移到右邊（移項，變號）：

$3x - x = 5 - 1$。

$\implies 2x = 4$。

$\implies x = 2$。

(d) $5x - 2 = 3x + 4$

移項（$3x$ 變 $-3x$，$-2$ 變 $+2$）：

$5x - 3x = 4 + 2$。

$\implies 2x = 6$。

$\implies x = 3$。

(e) $-x + 7 = 2$

移項：$-x = 2 - 7 = -5$。

兩邊同乘 $-1$（或同除以 $-1$，係數化為 $1$）：

$\implies x = 5$。

(f) $4 - x = x + 2$

移項（$-x$ 與 $x$ 分別處理）：

$4 - 2 = x + x$。

$\implies 2 = 2x$。

$\implies x = 1$。

**易錯點注意**

- 易錯：移項變號遺漏——(c) 中 $3x - x$ 而非常數 $1$ 直接移到左邊不變號；(e) 中 $-x = -5$ 兩邊同乘 $-1$ 得 $x = 5$。
- 易錯：(f) 中先將含 $x$ 項集中在一邊——$4 - 2 = x + x$，勿把 $4$ 留在左邊造成符號混亂。

**難度**

> 題 7｜難度：**T C｜C C｜E D｜Q D**
> 判定理由（T）：解答每項需「移項→合併→係數化為 1」三步（解答的移項＋合併＋係數化 1），鏈長 2–3 步。
> 判定理由（C）：整數四則運算，每項 2–3 步。

#### 題 8（`task` 類）——含括號的一元一次方程

(e) $3(2x - 1) = 2(3x - 2) + 1$

(f) $-(x - 3) + 2(2x + 1) = 5$

**考核目標**

去括號後求解一元一次方程。

**詳細解答**

解題流程（講義 5.2.2）：先去括號（分配律展開）→移項→合併同類項→係數化為 $1$。原式抄入首行。

(a) $3(x - 2) = 2x + 1$

去括號（分配律）：

$3x - 6 = 2x + 1$。

移項：$3x - 2x = 1 + 6$。

$\implies x = 7$。

(b) $2(2x + 1) - 3 = 5$

去括號：

$4x + 2 - 3 = 5$。

$\implies 4x - 1 = 5$。

移項：$4x = 6$。

$\implies x = \dfrac{3}{2}$。

(c) $5 - 2(3 - x) = x + 1$

去括號（$2(3 - x) = 6 - 2x$，前面有減號，整體變號）：

$5 - 6 + 2x = x + 1$。

$\implies -1 + 2x = x + 1$。

移項：$2x - x = 1 + 1$。

$\implies x = 2$。

(d) $4(x - 1) + 3 = 2(x + 3)$

去括號：

$4x - 4 + 3 = 2x + 6$。

$\implies 4x - 1 = 2x + 6$。

移項：$4x - 2x = 6 + 1$。

$\implies 2x = 7$。

$\implies x = \dfrac{7}{2}$。

(e) $3(2x - 1) = 2(3x - 2) + 1$

去括號：

$6x - 3 = 6x - 4 + 1$。

$\implies 6x - 3 = 6x - 3$。

兩邊完全相同，對任意 $x$ 都成立（恆等式）。

$\implies$ 無窮多解。

(f) $-(x - 3) + 2(2x + 1) = 5$

去括號（$-(x - 3) = -x + 3$）：

$-x + 3 + 4x + 2 = 5$。

$\implies 3x + 5 = 5$。

$\implies 3x = 0$。

$\implies x = 0$。

**易錯點注意**

- 易錯：括號前是負號時展開須整體變號——(c) 中 $-2(3 - x) = -6 + 2x$；(f) 中 $-(x - 3) = -x + 3$。
- 易錯：(e) 中化簡後兩邊相同，屬恆等式——答案為無窮多解，勿硬寫 $x$ 的具體值。

#### 題 9（`task` 類）——含分母的一元一次方程

**題干**

解下列一元一次方程。

(a) $\dfrac{x}{2} = 3$

(b) $\dfrac{x}{3} + \dfrac{x}{4} = 7$

(c) $\dfrac{x}{2} - \dfrac{x + 1}{3} = 1$

(d) $\dfrac{2x - 1}{5} + \dfrac{x + 1}{2} = 3$

(e) $\dfrac{x - 1}{2} = \dfrac{x + 3}{4}$

(f) $\dfrac{3x + 1}{2} - \dfrac{x - 1}{3} = 2$

**考核目標**

去分母後求解一元一次方程。

**詳細解答**

解題流程（講義 5.2.2）：先去分母（兩邊同乘各分母的最小公倍數，分子是多項式時要加括號）→去括號→移項→合併→係數化為 $1$。原式抄入首行。

$x = 6$。

(b) $\dfrac{x}{3} + \dfrac{x}{4} = 7$

各分母為 $3, 4$，最小公倍數為 $12$。兩邊同乘 $12$：

$12 \cdot \dfrac{x}{3} + 12 \cdot \dfrac{x}{4} = 12 \cdot 7$。

$\implies 4x + 3x = 84$。

$\implies 7x = 84$。

$\implies x = 12$。

(c) $\dfrac{x}{2} - \dfrac{x + 1}{3} = 1$

分母為 $2, 3$，最小公倍數為 $6$。兩邊同乘 $6$：

$6 \cdot \dfrac{x}{2} - 6 \cdot \dfrac{x + 1}{3} = 6 \cdot 1$。

$\implies 3x - 2(x + 1) = 6$。

去括號：$3x - 2x - 2 = 6$。

$\implies x = 8$。

(d) $\dfrac{2x - 1}{5} + \dfrac{x + 1}{2} = 3$

分母為 $5, 2$，最小公倍數為 $10$。兩邊同乘 $10$：

$10 \cdot \dfrac{2x - 1}{5} + 10 \cdot \dfrac{x + 1}{2} = 10 \cdot 3$。

$\implies 2(2x - 1) + 5(x + 1) = 30$。

去括號：$4x - 2 + 5x + 5 = 30$。

$\implies 9x + 3 = 30$。

$\implies 9x = 27$。

$\implies x = 3$。

(e) $\dfrac{x - 1}{2} = \dfrac{x + 3}{4}$

分母為 $2, 4$，最小公倍數為 $4$。兩邊同乘 $4$：

$4 \cdot \dfrac{x - 1}{2} = 4 \cdot \dfrac{x + 3}{4}$。

$\implies 2(x - 1) = x + 3$。

去括號：$2x - 2 = x + 3$。

$\implies x = 5$。

(f) $\dfrac{3x + 1}{2} - \dfrac{x - 1}{3} = 2$

分母為 $2, 3$，最小公倍數為 $6$。兩邊同乘 $6$：

$6 \cdot \dfrac{3x + 1}{2} - 6 \cdot \dfrac{x - 1}{3} = 6 \cdot 2$。

$\implies 3(3x + 1) - 2(x - 1) = 12$。

去括號：$9x + 3 - 2x + 2 = 12$。

$\implies 7x + 5 = 12$。

$\implies 7x = 7$。

$\implies x = 1$。

#### 題 10（`task` 類）——綜合一元一次方程

**題干**

解下列一元一次方程。

(a) $3(2x - 1) - 2(x + 3) = 4x - 5$

(b) $\dfrac{3x - 1}{2} - \dfrac{x + 2}{3} = x - 1$

(c) $5 - \dfrac{x - 1}{3} = 2 + \dfrac{x + 1}{2}$

(d) $2[3(x - 1) + 2] - 4 = 3(x + 2)$

(e) $\dfrac{x + 1}{2} + \dfrac{x - 1}{3} = \dfrac{2x + 3}{6} + 1$

(f) $3(x + 2) - \dfrac{2x - 1}{3} = x + \dfrac{x + 4}{2}$

**考核目標**

綜合運用去括號、去分母、移項求解。

**詳細解答**

綜合題依序處理（講義 5.2.2）：有分母先去分母、有括號再去括號，然後移項、合併、係數化為 $1$。原式抄入首行。

(a) $3(2x - 1) - 2(x + 3) = 4x - 5$

去括號：

$6x - 3 - 2x - 6 = 4x - 5$。

$\implies 4x - 9 = 4x - 5$。

移項：$4x - 4x = -5 + 9$。

$\implies 0 = 4$。

引出矛盾（$0 = 4$ 恆為假），對任意 $x$ 均不成立。

$\implies$ 無解。

(b) $\dfrac{3x - 1}{2} - \dfrac{x + 2}{3} = x - 1$

分母為 $2, 3$，最小公倍數為 $6$。兩邊同乘 $6$：

$6 \cdot \dfrac{3x - 1}{2} - 6 \cdot \dfrac{x + 2}{3} = 6(x - 1)$。

$\implies 3(3x - 1) - 2(x + 2) = 6(x - 1)$。

去括號：$9x - 3 - 2x - 4 = 6x - 6$。

$\implies 7x - 7 = 6x - 6$。

$\implies x = 1$。

(c) $5 - \dfrac{x - 1}{3} = 2 + \dfrac{x + 1}{2}$

分母為 $3, 2$，最小公倍數為 $6$。兩邊同乘 $6$：

$6 \cdot 5 - 6 \cdot \dfrac{x - 1}{3} = 6 \cdot 2 + 6 \cdot \dfrac{x + 1}{2}$。

$\implies 30 - 2(x - 1) = 12 + 3(x + 1)$。

去括號：$30 - 2x + 2 = 12 + 3x + 3$。

$\implies 32 - 2x = 15 + 3x$。

$\implies 32 - 15 = 3x + 2x$。

$\implies 17 = 5x$。

$\implies x = \dfrac{17}{5}$。

$\implies 2(3x - 3 + 2) - 4 = 3x + 6$。

$\implies 6x - 2 - 4 = 3x + 6$。

$\implies 3x = 12$。

$\implies x = 4$。

(a) $2x - 8y = 9 - x + y$

$2x - 8y - 9 + x - y = 0$。

$2x + y - 6 = 0$。

#### 題 27（`task` 類）——代入消元法

**題干**

用代入消元法解下列方程組。

(a) $\begin{cases} y = x - 2 \\ 2x + y = 4 \end{cases}$

(b) $\begin{cases} x + 2y = 7 \\ y = 3x - 5 \end{cases}$

(c) $\begin{cases} 3x - y = 8 \\ x + 2y = 5 \end{cases}$

(d) $\begin{cases} 2x + 3y = 12 \\ x - y = 1 \end{cases}$

**考核目標**

掌握代入消元法解二元一次方程組（變形→代入→求解→回代）。

**詳細解答**

代入消元法四步（講義 5.4.1）：變形（把一變量用另一變量表示）→代入（代入另一方程消元）→求解（解一元一次方程）→回代。原式抄入首行。

(a) $\begin{cases} y = x - 2 & \cdots\cdots (1) \\ 2x + y = 4 & \cdots\cdots (2) \end{cases}$

$(1)$ 已將 $y$ 用 $x$ 表示。代入 $(2)$：

$2x + (x - 2) = 4$。

$\implies 3x - 2 = 4$。

$\implies 3x = 6$。

$\implies x = 2$。

回代 $(1)$：$y = 2 - 2 = 0$。

$\implies$ 解為 $(x, y) = (2, 0)$。

(b) $\begin{cases} x + 2y = 7 & \cdots\cdots (1) \\ y = 3x - 5 & \cdots\cdots (2) \end{cases}$

$(2)$ 已將 $y$ 用 $x$ 表示。代入 $(1)$：

$x + 2(3x - 5) = 7$。

$\implies x + 6x - 10 = 7$。

$\implies 7x = 17$。

$\implies x = \dfrac{17}{7}$。

回代 $(2)$：$y = 3 \cdot \dfrac{17}{7} - 5 = \dfrac{51}{7} - \dfrac{35}{7} = \dfrac{16}{7}$。

$\implies$ 解為 $\left(x, y\right) = \left(\dfrac{17}{7}, \dfrac{16}{7}\right)$。

(c) $\begin{cases} 3x - y = 8 & \cdots\cdots (1) \\ x + 2y = 5 & \cdots\cdots (2) \end{cases}$

由 $(1)$ 變形，用 $y$ 表示 $x$ 較簡便：

$x = \dfrac{8 + y}{3}$（或由 $(2)$ 得 $x = 5 - 2y$ 代入亦可）。

選 $(2)$ 變形：$x = 5 - 2y$，代入 $(1)$：

$3(5 - 2y) - y = 8$。

$\implies 15 - 6y - y = 8$。

$\implies -7y = -7$。

$\implies y = 1$。

回代：$x = 5 - 2(1) = 3$。

$\implies$ 解為 $(x, y) = (3, 1)$。

(d) $\begin{cases} 2x + 3y = 12 & \cdots\cdots (1) \\ x - y = 1 & \cdots\cdots (2) \end{cases}$

由 $(2)$ 變形：$x = y + 1$，代入 $(1)$：

$2(y + 1) + 3y = 12$。

$\implies 2y + 2 + 3y = 12$。

$\implies 5y = 10$。

$\implies y = 2$。

回代：$x = 2 + 1 = 3$。

$\implies$ 解為 $(x, y) = (3, 2)$。

- 易錯：代入時須整體代入加括號——(a) 中 $2x + (x - 2)$，勿漏括號；(b) 中 $x + 2(3x - 5)$ 展開為 $x + 6x - 10$。
- 易錯：變形選擇——選係數較簡單的方程與變量（如 (c)(d) 由 $x - y = 1$ 得 $x = y + 1$），可減少分數運算。
- 易錯：回代代入哪個方程——代入變形得到的表示式（如 $y = x - 2$）最直接。

#### 題 28（`task` 類）——加減消元法

**題干**

用加減消元法解下列方程組。

(a) $\begin{cases} 2x + 3y = 8 \\ 2x - y = 0 \end{cases}$

(b) $\begin{cases} 3x + 2y = 13 \\ x + 2y = 7 \end{cases}$

(c) $\begin{cases} 4x - 3y = 7 \\ 2x + 5y = -3 \end{cases}$

(d) $\begin{cases} 5x + 2y = 16 \\ 3x - 4y = -2 \end{cases}$

**考核目標**

掌握加減消元法解二元一次方程組（配平係數→加減消元→求解→回代）。

**詳細解答**

加減消元法四步（講義 5.4.2）：變形（乘適當常數使某變量係數絕對值相等）→加減（符號相反相加、相同相減，消去該變量）→求解→回代。原式抄入首行。

(a) $\begin{cases} 2x + 3y = 8 & \cdots\cdots (1) \\ 2x - y = 0 & \cdots\cdots (2) \end{cases}$

兩方程 $x$ 項係數同為 $2$，$(1) - (2)$ 消去 $x$：

$(2x + 3y) - (2x - y) = 8 - 0$。

$\implies 4y = 8$。

$\implies y = 2$。

回代 $(2)$：$2x - 2 = 0$，$x = 1$。

$\implies$ 解為 $(x, y) = (1, 2)$。

(b) $\begin{cases} 3x + 2y = 13 & \cdots\cdots (1) \\ x + 2y = 7 & \cdots\cdots (2) \end{cases}$

兩方程 $y$ 項係數同為 $2$，$(1) - (2)$ 消去 $y$：

$(3x + 2y) - (x + 2y) = 13 - 7$。

$\implies 2x = 6$。

$\implies x = 3$。

回代 $(2)$：$3 + 2y = 7$，$y = 2$。

$\implies$ 解為 $(x, y) = (3, 2)$。

(c) $\begin{cases} 4x - 3y = 7 & \cdots\cdots (1) \\ 2x + 5y = -3 & \cdots\cdots (2) \end{cases}$

兩方程 $x$ 項係數不成倍數關係，先配平：$(2) \times 2$ 得 $4x + 10y = -6$。$(1) - 2(2)$ 消去 $x$：

$(4x - 3y) - (4x + 10y) = 7 - (-6)$。

$\implies -13y = 13$。

$\implies y = -1$。

回代 $(2)$：$2x + 5(-1) = -3$，$2x = 2$，$x = 1$。

$\implies$ 解為 $(x, y) = (1, -1)$。

(d) $\begin{cases} 5x + 2y = 16 & \cdots\cdots (1) \\ 3x - 4y = -2 & \cdots\cdots (2) \end{cases}$

$y$ 項係數 $2$ 與 $-4$ 成倍數關係：$(1) \times 2$ 得 $10x + 4y = 32$。$2(1) + (2)$ 消去 $y$（係數 $+4$ 與 $-4$ 符號相反，相加）：

$(10x + 4y) + (3x - 4y) = 32 + (-2)$。

$\implies 13x = 30$。

$\implies x = \dfrac{30}{13}$。

回代 $(1)$：$5 \cdot \dfrac{30}{13} + 2y = 16$，$2y = 16 - \dfrac{150}{13} = \dfrac{208 - 150}{13} = \dfrac{58}{13}$，$y = \dfrac{29}{13}$。

$\implies$ 解為 $\left(x, y\right) = \left(\dfrac{30}{13}, \dfrac{29}{13}\right)$。

**易錯點注意**

- 易錯：加減消元的方向——係數符號相同用相減（(a)(b)(c)），符號相反用相加（(d) 中 $+4y$ 與 $-4y$）。
- 易錯：配平時兩邊都要乘——(c) 中 $(2) \times 2$ 得 $4x + 10y = -6$，常數項 $-3$ 也要乘 $2$。
- 易錯：相減時括號整體處理——$(4x - 3y) - (4x + 10y) = 7 - (-6)$，第二括號內各項變號。

**難度**

> 判定理由（T）：解答每項需「配平係數→加減消元→解一元一次方程→回代」四步（解答的加減消元鏈），含係數配平，鏈長 3–5 步。
> 判定理由（C）：多步代數運算（含分數答案），每項 4–6 步。
> 判定理由（E）：配平對象與加減方向須自行判斷，屬方法選擇層。

**題干**

(a) $\begin{cases} x - 3y = 1 & \cdots\cdots (1) \\ 2x + 5y = 13 & \cdots\cdots (2) \end{cases}$

$2(3y + 1) + 5y = 13$。

$\implies 6y + 2 + 5y = 13$。

$\implies 11y = 11$。

$\implies y = 1$。

回代：$x = 3(1) + 1 = 4$。

$\implies$ 解為 $(x, y) = (4, 1)$。

(b) $\begin{cases} 3x - 2y = 7 & \cdots\cdots (1) \\ 5x - 2y = 11 & \cdots\cdots (2) \end{cases}$

$(5x - 2y) - (3x - 2y) = 11 - 7$。

$\implies 2x = 4$。

$\implies x = 2$。

回代 $(1)$：$3(2) - 2y = 7$，$-2y = 1$，$y = -\dfrac{1}{2}$。

$\implies$ 解為 $\left(x, y\right) = \left(2, -\dfrac{1}{2}\right)$。

(c) $\begin{cases} \dfrac{x}{2} + y = 3 & \cdots\cdots (1) \\ x - \dfrac{y}{3} = 2 & \cdots\cdots (2) \end{cases}$

先去分母整理：$(1) \times 2$ 得 $x + 2y = 6$；$(2) \times 3$ 得 $3x - y = 6$。

$3(6 - 2y) - y = 6$。

$\implies 18 - 6y - y = 6$。

$\implies -7y = -12$。

$\implies y = \dfrac{12}{7}$。

$\implies$ 解為 $\left(x, y\right) = \left(\dfrac{18}{7}, \dfrac{12}{7}\right)$。

(d) $\begin{cases} 2x + 3y = 7 & \cdots\cdots (1) \\ 4x - 5y = 3 & \cdots\cdots (2) \end{cases}$

$4x$ 是 $2x$ 的 $2$ 倍，用加減法：$(2) - 2(1)$ 消去 $x$：

$(4x - 5y) - (4x + 6y) = 3 - 14$。

$\implies -11y = -11$。

$\implies y = 1$。

回代 $(1)$：$2x + 3(1) = 7$，$x = 2$。

$\implies$ 解為 $(x, y) = (2, 1)$。

#### 題 40（複雜結構類，藍框 `recquestion`）——含參方程組討論

**題干**

設 $k$ 為常數，就方程組 $\begin{cases} x + y = 5 & \cdots\cdots (1) \\ 2x + ky = 9 & \cdots\cdots (2) \end{cases}$ 回答以下問題。

(a) 當 $k = 3$ 時，解該方程組。

(b) 若方程組有唯一解，求 $k$ 的取值範圍。

(c) 是否存在 $k$ 值使方程組無解或有無窮多解？若存在，求出該 $k$ 值並判斷是哪種情況。

**考核目標**

就參數 $k$ 的取值討論二元一次方程組的解的情況。

**詳細解答**

含參方程組解型的判別法（講義 5.4.4）：消元後看得到的方程。消去 $x$ 得 $(k - 2)y = -1$ 型的方程，再就係數是否為零分類。

(a) 代入 $k = 3$：

$\begin{cases} x + y = 5 & \cdots\cdots (1) \\ 2x + 3y = 9 & \cdots\cdots (2) \end{cases}$。

$(2) - 2(1)$ 消去 $x$：

$(2x + 3y) - (2x + 2y) = 9 - 10$。

$\implies y = -1$。

回代 $(1)$：$x + (-1) = 5$，$x = 6$。

$\implies$ 解為 $(x, y) = (6, -1)$。

(b) 先消元求一般形式：$(2) - 2(1)$ 消去 $x$：

$(2x + ky) - (2x + 2y) = 9 - 10$。

$\implies (k - 2)y = -1$。

有唯一解需要 $y$ 的係數非零：

$k - 2 \neq 0$。

$\implies k \neq 2$。

(c) 當 $k = 2$ 時，$(k - 2)y = -1$ 化為 $0 \cdot y = -1$，恆矛盾。

$\implies k = 2$ 時方程組無解。

（無窮多解需要 $0 \cdot y = 0$ 型，但右邊恆為 $-1$，不可能，故不存在 $k$ 使方程組有無窮多解。）

#### 題 41（無結構類，藍框 `recquestion`）——無解條件

**題干**

**考核目標**

由方程組無解反推參數條件（係數成比例而常數不成比例）。

**詳細解答**

兩方程左邊係數成比例時（第二式左邊是第一式的 $k$ 倍），若右邊不成同一比例則無解（講義 5.4.4 矛盾情形）。

第一式的 $x, y$ 係數為 $2, 3$；第二式為 $a, 6$。因 $6 = 3 \times 2$，第二式左邊是第一式的 $2$ 倍（$y$ 係數 $3 \times 2 = 6$），故須 $a = 2 \times 2 = 4$ 才使 $x$ 係數也成比例。

此時第二式為 $4x + 6y = b$，是第一式 $2x + 3y = 5$ 左邊的 $2$ 倍。無解需要右邊不成同一比例：

$b \neq 2 \times 5 = 10$。

$\implies$ 無解條件：$a = 4$ 且 $b \neq 10$。

驗證：$a = 4$、$b = 11$ 時，$(2) - 2(1)$ 得 $0 = 11 - 10 = 1$，矛盾，無解 ✓。

**易錯點注意**

- 易錯：比例關係須同時檢查 $x, y$ 係數——$a = 4$ 使兩式 $x$、$y$ 係數均成 $2$ 倍；若 $a \neq 4$ 則兩式不成比例，必有唯一解（而非無解）。
- 易錯：常數比——$b \neq 10$（$b$ 不可等於 $5$ 的 $2$ 倍），若 $b = 10$ 則兩式恆等，為無窮多解。

(a) 寫出 $d$、$t$ 與 $v$ 之間的關係式。

(b) 當 $v = 80$ 時，求 $t$ 和 $d$。

(c) 消去 $d$，討論 $v$ 取何值時方程組有唯一解或無解，並解釋 $v = 60$ 時「無解」的實際含義。

速率應用建模＋含參討論（距離、時間、速度三量關係）。

甲車：$d = vt$；

$80t = 60(t + 0.5)$。

$\implies 80t = 60t + 30$。

$\implies 20t = 30$。

$\implies t = 1.5$。

回代：$d = 80 \times 1.5 = 120$。

$\implies t = 1.5$ 小時，$d = 120$ km。

(c) 兩式消去 $d$：

$vt = 60(t + 0.5)$。

$\implies vt = 60t + 30$。

$\implies (v - 60)t = 30$。

有唯一解需要 $t$ 的係數非零：

$v - 60 \neq 0$。

$\implies v \neq 60$ 時有唯一解。

當 $v = 60$ 時，$(v - 60)t = 30$ 化為 $0 \cdot t = 30$，恆矛盾。

$\implies v = 60$ 時方程組無解。

**題干**

(a) 寫出以 $x$、$y$ 為未知數的方程組。

(b) 當 $c = 11$ 時，求 $x$ 和 $y$。

(c) 求 $c$ 的值使方程組無（數學）解。即使方程組有數學解，是否必定對應實際可行的混合方案？試以 $c$ 的取值範圍說明。

**考核目標**

濃度應用建模＋含參討論（數學解與實際可行性）。

**詳細解答**

(a) 建模：總體積與溶質（鹽）量各寫一個方程。

總體積：$x + y = 10$；

鹽量：$c\%$ 鹽水 $x$ L 含鹽 $0.01cx$ L，$5\%$ 鹽水 $y$ L 含鹽 $0.05y$ L；混合後 $8\%$ 鹽水 $10$ L 含鹽 $0.08 \times 10 = 0.8$ L。

$0.01cx + 0.05y = 0.8$。

兩邊同乘 $100$：$cx + 5y = 80$。

$\implies$ 方程組：$\begin{cases} x + y = 10 & \cdots\cdots (1) \\ cx + 5y = 80 & \cdots\cdots (2) \end{cases}$。

(b) 代入 $c = 11$：

$\begin{cases} x + y = 10 & \cdots\cdots (1) \\ 11x + 5y = 80 & \cdots\cdots (2) \end{cases}$。

$(2) - 5(1)$ 消去 $y$：

$(11x + 5y) - (5x + 5y) = 80 - 50$。

$\implies 6x = 30$。

$\implies x = 5$。

回代 $(1)$：$y = 5$。

$\implies x = 5$ L，$y = 5$ L。

(c) 消元：$(2) - c(1)$：

$(cx + 5y) - (cx + cy) = 80 - 10c$。

$\implies (5 - c)y = 80 - 10c$。

無（數學）解需要 $y$ 的係數為零而右邊非零：

$5 - c = 0$ 且 $80 - 10c \neq 0$。

$\implies c = 5$ 且 $80 - 50 = 30 \neq 0$。

$\implies c = 5$ 時方程組無解（兩瓶濃度相同皆 $5\%$，混合後濃度只能是 $5\%$，不可能為 $8\%$）。

$\implies$ 數學解不一定對應實際可行方案；須 $c \ge 8$ 才可行（$c = 5$ 無解，$5 < c < 8$ 有數學解但 $x < 0$ 不實際）。

**易錯點注意**

#### 題 47（複雜結構類，藍框 `recquestion`）——投資回報

**題干**

陳先生將 $\$10$ 萬元投資於兩種產品：A 產品回報率為 $r\%$，B 產品回報率為 $4\%$。設投資 A 產品 $x$ 萬元、B 產品 $y$ 萬元，一年後總回報為 $\$0.6$ 萬元，其中 $r$ 為常數。

(a) 寫出以 $x$、$y$ 為未知數的方程組。

(c) 當 $r = 4$ 時，方程組的解屬何種情況？試解釋此情況在實際中的含義。

(d) 若要求 $x \ge 0$ 且 $y \ge 0$，求 $r$ 的取值範圍。

**考核目標**

投資回報建模＋含參討論（解型與非負約束）。

**詳細解答**

(a) 建模：總投資與總回報各寫一個方程（金額單位皆為萬元）。

總投資：$x + y = 10$；

總回報：A 產品回報 $r\% \cdot x = \dfrac{r}{100}x$ 萬元，B 產品回報 $4\% \cdot y = 0.04y$ 萬元，合計 $0.6$ 萬元：

$\dfrac{r}{100}x + 0.04y = 0.6$。

兩邊同乘 $100$：$rx + 4y = 60$。

$\implies$ 方程組：$\begin{cases} x + y = 10 & \cdots\cdots (1) \\ rx + 4y = 60 & \cdots\cdots (2) \end{cases}$。

(b) 代入 $r = 8$：

$\begin{cases} x + y = 10 & \cdots\cdots (1) \\ 8x + 4y = 60 & \cdots\cdots (2) \end{cases}$。

$(2) - 4(1)$ 消去 $y$：

$(8x + 4y) - (4x + 4y) = 60 - 40$。

$\implies 4x = 20$。

$\implies x = 5$。

回代 $(1)$：$y = 5$。

$\implies x = 5$ 萬元，$y = 5$ 萬元。

(c) 代入 $r = 4$：$4x + 4y = 60$，即 $x + y = 15$（兩邊同除以 $4$）。

與 $(1)$：$x + y = 10$ 比較，左邊相同而右邊不同（$15 \neq 10$），矛盾。

$\implies$ 方程組無解。

實際含義：$r = 4$ 時兩種產品回報率相同（皆 $4\%$），投資 $10$ 萬元一年回報必為 $10 \times 4\% = 0.4$ 萬元，不可能為 $0.6$ 萬元——條件與回報率矛盾。

(d) 消元：$(2) - r(1)$：

$(rx + 4y) - (rx + ry) = 60 - 10r$。

$\implies (4 - r)y = 60 - 10r$。

$\implies y = \dfrac{60 - 10r}{4 - r}$（$r \neq 4$ 時）。

要求 $y \ge 0$：分母 $4 - r$ 與分子 $60 - 10r = 10(6 - r)$ 須同號（或分子為零）。

$\dfrac{60 - 10r}{4 - r} \le 10 \iff 60 - 10r \le 40 - 10r \iff 60 \le 40$，不成立。

故 $r < 4$ 時 $y > 10$，$x < 0$，不符。

$r > 4$ 時分母為負，分子 $10(6 - r)$：$r < 6$ 時分子為正，$y < 0$，不符；$r \ge 6$ 時分子 $\le 0$，$y \ge 0$ ✓，且 $x = 10 - y \ge 0$ ✓（$r = 6$ 時 $y = 0$，$x = 10$；$r = 8$ 時 $y = 5$；$r \to \infty$ 時 $y \to 10^-$）。

$\implies$ 須 $r \ge 6$ 才有 $x, y \ge 0$（$r = 4$ 無解不考慮；$4 < r < 6$ 時 $y < 0$）。

### §5.4 試根法

#### 題 48（`task` 類）——試根法解方程

**題干**

用試根法解下列方程。

(a) $x^2 - 5x + 6 = 0$

(b) $x^3 - 6x^2 + 11x - 6 = 0$

(c) $x^2 - 4 = 0$

(d) $x^3 + 2x^2 - x - 2 = 0$

**考核目標**

用試根法（整數試探＋驗證）解簡單整係數多項式方程。

**詳細解答**

試根法（講義 5.5）：依方程特徵選取可能的整數值（通常從 $0, \pm 1, \pm 2$ 等入手）代入驗證，使等式成立的即為根。原式抄入首行。

(a) $x^2 - 5x + 6 = 0$

試 $x = 2$：$2^2 - 5(2) + 6 = 4 - 10 + 6 = 0$ ✓。

試 $x = 3$：$3^2 - 5(3) + 6 = 9 - 15 + 6 = 0$ ✓。

$\implies$ 根為 $x = 2$ 或 $x = 3$。

(b) $x^3 - 6x^2 + 11x - 6 = 0$

試 $x = 1$：$1 - 6 + 11 - 6 = 0$ ✓。

試 $x = 2$：$8 - 24 + 22 - 6 = 0$ ✓。

試 $x = 3$：$27 - 54 + 33 - 6 = 0$ ✓。

$\implies$ 根為 $x = 1$、$x = 2$ 或 $x = 3$。

(c) $x^2 - 4 = 0$

試 $x = 2$：$4 - 4 = 0$ ✓。

試 $x = -2$：$4 - 4 = 0$ ✓。

$\implies$ 根為 $x = 2$ 或 $x = -2$。

(d) $x^3 + 2x^2 - x - 2 = 0$

試 $x = 1$：$1 + 2 - 1 - 2 = 0$ ✓。

試 $x = -1$：$-1 + 2 + 1 - 2 = 0$ ✓。

試 $x = 2$：$8 + 8 - 2 - 2 = 12 \neq 0$ ✗。

試 $x = -2$：$-8 + 8 + 2 - 2 = 0$ ✓。

$\implies$ 根為 $x = 1$、$x = -1$ 或 $x = -2$。

**易錯點注意**

- 易錯：試根不是亂猜——依常數項的因數（如 $6$ 的因數 $\pm 1, \pm 2, \pm 3$）有規律地試探，並逐一驗證。
- 易錯：負數試根——(c)(d) 中 $x = -2$、$x = -1$ 代入時負號勿錯（$(-2)^2 = 4$、$(-1)^3 = -1$）。
- 易錯：多項式方程可能有多個根（次數即最多根數）——(b)(d) 三次方程須找全 $3$ 個根。

**難度**

> 題 48｜難度：**T C｜C C｜E C｜Q C**
> 判定理由（T）：解答每項需「選整數試探→代入計算→驗證」多步（解答的試根鏈），三次方程須找全多個根，鏈長 3–5 步。
> 判定理由（C）：多步代入計算（含冪運算），每項 3–6 步。
> 判定理由（E）：試探值的選擇須自行判斷（依因數），屬方法選擇層。
> 判定理由（Q）：方程 × 多項式（Ch04），跨課題。

### §5.6 理論問題

#### 題 55（簡單結構類，藍框 `recquestion`）——三元方程組唯一解

**題干**

證明方程組 $\begin{cases} x + y + z = a & \cdots\cdots (1) \\ x - y + z = b & \cdots\cdots (2) \\ x + y - z = c & \cdots\cdots (3) \end{cases}$ 必有唯一解，並求出該解。

(a) 利用加減消元法分別求出 $y$ 與 $z$（用 $a, b, c$ 表示）。

(b) 代入求出 $x$，並說明為何此解是唯一的。

**考核目標**

把加減消元法推廣至三元方程組，論證解的存在與唯一。

**詳細解答**

把二元加減消元的思路推廣（講義 5.4.2）：相減消去某變量，逐步化簡。方程中 $y, z$ 的係數在 $(1)(2)(3)$ 間有對稱性，用相減即可消元。

(a) $(1) - (2)$ 消去 $x$ 與 $z$：

$(x + y + z) - (x - y + z) = a - b$。

$\implies 2y = a - b$。

$\implies y = \dfrac{a - b}{2}$。

$(1) - (3)$ 消去 $x$ 與 $y$：

$(x + y + z) - (x + y - z) = a - c$。

$\implies 2z = a - c$。

$\implies z = \dfrac{a - c}{2}$。

(b) 代入 $(1)$：

$x + \dfrac{a - b}{2} + \dfrac{a - c}{2} = a$。

$\implies x = a - \dfrac{a - b}{2} - \dfrac{a - c}{2}$。

通分：

$x = \dfrac{2a - (a - b) - (a - c)}{2} = \dfrac{2a - a + b - a + c}{2} = \dfrac{b + c}{2}$。

唯一性：求解過程每一步都是恆等變換（相減、代入），保持方程組等價（講義 5.3.3）；$y, z, x$ 分別由 $a, b, c$ 唯一確定，故方程組必有且僅有一組解。

$\implies$ 唯一解為 $\left(x, y, z\right) = \left(\dfrac{b + c}{2}, \dfrac{a - b}{2}, \dfrac{a - c}{2}\right)$。

**易錯點注意**

#### 題 56（複雜結構類，藍框 `recquestion`）——解的公式推導

**題干**

考慮一般形式的二元一次方程組：

$$\begin{cases} a_1 x + b_1 y = c_1 & \cdots\cdots (1) \\ a_2 x + b_2 y = c_2 & \cdots\cdots (2) \end{cases}$$

其中 $a_1, b_1, a_2, b_2$ 為常數且 $a_1 b_2 - a_2 b_1 \neq 0$。

(a) 利用加減消元法消去 $y$，推導 $x$ 的解。（提示：考慮 $b_2 (1)$ 及 $b_1 (2)$）

(b) 利用加減消元法消去 $x$，推導 $y$ 的解。（提示：考慮 $a_2 (1)$ 及 $a_1 (2)$）

(c) 由此證明此方程組必有唯一解。

**考核目標**

用加減消元法推導一般方程組解的公式（用已建定理推新結論）。

**詳細解答**

把加減消元法（講義 5.4.2）應用到含參一般形式：配平 $y$（或 $x$）的係數後相減消元，得到單變量方程，再解出公式。

(a) 消去 $y$：考慮 $b_2 \times (1) - b_1 \times (2)$。

$b_2(1)$：$a_1 b_2 x + b_1 b_2 y = c_1 b_2$；

$b_1(2)$：$a_2 b_1 x + b_1 b_2 y = c_2 b_1$。

相減：

$(a_1 b_2 - a_2 b_1)x = c_1 b_2 - c_2 b_1$。

因 $a_1 b_2 - a_2 b_1 \neq 0$，兩邊同除以 $a_1 b_2 - a_2 b_1$：

$\implies x = \dfrac{c_1 b_2 - c_2 b_1}{a_1 b_2 - a_2 b_1}$。

(b) 消去 $x$：考慮 $a_2 \times (1) - a_1 \times (2)$。

$a_2(1)$：$a_1 a_2 x + b_1 a_2 y = c_1 a_2$；

$a_1(2)$：$a_1 a_2 x + b_2 a_1 y = c_2 a_1$。

相減：

$(b_1 a_2 - b_2 a_1)y = c_1 a_2 - c_2 a_1$。

整理（分母與 (a) 一致）：

$\implies y = \dfrac{a_1 c_2 - a_2 c_1}{a_1 b_2 - a_2 b_1}$。

(c) 由 (a)(b)，$x, y$ 的表達式分母均為 $a_1 b_2 - a_2 b_1 \neq 0$，故 $x, y$ 有確定值；且每一步為恆等變換（等價），方程組等價於 $x, y$ 取上述值的單點條件。

$\implies$ 方程組必有唯一解 $\left(x, y\right) = \left(\dfrac{c_1 b_2 - c_2 b_1}{a_1 b_2 - a_2 b_1}, \dfrac{a_1 c_2 - a_2 c_1}{a_1 b_2 - a_2 b_1}\right)$。

**易錯點注意**

- 易錯：(a) 相減時 $b_1 b_2 y$ 抵消——兩式 $y$ 係數皆為 $b_1 b_2$，相減消去 $y$，剩 $x$ 的方程。

- 易錯：勿引用未學過的「行列式／克拉默公式」命名——本題只用加減消元推導，公式為解的公式，不引入新工具。

> 判定理由（C）：含參代數運算。
> 判定理由（E）：一般化消元的組織須自行進行，屬概念遷移層。

> 判定理由（C）：含參代數運算。
> 判定理由（E）：對稱推導的組織須自行進行，屬概念遷移層。

#### 題 57（無結構類，藍框 `recquestion`）——換元證明

**題干**

設 $a$、$b$ 為實數，且滿足 $a + b \neq 0$ 及 $a - b \neq 0$。證明方程組

$$\begin{cases} \dfrac{1}{x} + \dfrac{1}{y} = a & \cdots\cdots (1) \\ \dfrac{1}{x} - \dfrac{1}{y} = b & \cdots\cdots (2) \end{cases}$$

有解且有唯一解。（提示：設 $u = \dfrac{1}{x}$，$v = \dfrac{1}{y}$。）

**考核目標**

用換元法把分式方程組化為線性方程組，並由非零條件論證解的存在與唯一。

**詳細解答**

方程含 $\dfrac{1}{x}$、$\dfrac{1}{y}$，按提示換元：設 $u = \dfrac{1}{x}$，$v = \dfrac{1}{y}$（替換思想，講義 5.1.2）。

代入原方程組：

$\begin{cases} u + v = a & \cdots\cdots (1') \\ u - v = b & \cdots\cdots (2') \end{cases}$。

$(1') + (2')$ 消去 $v$：

$2u = a + b$。

$\implies u = \dfrac{a + b}{2}$。

$(1') - (2')$ 消去 $u$：

$2v = a - b$。

$\implies v = \dfrac{a - b}{2}$。

因 $a + b \neq 0$ 且 $a - b \neq 0$，$u \neq 0$ 且 $v \neq 0$，故 $x = \dfrac{1}{u} = \dfrac{2}{a + b}$、$y = \dfrac{1}{v} = \dfrac{2}{a - b}$ 均有定義（分母非零）且唯一。

$\implies$ 方程組有解且有唯一解：$\left(x, y\right) = \left(\dfrac{2}{a + b}, \dfrac{2}{a - b}\right)$。

**易錯點注意**

- 易錯：換元後必須檢驗 $u, v \neq 0$——由 $x = \dfrac{1}{u}$ 知 $u = 0$ 時 $x$ 無定義；條件 $a + b \neq 0$、$a - b \neq 0$ 恰保證 $u, v$ 非零。
- 易錯：加減消元方向——$(1') + (2')$ 得 $2u = a + b$（$+v$ 與 $-v$ 相消），$(1') - (2')$ 得 $2v = a - b$。

**難度**

> 題 57｜難度：**T B-｜C C｜E B｜Q D**
> 判定理由（T）：解答需「換元→線性化→加減消元→非零檢驗→代回」多步（解答的換元＋消元＋非零論證），鏈長 5–6 步，B- 下限。
> 判定理由（C）：分式代數運算。
> 判定理由（E）：換元證明與非零條件的運用須自行組織，屬概念遷移層。
> 判定理由（Q）：方程組單課題。

#### 題 58（無結構類，藍框 `recquestion`）——判斷陳述

**題干**

判斷陳述是否正確。正確则給出證明，不正確则給出反例：

「若 $a \neq b$，則方程組 $\begin{cases} x + ay = 1 \\ x + by = 1 \end{cases}$ 有唯一解。」

**考核目標**

判斷含參方程組陳述的真假，正確則證明、不正確則舉反例。

**詳細解答**

先化簡判斷。原式抄入首行：

$\begin{cases} x + ay = 1 & \cdots\cdots (1) \\ x + by = 1 & \cdots\cdots (2) \end{cases}$。

$(1) - (2)$ 消去 $x$：

$(x + ay) - (x + by) = 1 - 1$。

$\implies (a - b)y = 0$。

因 $a \neq b$，$a - b \neq 0$，兩邊同除以 $a - b$：

$y = 0$。

回代 $(1)$：$x + a \cdot 0 = 1$，$x = 1$。

$\implies$ 方程組有唯一解 $(x, y) = (1, 0)$。

$\implies$ 陳述正確。（證明：$(1)-(2)$ 得 $(a - b)y = 0$，由 $a \neq b$ 得 $y = 0$，代回得 $x = 1$，唯一。）

**易錯點注意**

- 易錯：$(1) - (2)$ 的方向——消去 $x$ 後得 $(a - b)y = 0$，勿把 $a, b$ 的位置寫反。
- 易錯：除以 $a - b$ 的合法性——因 $a \neq b$ 故 $a - b \neq 0$，可以安全相除；這是本題的關鍵條件。

**難度**

#### 題 59（複雜結構類，藍框 `recquestion`）——解型總結

**題干**

考慮二元一次方程組

$$\begin{cases} a_1 x + b_1 y = c_1 & \cdots\cdots (1) \\ a_2 x + b_2 y = c_2 & \cdots\cdots (2) \end{cases}$$

其中 $a_1, b_1$ 不全為零，$a_2, b_2$ 不全為零。

第 57 題已證：當 $a_1 b_2 - a_2 b_1 \neq 0$ 時，方程組有唯一解。現討論 $a_1 b_2 - a_2 b_1 = 0$ 的情況。

(a) 考慮由步驟 $b_2 \times (1) - b_1 \times (2)$ 消去 $y$，由此證明若 $b_1 c_2 - b_2 c_1 \neq 0$，則方程組無解。

(b) 考慮由步驟 $a_2 \times (1) - a_1 \times (2)$ 消去 $x$，由此證明若 $a_1 c_2 - a_2 c_1 \neq 0$，則方程組無解。

(c) 證明若 $b_1 c_2 - b_2 c_1 = 0$ 且 $a_1 c_2 - a_2 c_1 = 0$，則方程組有無窮多解。

(d) 由此總結二元一次方程組在何條件下有唯一解、無解、無窮多解？

**考核目標**

系統總結一般方程組解型的判別條件（用已建定理推新結論）。

**詳細解答**

(a) 消去 $y$：$b_2(1) - b_1(2)$。

$b_2(1)$：$a_1 b_2 x + b_1 b_2 y = c_1 b_2$；

$b_1(2)$：$a_2 b_1 x + b_1 b_2 y = c_2 b_1$。

相減：

$(a_1 b_2 - a_2 b_1)x = c_1 b_2 - c_2 b_1$。

因 $a_1 b_2 - a_2 b_1 = 0$，左邊為 $0 \cdot x = 0$；若 $c_1 b_2 - c_2 b_1 \neq 0$（即 $b_1 c_2 - b_2 c_1 \neq 0$），則得 $0 = c_1 b_2 - c_2 b_1 \neq 0$，矛盾。

$\implies$ 若 $b_1 c_2 - b_2 c_1 \neq 0$，方程組無解。

(b) 消去 $x$：$a_2(1) - a_1(2)$。

$a_2(1)$：$a_1 a_2 x + b_1 a_2 y = c_1 a_2$；

$a_1(2)$：$a_1 a_2 x + b_2 a_1 y = c_2 a_1$。

相減：

$(b_1 a_2 - b_2 a_1)y = c_1 a_2 - c_2 a_1$。

因 $a_1 b_2 - a_2 b_1 = 0$，左邊係數 $b_1 a_2 - b_2 a_1 = -(a_1 b_2 - a_2 b_1) = 0$；若 $c_1 a_2 - c_2 a_1 \neq 0$（即 $a_1 c_2 - a_2 c_1 \neq 0$），則得 $0 = c_1 a_2 - c_2 a_1 \neq 0$，矛盾。

$\implies$ 若 $a_1 c_2 - a_2 c_1 \neq 0$，方程組無解。

(c) 已知 $b_1 c_2 - b_2 c_1 = 0$ 且 $a_1 c_2 - a_2 c_1 = 0$，且 $a_1 b_2 - a_2 b_1 = 0$（本題前提）。

由 $a_1 b_2 = a_2 b_1$、$b_1 c_2 = b_2 c_1$、$a_1 c_2 = a_2 c_1$，三組數成比例：存在非零 $\lambda$ 使 $a_2 = \lambda a_1$、$b_2 = \lambda b_1$、$c_2 = \lambda c_1$（因 $a_1, b_1$ 不全為零，可選其一為基準）。

則 $(2)$ 為 $\lambda a_1 x + \lambda b_1 y = \lambda c_1$，即 $\lambda(1)$——兩方程實為同一方程的倍數，提供完全相同的信息。

由二元一次方程有無窮多解（講義 5.3.1 定理），方程組退化為單一方程：

$\implies$ 方程組有無窮多解。

(d) 總結判別條件：

- $a_1 b_2 - a_2 b_1 \neq 0$：唯一解（題 57 已證）；
- $a_1 b_2 - a_2 b_1 = 0$ 且 $b_1 c_2 - b_2 c_1 \neq 0$（或 $a_1 c_2 - a_2 c_1 \neq 0$）：無解（(a)(b) 已證）；
- $a_1 b_2 - a_2 b_1 = 0$ 且 $b_1 c_2 - b_2 c_1 = 0$ 且 $a_1 c_2 - a_2 c_1 = 0$：無窮多解（(c) 已證）。

$\implies$ 二元一次方程組的解型由 $a_1 b_2 - a_2 b_1$ 是否為零及常數項比例是否一致完全判定。

**易錯點注意**

- 易錯：(a)(b) 中消元後左邊係數為 $0$——由前提 $a_1 b_2 - a_2 b_1 = 0$，相減後 $x$（或 $y$）項消失；右邊非零即矛盾。
- 易錯：(c) 比例論證——須由三個式子同時為零推兩方程成比例（$a_2 : a_1 = b_2 : b_1 = c_2 : c_1$），因 $a_1, b_1$ 不全為零故比例因子存在。
- 易錯：(d) 總結條件要完整——無解與無窮多解都是在 $a_1 b_2 - a_2 b_1 = 0$ 的前提下再分常數比例是否一致。
