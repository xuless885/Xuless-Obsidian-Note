$\dfrac{138 - 120}{120} \times 100\% = +15\%$

#### 題 6（無結構類）——連續百分變化不可直接加減

**題干**

小明認為「先增加 $20\%$ 再減少 $20\%$，結果不變」。你同意嗎？若不同意，以原值 $100$ 為例計算實際結果，並解釋原因。

**考核目標**

辨析「連續百分變化不可直接加減百分率」：減少 $20\%$ 的基數已是加價後的值。

**詳細解答**

以具體數值驗算：$100 \times 1.2 \times 0.8 = 96 \neq 100$，可見兩次變化不可抵消。

不同意。

$$\begin{aligned}

100 \times 1.20 &= 120 \\

120 \times 0.80 &= 96

\end{aligned}$$
$\implies$ 最終值為 $96 \neq 100$，百分變化須逐次乘以 $(1 \pm r\%)$，不能直接加減百分率。


**易錯點注意**

- 易錯：增 $20\%$ 再減 $20\%$ 的結果是 $96$（$100 \to 120 \to 96$）而非回到 $100$——減少的基數已是 $120$。


**難度**

#### 題 47（複雜結構類）——更比、合比、分比、等比四定理

**題干**

設 $a : b = c : d = k$（$k \neq 0$）。

(a) 更比定理（Alternendo）：證明 $a : c = b : d$。

(b) 合比定理（Componendo）：證明 $(a + b) : b = (c + d) : d$。

(c) 分比定理（Dividendo）：證明 $(a - b) : b = (c - d) : d$。

(d) 等比定理（Addendo）：證明 $(a + c) : (b + d) = k$。

**考核目標**

以比例常數法（設 $a = kb$、$c = kd$）統一證明四定理，理解四定理為同一代入法的等價表述。

**詳細解答**


(a)

$a : c = kb : kd = b : d$。

(b)

$$\begin{aligned}
(a + b) : b &= (kb + b) : b \\
&\equiv (k + 1) : 1 \\
(c + d) : d &= (kd + d) : d \\
&\equiv (k + 1) : 1
\end{aligned}$$
$\implies (a + b) : b = (c + d) : d$。

(c)

$$\begin{aligned}
(a - b) : b &= (kb - b) : b \\
&\equiv (k - 1) : 1 \\
(c - d) : d &= (kd - d) : d \\
&\equiv (k - 1) : 1
\end{aligned}$$
$\implies (a - b) : b = (c - d) : d$。

(d)

$$\begin{aligned}
(a + c) : (b + d) &= (kb + kd) : (b + d) \\
&\equiv k(b + d) : (b + d) \\
&= k
\end{aligned}$$
$\implies (a + c) : (b + d) = k$。

**易錯點注意**

- 易錯：(d) 等比定理 $\frac{a+c}{b+d} = \frac{kb+kd}{b+d} = k$，須註明 $b+d \neq 0$；各定理代入時 $k$ 須一致。


**難度**

> 分題 (a)｜難度：**T B-｜C D｜E B｜Q D**
> 判定理由（T）：由 $a:b=c:d=k$ 推 $a:c=b:d$，鏈 3 步，B- 下限。
> 判定理由（C）：無計算。
> 判定理由（E）：須自行組織證明，概念遷移層。
> 判定理由（Q）：比例定理單課題。

> 分題 (b)｜難度：**T B-｜C C｜E B｜Q D**
> 判定理由（T）：證合比定理 $(a+b):b=(c+d):d$，鏈 3–4 步。
> 判定理由（C）：代數變形。

等比定理的加權推廣。設 $\dfrac{a_1}{b_1} = \dfrac{a_2}{b_2} = \cdots = \dfrac{a_n}{b_n} = k$（$b_1, b_2, \ldots, b_n \neq 0$），且 $w_1, w_2, \ldots, w_n$ 為正數。

(a) 以 $k$ 及 $w_i b_i$ 表示 $w_i a_i$（$i = 1, 2, \ldots, n$）。

(b) 證明 $\dfrac{w_1a_1 + w_2a_2 + \cdots + w_na_n}{w_1b_1 + w_2b_2 + \cdots + w_nb_n} = k$。

**考核目標**

以比例常數法把講義的等比定理推廣至「加權和之比」：先以 $a_i = kb_i$ 寫出 $w_i a_i = k \cdot w_i b_i$，再對加權和提取 $k$ 約分；加權結構對應 §7.4.2 混合比例的 $\dfrac{\sum p_i w_i}{\sum w_i}$，理解等比定理與加權平均的內在聯繫（聯動 Ch6 代數式）。

**詳細解答**

由 $a_i = kb_i$ 兩邊同乘正數 $w_i$，權重即織入每個 $b_i$ 的係數，其後對加權和提取公因數 $k$ 約分——證明結構與講義等比定理同源，但結論推廣至任意權重的和之比。

(a)

$w_i a_i = k \cdot w_i b_i$（$i = 1, 2, \ldots, n$）

(b)

把每個 $w_i a_i$ 代換為 $k \cdot w_i b_i$（依 (a) 的結論）：

$$\begin{aligned}
\dfrac{w_1a_1 + w_2a_2 + \cdots + w_na_n}{w_1b_1 + w_2b_2 + \cdots + w_nb_n} &= \dfrac{k w_1 b_1 + k w_2 b_2 + \cdots + k w_n b_n}{w_1 b_1 + w_2 b_2 + \cdots + w_n b_n} \\
&= \dfrac{k(w_1 b_1 + w_2 b_2 + \cdots + w_n b_n)}{w_1 b_1 + w_2 b_2 + \cdots + w_n b_n} \\
&= k
\end{aligned}$$
須 $w_1 b_1 + w_2 b_2 + \cdots + w_n b_n \neq 0$——因 $w_i > 0$ 且 $b_i \neq 0$，當各 $b_i$ 同號時自動成立。

**易錯點注意**

- 易錯：提取公因數 $k$ 時須連同權重保留分母的 $w_i b_i$，勿把 $w_i$ 誤約去；證明末須確認 $\sum w_i b_i \neq 0$——因 $w_i > 0$，若各 $b_i$ 同號則自動成立，否則仍須檢驗。

\end{aligned}$$

又因 $a > 0$、$b > 0$，$\dfrac{a}{a+b} > 0$ 且 $\dfrac{a}{a+b} < 1$（因 $b > 0$），故 $0 < r < 1$；$1-r = \dfrac{b}{a+b} > 0$。

(b)

$a : b = 3 : 5$ 時，$r = \dfrac{3}{3+5} = \dfrac{3}{8}$。

$r = \dfrac{2}{7}$ 時，$a : b = \dfrac{2}{7} : \dfrac{5}{7} = 2 : 5$。
