### §3.1 指數運算律

#### 題 1（`task` 類）——同底數冪相乘（已知底數）

**題干**

利用運算律 $a^m \times a^n = a^{m+n}$ 化簡下列各式。

(a) $2^3 \times 2^4$

(b) $3^2 \times 3^5$

(c) $5 \times 5^4$

(d) $(-2)^3 \times (-2)^2$

(e) $7^3 \times 7^4$

(f) $10^2 \times 10^3 \times 10^4$

(g) $\left(\dfrac{1}{2}\right)^3 \times \left(\dfrac{1}{2}\right)^2$

(h) $(-3)^4 \times (-3)^3$

**考核目標**

套用 $a^m \times a^n = a^{m+n}$ 合併同底數冪。

**詳細解答**

(a) $2^3 \times 2^4 = 2^{3+4} = 2^7 = 128$。

(b) $3^2 \times 3^5 = 3^{2+5} = 3^7 = 2187$。

(c) $5 \times 5^4 = 5^{1+4} = 5^5 = 3125$（注意 $5 = 5^1$）。

(d) $(-2)^3 \times (-2)^2 = (-2)^{3+2} = (-2)^5 = -32$（負底數，奇數次冪為負）。

(e) $7^3 \times 7^4 = 7^{3+4} = 7^7 = 823543$。

(f) $10^2 \times 10^3 \times 10^4 = 10^{2+3+4} = 10^9$（多項合併，指數相加）。

(g) $\left(\dfrac{1}{2}\right)^3 \times \left(\dfrac{1}{2}\right)^2 = \left(\dfrac{1}{2}\right)^{3+2} = \left(\dfrac{1}{2}\right)^5 = \dfrac{1}{32}$。

(h) $(-3)^4 \times (-3)^3 = (-3)^{4+3} = (-3)^7 = -2187$（負底數，奇數次冪為負）。

**易錯點注意**
- 易錯：把 $a^m \times a^n$ 誤算為 $a^{m \times n}$——運算律是**指數相加**（$a^{m+n}$），不是相乘。
- 易錯：(c) 中把 $5$ 當作「指數 $0$」——$5 = 5^1$，指數是 $1$，故 $5 \times 5^4 = 5^{1+4} = 5^5$。
- 易錯：負底數的符號——(d)(h) 中 $(-2)^5$、$(-3)^7$ 指數為奇數，結果為負；判斷符號後再算絕對值的冪。

**難度**

#### 題 2（`task` 類）——同底數冪相除（已知底數）

**題干**

利用運算律 $\dfrac{a^m}{a^n} = a^{m-n}$（$m > n$）化簡下列各式。

(a) $\dfrac{5^4}{5^2}$

(b) $\dfrac{3^7}{3^4}$

(c) $\dfrac{2^8}{2^3}$

(d) $\dfrac{(-4)^5}{(-4)^2}$

(e) $\dfrac{10^6}{10^2}$

(f) $\dfrac{7^8}{7^4}$

(g) $\dfrac{6^5}{6^4}$

(h) $\dfrac{(-2)^7}{(-2)^4}$

**考核目標**

套用 $\dfrac{a^m}{a^n} = a^{m-n}$ 合併同底數冪。

**詳細解答**

(a) $\dfrac{5^4}{5^2} = 5^{4-2} = 5^2 = 25$。

(b) $\dfrac{3^7}{3^4} = 3^{7-4} = 3^3 = 27$。

(c) $\dfrac{2^8}{2^3} = 2^{8-3} = 2^5 = 32$。

(d) $\dfrac{(-4)^5}{(-4)^2} = (-4)^{5-2} = (-4)^3 = -64$。

(e) $\dfrac{10^6}{10^2} = 10^{6-2} = 10^4 = 10000$。

(f) $\dfrac{7^8}{7^4} = 7^{8-4} = 7^4 = 2401$。

(g) $\dfrac{6^5}{6^4} = 6^{5-4} = 6^1 = 6$。

(h) $\dfrac{(-2)^7}{(-2)^4} = (-2)^{7-4} = (-2)^3 = -8$。

**易錯點注意**
- 易錯：把同底數冪相除誤算為指數相乘——運算律是**指數相減**（$a^{m-n}$），如 $\dfrac{5^4}{5^2} = 5^{4-2}$，不是 $5^{4 \times 2}$。
- 易錯：負底數的符號——(d) $(-4)^3$、(h) $(-2)^3$ 指數為奇數，結果為負。
- 易錯：(g) $6^1 = 6$——指數為 $1$ 時勿漏寫結果（仍等於底數本身）。

#### 題 3（`task` 類）——冪的冪（已知底數）

**題干**

利用運算律 $(a^m)^n = a^{mn}$ 化簡下列各式。

(a) $(2^3)^2$

(b) $(3^2)^4$

(c) $(5^2)^3$

(d) $((-2)^3)^2$

(e) $(10^2)^4$

(f) $(7^3)^2$

(g) $\left(\left(\dfrac{1}{2}\right)^2\right)^3$

(h) $((-3)^2)^3$

**考核目標**

套用 $(a^m)^n = a^{mn}$ 合併冪的冪。

**詳細解答**

(a) $(2^3)^2 = 2^{3\times2} = 2^6 = 64$。

(b) $(3^2)^4 = 3^{2\times4} = 3^8 = 6561$。

(c) $(5^2)^3 = 5^{2\times3} = 5^6 = 15625$。

(d) $((-2)^3)^2 = (-2)^{3\times2} = (-2)^6 = 64$。

(e) $(10^2)^4 = 10^{2\times4} = 10^8$。

(f) $(7^3)^2 = 7^{3\times2} = 7^6 = 117649$。

(g) $\left(\left(\dfrac{1}{2}\right)^2\right)^3 = \left(\dfrac{1}{2}\right)^6 = \dfrac{1}{64}$。

(h) $((-3)^2)^3 = (-3)^{2\times3} = (-3)^6 = 729$。

**易錯點注意**
- 易錯：把 $(a^m)^n$ 誤算為 $a^{m+n}$——冪的冪律是**指數相乘**（$a^{mn}$），如 $(2^3)^2 = 2^{3\times2} = 2^6$。
- 易錯：負底數的符號——(d) $(-2)^6$、(h) $(-3)^6$ 指數為偶數，結果為正。
- 易錯：分數底數的嵌套冪——先算內層冪再算外層（或直接相乘指數），如 $\left(\left(\frac{1}{2}\right)^2\right)^3 = \left(\frac{1}{2}\right)^6$。

#### 題 4（`task` 類）——積與商的冪（已知底數）

**題干**

利用運算律 $(ab)^n = a^n b^n$ 及 $\left(\dfrac{a}{b}\right)^n = \dfrac{a^n}{b^n}$ 化簡下列各式。

(a) $(2 \times 3)^2$

(b) $(5 \times 2)^3$

(c) $(-2 \times 3)^3$

(d) $(4 \times 5)^2$

(e) $\left(\dfrac{2}{3}\right)^3$

(f) $\left(\dfrac{3}{4}\right)^2$

(g) $\left(-\dfrac{1}{2}\right)^4$

(h) $\left(\dfrac{5}{2}\right)^3$

**考核目標**

套用積與商的冪律展開計算。

**詳細解答**

(a) $(2 \times 3)^2 = 2^2 \times 3^2 = 4 \times 9 = 36$。

(b) $(5 \times 2)^3 = 5^3 \times 2^3 = 125 \times 8 = 1000$。

(c) $(-2 \times 3)^3 = (-2)^3 \times 3^3 = -8 \times 27 = -216$。

(d) $(4 \times 5)^2 = 4^2 \times 5^2 = 16 \times 25 = 400$。

(e) $\left(\dfrac{2}{3}\right)^3 = \dfrac{2^3}{3^3} = \dfrac{8}{27}$。

(f) $\left(\dfrac{3}{4}\right)^2 = \dfrac{3^2}{4^2} = \dfrac{9}{16}$。

(g) $\left(-\dfrac{1}{2}\right)^4 = \dfrac{(-1)^4}{2^4} = \dfrac{1}{16}$。

(h) $\left(\dfrac{5}{2}\right)^3 = \dfrac{5^3}{2^3} = \dfrac{125}{8}$。

**易錯點注意**
- 易錯：積的冪須對**每個**因子乘方——如 $(2 \times 3)^2 = 2^2 \times 3^2$，勿只乘方其中一個。

- 易錯：分數冪的符號——$\left(-\frac{1}{2}\right)^4 = \frac{(-1)^4}{2^4} = \frac{1}{16}$，偶次冪消去負號。

#### 題 5（`task` 類）——多律並用（已知底數）

**題干**

計算下列各式。

(a) $\dfrac{2^5 \times 2^3}{2^4}$

(b) $\dfrac{3^4 \times 3^7}{3^8}$

(c) $\dfrac{5^6 \times 5^2}{5^5}$

(d) $(2^3 \times 2^4) \div 2^5$

(e) $(3^2)^3 \times 3^4$

(f) $\dfrac{(4^3)^2}{4^4}$

(g) $(2 \times 3^2)^2$

(h) $\left(\dfrac{2^2}{3}\right)^3$

**考核目標**

綜合運用多條指數運算律化簡。

**詳細解答**

(a) $\dfrac{2^5 \times 2^3}{2^4} = \dfrac{2^8}{2^4} = 2^4 = 16$。

(b) $\dfrac{3^4 \times 3^7}{3^8} = \dfrac{3^{11}}{3^8} = 3^3 = 27$。

(c) $\dfrac{5^6 \times 5^2}{5^5} = \dfrac{5^8}{5^5} = 5^3 = 125$。

(d) $(2^3 \times 2^4) \div 2^5 = 2^7 \div 2^5 = 2^2 = 4$。

(e) $(3^2)^3 \times 3^4 = 3^6 \times 3^4 = 3^{10} = 59049$。

(f) $\dfrac{(4^3)^2}{4^4} = \dfrac{4^6}{4^4} = 4^2 = 16$。

(g) $(2 \times 3^2)^2 = 2^2 \times 3^4 = 4 \times 81 = 324$。

(h) $\left(\dfrac{2^2}{3}\right)^3 = \dfrac{2^6}{3^3} = \dfrac{64}{27}$。

**易錯點注意**
- 易錯：運算順序——先按運算律合併同底數指數（分子合併、分母合併），再相除；如 $\dfrac{2^5 \times 2^3}{2^4} = \dfrac{2^8}{2^4} = 2^4$。
- 易錯：(g) $(2 \times 3^2)^2$ 須展開為 $2^2 \times 3^4$——積的冪律對每個因式乘方，勿直接寫成 $6^4$。
- 易錯：多律並用時勿跳步——每步註明所套運算律，避免指數加減混淆。

**難度**

比較下列各組數的大小，將結果寫為 $a > b$ 或 $a < b$ 的形式。

(a) $5.6 \times 10^7$ 與 $3.2 \times 10^8$

(b) $4.8 \times 10^{-3}$ 與 $9.1 \times 10^{-4}$

(c) $1.23 \times 10^6$ 與 $9.87 \times 10^5$

(d) $2.5 \times 10^{-5}$ 與 $1.5 \times 10^{-6}$

(e) $-4.5 \times 10^{-3}$ 與 $-2.1 \times 10^{-2}$

(f) $-8.0 \times 10^4$ 與 $-6.0 \times 10^5$

**考核目標**

比較數量級不同或係數不同的科學記數法數。

**詳細解答**

(a) $10^7 < 10^8$，故 $5.6 \times 10^7 < 3.2 \times 10^8$。

(b) $10^{-3} > 10^{-4}$，故 $4.8 \times 10^{-3} > 9.1 \times 10^{-4}$。

(c) $10^6 > 10^5$，故 $1.23 \times 10^6 > 9.87 \times 10^5$。

(d) $10^{-5} < 10^{-6}$，故 $2.5 \times 10^{-5} < 1.5 \times 10^{-6}$。

(e) $|-4.5 \times 10^{-3}| = 4.5 \times 10^{-3} > |-2.1 \times 10^{-2}| = 2.1 \times 10^{-2}$？否，$4.5 \times 10^{-3} < 2.1 \times 10^{-2}$，故 $-4.5 \times 10^{-3} > -2.1 \times 10^{-2}$。

**易錯點注意**
- 易錯：正數先比數量級（指數）——指數大者大；指數相同才比係數。
- 易錯：負數比較反向——$|-4.5 \times 10^{-3}| = 4.5 \times 10^{-3} < 2.1 \times 10^{-2} = |-2.1 \times 10^{-2}|$，故前者反而大。

#### 題 43（無結構類）——$b$ 進制的位值推廣

(d) 由此證明重複「除以 $2$ 取餘數」並將餘數倒序排列，可得到 $A$ 的二進制表示。

**考核目標**

以位值展開證明除 2 取餘法的數學原理。

**詳細解答**

(a) $A = a_k 2^{k-1} + a_{k-1} 2^{k-2} + \cdots + a_2 2 + a_1$。

(b) $A = 2(a_k 2^{k-2} + a_{k-1} 2^{k-3} + \cdots + a_2) + a_1$。
除 $a_1$ 外各項均含因子 $2$。
$\implies A$ 除以 $2$ 的餘數為 $a_1$。

(c) 由 (b)，$A$ 除以 $2$ 的商為 $a_k 2^{k-2} + a_{k-1} 2^{k-3} + \cdots + a_2 = a_k a_{k-1} \cdots a_2 {}_2$。

(d) 重複除以 $2$：每次得到的餘數依次為 $a_1, a_2, \dots, a_k$（由低位到高位），將餘數倒序排列即得 $a_k \cdots a_2 a_1 {}_2$。
$\implies$ 此即 $A$ 的二進制表示。

**易錯點注意**
- 易錯：(a) 位數與指數對應——$a_k$ 在 $2^{k-1}$ 位（從 $a_1$ 起為個位），勿錯位。
- 易錯：(b) 提出因子 $2$ 後識別餘數——$A = 2(\ldots) + a_1$，故除以 $2$ 的餘數為 $a_1$。
- 易錯：(d) 倒序的原因——先除得的餘數是最低位 $a_1$，最後才得最高位 $a_k$。

#### 題 53（複雜結構類）——證明乘 2 取整法

**題干**

（引導式證明）證明乘 $2$ 取整法的原理。

設 $0 \leq B < 1$ 為一純小數，其在二進制中表示為 $0.c_1 c_2 c_3 \cdots {}_2$，其中每個 $c_i$ 取值為 $0$ 或 $1$。

(a) 寫出 $B$ 的進制展開式。

(b) 證明 $2B$ 的整數部分為 $c_1$。

(c) 證明 $2B$ 的小數部分為 $0.c_2 c_3 \cdots {}_2$。

(d) 由此證明重複「乘以 $2$ 取整數部分」並將整數部分正序排列，可得到 $B$ 的二進制表示。

**考核目標**

以位值展開證明乘 2 取整法的數學原理。

**詳細解答**

(a) $B = c_1 2^{-1} + c_2 2^{-2} + c_3 2^{-3} + \cdots$。

(b) $2B = c_1 + c_2 2^{-1} + c_3 2^{-2} + \cdots$。
$c_1$ 為整數部分（$c_1 = 0$ 或 $1$），其餘各項和 $< 1$。
$\implies 2B$ 的整數部分為 $c_1$。

(c) 由 (b)，$2B$ 的小數部分為 $c_2 2^{-1} + c_3 2^{-2} + \cdots = 0.c_2 c_3 \cdots {}_2$。

(d) 重複乘以 $2$：每次取出的整數部分依次為 $c_1, c_2, \dots$（由高位到低位），正序排列即得 $0.c_1 c_2 c_3 \cdots {}_2$。
$\implies$ 此即 $B$ 的二進制表示。

**易錯點注意**
- 易錯：(a) 小數展開用負指數——$B = c_1 2^{-1} + c_2 2^{-2} + \cdots$。
- 易錯：(b) 乘 $2$ 後 $c_1$ 移入整數部分——其餘各項和 $< 1$（因 $c_i \le 1$ 且 $2^{-1} + 2^{-2} + \cdots = 1$）。

其中 $n$ 為自然數。

**考核目標**

逆用分配律提取公因式後約分化簡。

**詳細解答**

### 判定標準

- **配圖**：題干描述具體幾何圖形（具頂點字母的三角形／四邊形），或可建模為直角三角形的現實情境。
- **不配圖**：純計算、推理、代數化簡、文字應用題。
- 配圖遵循既有規範：頂點字母必標、不畫頂點圓點、不標角度／邊長數值；圖僅為展示，題干資訊須足以獨立還原配圖。

### 逐題判定

- **需配圖（0 題）**：無
- **不需配圖（57 題）**：1–57

（全冊為純計算／推理／代數化簡題，無幾何圖形或可建模情境，故全部不配圖。）
