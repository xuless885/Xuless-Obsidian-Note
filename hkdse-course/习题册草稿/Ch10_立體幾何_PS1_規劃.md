### §10.1 基本立體圖形

#### 題 1（`task` 類）——柱體與錐體辨識

**題干**

判斷下列各描述是否為柱體（棱柱或圓柱）或錐體（棱錐或圓錐），並解釋你的答案。

(a) 上下兩底為全等且平行的凸多邊形，側面均為矩形。

(b) 上下兩底為全等且平行的圓，側面為一曲面。

(c) 上下兩底為相似但不全等的三角形，側面為梯形。

(d) 一個多邊形底面及一個不在底面上的頂點，側面均為三角形。

(e) 一個圓形底面及一個頂點，頂點在底面上的垂直投影為圓心。

(f) 兩個全等且平行的三角形底面及三個矩形側面。

(g) 一個凸多邊形底面及一個頂點，頂點在底面上的垂直投影為底面中心。

(h) 一個三角形底面及一個頂點，但頂點在底面上的垂直投影不在底面內。

**考核目標**

運用柱體／錐體定義辨識立體類型（講義 §10.1.1–10.1.2）。

**詳細解答**

依柱體定義（兩全等且平行的凸多邊形底面＋矩形側面、側棱垂直底面，講義 §10.1.1）與錐體定義（凸多邊形／圓底面＋一頂點、側面為三角形／曲面，講義 §10.1.2）逐項判斷：

(a) 兩底為全等且平行的凸多邊形、側面均為矩形，符合棱柱定義。

(b) 兩底為全等且平行的圓、側面為曲面，符合圓柱定義。

(c) 兩底相似但**不全等**，不滿足柱體「兩底全等」的條件；此為平截頭體，兩者皆不是。

(d) 多邊形底面＋不在底面上的頂點、側面均為三角形，符合棱錐定義。

(e) 圓形底面＋頂點投影為圓心，符合圓錐定義。

(f) 兩全等且平行的三角形底面＋三個矩形側面，符合棱柱定義。

(g) 凸多邊形底面＋頂點投影為底面中心、側面為三角形，符合棱錐定義。

(h) 雖頂點投影不在底面內，仍有三角形側面，屬斜棱錐（錐體定義不要求頂點投影在底面內）。

**易錯點注意**

- 易錯：誤把 (c) 的「平截頭體」當作柱體——柱體須兩底**全等**，相似但不全等不滿足。
- 易錯：誤以為 (h) 不是錐體——定義只要求底面＋頂點＋三角形側面，頂點投影位置不影響類型。

#### 題 4（簡單結構類）——圓錐的斜高與垂直高

**題干**

一個直圓錐的底面半徑為 $5\text{ cm}$，垂直高為 $12\text{ cm}$。

(a) 求該圓錐的斜高 $\ell$。

(b) 若另一個直圓錐的底面半徑為 $8\text{ cm}$，斜高為 $17\text{ cm}$，求其垂直高。

**考核目標**

運用畢氏定理求斜高（講義 §10.1.2、Ch08 聯動），正反向各一次。

**詳細解答**

斜高 $\ell$、垂直高 $h$ 與底面半徑 $r$ 構成直角三角形（講義 §10.1.2 例題），先看 (a) 由 $r,h$ 求 $\ell$，再看 (b) 反過來由 $\ell,r$ 求 $h$。

(a) 由畢氏定理（Ch08 §8.5）：

$\ell = \sqrt{5^2 + 12^2} = \sqrt{25 + 144} = \sqrt{169} = 13$。

$\implies$ 該圓錐的斜高為 $13\text{ cm}$。

(b) 已知斜高與半徑，反向用畢氏定理：

$h = \sqrt{17^2 - 8^2} = \sqrt{289 - 64} = \sqrt{225} = 15$。

$\implies$ 其垂直高為 $15\text{ cm}$。

**易錯點注意**

- 易錯：斜高 $\ell$ 與垂直高 $h$ 混淆——$\ell$ 沿側面走、$h$ 沿垂直方向升降（講義 §10.1.2）。
- 易錯：(b) 是斜邊平方減半徑平方（$17^2 - 8^2$），勿寫成 $8^2 - 17^2$ 或兩者相加。

**難度**

> 分題 (a)｜難度：**T D｜C C｜E D｜Q C**
> 判定理由（T）：直接套畢氏定理求斜邊，一步直出。

#### 題 56（複雜結構類）——平截頭體公式的退化

**題干**

已知平截頭體體積公式 $V = \dfrac{h}{3}\left(A_1 + A_2 + \sqrt{A_1 A_2}\right)$，其中 $A_1, A_2$ 分別為下底面與上底面的面積，$h$ 為高。

(a) 當上下底面全等（$A_1 = A_2 = A$）時，平截頭體退化為柱體。證明此時公式給出 $V = Ah$。

(b) 當上底面收縮為一點（$A_2 = 0$）時，平截頭體退化為錐體。證明此時公式給出 $V = \dfrac{1}{3}A_1 h$。

(c) 當上下底面均為圓（$A_1 = \pi R^2$，$A_2 = \pi r^2$）時，證明 $\sqrt{A_1 A_2} = \pi Rr$，從而公式化為圓台體積公式 $V = \dfrac{\pi h}{3}(R^2 + Rr + r^2)$。

**考核目標**

運用已建定理（平截頭體體積公式，講義 §10.2.3）推退化結論。

**詳細解答**

(a) 把 $A_1 = A_2 = A$ 代入公式（講義 §10.2.3），化簡即得柱體體積：

$V = \dfrac{h}{3}(A + A + \sqrt{A \cdot A})$。

$\equiv \dfrac{h}{3}(A + A + A)$（$\sqrt{A^2} = A$，$A > 0$，根式化簡）。

$\equiv \dfrac{h}{3}(3A)$（合併同類項）。

$\equiv Ah$（約分）。

$\implies$ 當 $A_1 = A_2 = A$ 時，$V = Ah$。

(b) 把 $A_2 = 0$ 代入：

$V = \dfrac{h}{3}(A_1 + 0 + \sqrt{0})$。

$\equiv \dfrac{h}{3}A_1$。

$\implies$ 當 $A_2 = 0$ 時，$V = \dfrac{1}{3}A_1 h$。

(c) 代 $A_1 = \pi R^2$、$A_2 = \pi r^2$：

$\sqrt{A_1 A_2} = \sqrt{(\pi R^2)(\pi r^2)} = \sqrt{\pi^2 R^2 r^2} = \pi Rr$（$R, r > 0$，根式化簡，Ch06）。

$V = \dfrac{h}{3}(\pi R^2 + \pi r^2 + \pi Rr) \equiv \dfrac{\pi h}{3}(R^2 + Rr + r^2)$（提取公因式 $\pi h/3$）。

$\implies$ 公式化為圓台體積公式 $V = \dfrac{\pi h}{3}(R^2 + Rr + r^2)$。

#### 題 60（複雜結構類，黑框）——正多面體的對偶性

**題干**

講義已證明世界上僅存在五種正多面體，並以 $(p, q)$ 表示每個面為正 $p$ 邊形、每個頂點匯聚 $q$ 條棱。

對於一個正多邊形面，其**中心**為該正多邊形的外接圓圓心，亦即內切圓圓心，即該正多邊形所有對稱軸的交點。

考慮將該正多面體的每個面的中心取為新頂點，連接相鄰面（即共用一條棱的兩個面）的中心以構成一個新的正多面體，稱為原正多面體的**對偶（dual）**。

(a) 證明正四面體 $(3, 3)$ 的對偶仍為 $(3, 3)$，即正四面體自對偶。

(b) 證明正方體 $(4, 3)$ 的對偶為 $(3, 4)$（正八面體），反之亦然。

(c) 由此，說明正十二面體 $(5, 3)$ 與正二十面體 $(3, 5)$ 互為對偶。某人宣稱五種正多面體的對偶仍在五種正多面體之中。該宣稱是否正確？試解釋你的答案。

**考核目標**

$p \leftrightarrow q$ 變換（新概念「對偶」由題干定義，黑框探索）。

**詳細解答**

對偶以面中心為新頂點：對偶的頂點數＝原立體的面數 $F$；每個原面為 $p$ 邊形（每棱屬 2 面），故每個新頂點匯聚 $p$ 條棱，即 $(p,q) \mapsto (q,p)$ 交換：

(a) 正四面體 $(3,3)$ 有 $4$ 個面，故對偶有 $4$ 個頂點。

每個面為正三角形（3 條棱），每條棱屬 2 個面，故每個新頂點由 3 個面中心匯合，即每頂點匯聚 3 條棱。

$\implies$ 對偶為 $(3,3)$，正四面體自對偶。

(b) 正方體 $(4,3)$ 有 $6$ 個面，故對偶有 $6$ 個頂點。

每個面為正方形（4 條棱），故每個新頂點匯聚 4 條棱；每個對偶面由 3 個面中心構成（三角形）。

$\implies$ 對偶為 $(3,4)$，即正八面體；反之，正八面體 $(3,4)$ 的對偶為 $(4,3)$（正方體）。

(c) 同理，正十二面體 $(5,3)$ 有 $12$ 個面，對偶有 $12$ 個頂點、每頂點匯聚 5 條棱，即 $(3,5)$（正二十面體）；反之亦然。

五種正多面體的對偶依次為 $(3,3) \leftrightarrow (3,3)$、$(4,3) \leftrightarrow (3,4)$、$(5,3) \leftrightarrow (3,5)$，均在五種之中。

$\implies$ 該宣稱正確。

**易錯點注意**
